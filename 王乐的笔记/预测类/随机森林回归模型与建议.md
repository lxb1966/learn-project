# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：**种很多棵"各看一部分数据、各看一部分特征"的决策树，让它们投票/取平均**，得到比单棵树稳得多的预测。

| 问题 | 回答 |
|---|---|
| 核心问题 | 给定一堆特征，预测一个连续值（或概率），且**不假设关系是线性的** |
| 输入 | `n × k` 表格数据（数值/类别都行），**有标签** |
| 输出 | 预测值（回归）/ 概率（分类）+ **特征重要性** + 偏依赖曲线 |
| 数据类型 | 表格型（structured data）的绝对王者 |
| 方法类别 | **机器学习 → 集成学习 → Bagging（并行式）** |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **单棵决策树** | 随机森林的"退化版" | 只需要一个能画出来给评委看的规则树 |
| **GBDT / XGBoost / LightGBM** | 串行 Boosting，通常更准 | 追求精度、肯花调参时间（比赛常用） |
| **线性/逻辑回归** | 线性基线 | 关系接近线性、样本少、要解释系数 |
| **SVM** | 核方法 | 中小样本、高维 |
| **KNN** | 最近邻 | 特征少、样本少 |
| **神经网络** | 万能逼近 | 图像/文本/超大样本 |

### 一句话选型

> **表格数据 + 关系非线性 + 要特征重要性 → 随机森林；追求极致精度 → GBDT；要解释系数 → 回归。**

---

## 第二层：假设 —— 它成立的前提

随机森林的假设**比线性回归少得多**，这是它最大的优势。

| # | 假设 | 含义 | 违反了会怎样 |
|---|---|---|---|
| 1 | **样本独立同分布** | 每行数据互不影响 | 时序/重复测量数据要特殊处理（否则泄漏） |
| 2 | **训练集与测试集同分布** | 未来和过去长得像 | 分布漂移后精度暴跌 |
| 3 | **特征包含足够信息** | 该有的变量都在 | 再强的模型也救不回来（垃圾进垃圾出） |
| 4 | **样本量足够** | 经验：≥ 几百行 | 小样本时极不稳定，重要性排序随机 |
| 5 | **树足够多** | 200–500 棵以上 | 太少则方差大、结果随机 |

### 它**不需要**的假设（相对线性回归的巨大优势）

- ❌ 不需要线性
- ❌ 不需要正态
- ❌ 不需要同方差
- ❌ 不需要特征独立（共线不影响预测精度，但会**摊薄重要性**）
- ❌ 不需要标准化（树只看大小顺序，不看绝对尺度）

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **不能外推** | 树只会在"见过的取值范围内"做平均 | 预测 2030 年（超出训练区间）只能输出历史最大值附近 |
| **对高基数特征有偏** | 不纯度重要性偏爱取值多的特征 | 重要性排序可能骗人 |
| **小样本不稳** | n < 200 时结果每次都不一样 | 结论不可复现 |
| **类别不平衡** | 99:1 的数据会全预测成多数类 | 要看 AUC/召回率，不能只看准确率 |
| **数据泄漏** | 特征里混进了"未来信息" | 交叉验证分数虚高，一上测试集就崩 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | ≥ 几百；k 可以很多（几十上百都行） |
| 缺失值 | **sklearn 的随机森林不吃 NaN**，要先填补（均值/中位数/模型插补） |
| 类别变量 | 要编码（One-Hot 或 有序编码） |
| 异常值 | 不敏感（树按顺序切分），但极端值仍会影响 |
| 量纲 | 不用管 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **单棵树容易"过拟合 + 方差大"；让很多棵各不相同的树取平均，方差就被平掉了。**

数学上：若 B 棵树的方差都是 σ²、两两相关系数 ρ，则平均后的方差是

```
ρσ² + (1−ρ)σ²/B
```

- 树越多（B↑）→ 第二项趋于 0；
- **树之间越不相关（ρ↓）→ 第一项越小**。

随机森林的两处"随机"就是为了把 ρ 压下去：

| 随机 | 怎么做 | 作用 |
|---|---|---|
| **样本随机（Bootstrap）** | 每棵树有放回抽 n 个样本（约 63% 不重复） | 让每棵树看到不同的数据 |
| **特征随机** | 每次分裂只从**随机 k 个特征**里挑最优（分类默认 √k，回归默认 k/3） | 防止所有树都盯着同一个强特征 |

### 单棵树怎么长

在每个节点，遍历候选特征和切分点，选让**不纯度下降最多**的那个：

- 回归用**方差（MSE）**：`MSE = (1/n)Σ(yᵢ − ȳ)²`
- 分类用**基尼系数**：`Gini = 1 − Σpⱼ²`

一直分到满足停止条件（最大深度 / 叶节点最少样本）。

### 关键超参数

| 超参数 | 控制什么 | 调大/调小的后果 | 常用范围 |
|---|---|---|---|
| `n_estimators` | 树的数量 | 越大越稳，但收益递减、耗时线性增长 | 200–1000 |
| `max_depth` | 树的最大深度 | 大→过拟合；小→欠拟合 | 4–20 或 None |
| `min_samples_leaf` | 叶节点最少样本 | **大→更平滑、概率估计更准**（本案例的关键） | 1–50 |
| `max_features` | 每次分裂考虑几个特征 | 小→更去相关、更稳；大→单树更强 | sqrt / 0.3–0.6 |
| `oob_score` | 是否算袋外评分 | 开了就有一份免费验证 | True |

### 可解释性：★★★☆☆（比线性弱，比神经网络强得多）

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **不纯度重要性** | 这个特征在分裂时贡献了多少 | ⚠️ 偏爱高基数特征，会虚高 |
| **置换重要性** | 打乱这一列，误差涨多少 | ✅ 推荐写进论文 |
| **偏依赖图 PDP** | 这个特征和预测值是什么形状的关系 | ✅ 论文里最好看 |
| **SHAP** | 每个样本、每个特征的贡献 | ✅ 最细，但计算贵 |

## 第四层：操作 —— 怎么跑起来

### 七步流程（速览）

```
① 数据准备     缺失值填补、类别编码、划分训练/测试
② 基线模型     线性回归（没有基线就没有"提升"）
③ 训练随机森林  先默认超参跑一遍
④ 调参         用 CV 分数驱动超参选择（GridSearch / RandomizedSearch 内部含 CV）
⑤ 检验         OOB 评分 · 测试集指标 · 学习曲线（三者各司其职，不混为一谈）
⑥ 解释         特征重要性 + 偏依赖图
⑦ 对比         与基线、与单棵树、与 GBDT 放进同一张表
```

> **两个定位提醒**（实操与论文写作最容易混的地方）：
> 1. **第④步不是"交叉验证调参"这个独立动作**——交叉验证是 `GridSearchCV` / `RandomizedSearchCV` **内部**用来评估候选超参好坏的手段，嵌在搜索器里，不是调参之后再"额外做一次"。
> 2. **第⑤步要拆成三个不同层次的数据**：OOB 是训练阶段的内部估计、测试集指标是最终泛化能力的唯一权威数字、学习曲线是诊断过拟合/欠拟合的工具。三者角色不同，不能当"一步"随意带过。

### 七步详解

> 每一步给五样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**要画什么图**、**论文呈现**、**常见坑**。
> 本案例是 5000 个逐分数据，预测"发球方赢下这一分"，所以指标是 Brier/AUC，不是 R²。

#### ① 数据准备：产出可复现的训练/测试集

**做什么（按顺序）**：

1. **看目标变量的分布**：画直方图；严重偏态时考虑取对数，或改用能处理偏态的指标。
2. **补缺失**：随机森林能吃 NaN 的只有 `HistGradientBoosting`，`RandomForestRegressor` 不行，必须先填。连续用中位数、类别用"缺失"单列。
3. **类别编码**：`pd.get_dummies(drop_first=True)`；有序类别（低/中/高）直接编码成 0/1/2 更省维度。
4. **划分**：`train_test_split(test_size=0.25, random_state=42)`；时序数据必须按时间切，不能随机。
5. **固定种子**：全流程只用一个 `random_state`，否则论文数字对不上。

```python
from sklearn.model_selection import train_test_split

df['serve_kmh'] = df['serve_kmh'].fillna(df['serve_kmh'].median())
df = pd.get_dummies(df, columns=['surface'], drop_first=True, dtype=int)

X, y = df[FEATURES], df['win']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 训练/测试样本数 | `len(X_train)`、`len(X_test)` | 3750 / 1250 |
| 入模特征数 | `X_train.shape[1]`（编码后） | 7 |
| 各特征缺失率 | `df[col].isnull().mean()` | 0%（构造数据无缺失） |
| 目标均值 | `y.mean()` | 0.504（类别均衡） |

**要画什么图**：**目标变量直方图**（可选项），用来看偏态与是否类别均衡；本案例 0/1 目标，画一张 0/1 柱状图即可，正文一句话"胜率 0.504，均衡"。

**论文呈现**：一张"清洗前后对比表"（样本量变化、缺失填补方式、编码后特征数）。

**常见坑**：
- 先填补再划分，会让测试集的统计量漏进训练集；正确顺序是**先切分，填补用的中位数只在训练集上算**。
- 时序/比赛数据随机切分 = 数据泄漏，分数虚高。
- 编码后的列名要记下来，PDP 那一步要用。

#### ② 基线模型：没有基线就没有"提升"

**做什么（按顺序）**：

1. 拟合线性回归（回归问题）或逻辑回归（0/1 目标），同一训练集、同一测试集。
2. 再补一个"均值预测基线"（永远预测训练集均值），作为更弱的参照。
3. 三个模型的三项指标摆在一起，看随机森林到底有没有赢。

```python
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.metrics import brier_score_loss, roc_auc_score

base = LogisticRegression(max_iter=2000).fit(X_train, y_train)
p_base = base.predict_proba(X_test)[:, 1]
print(brier_score_loss(y_test, p_base), roc_auc_score(y_test, p_base))
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| Brier | `mean((p − y)²)` | 0.1904 |
| AUC | 正例得分高于负例的概率 | 0.7826 |
| R²（回归题） | `1 − SSE/SST` | — |

**要画什么图**：**预测值 vs 实际值散点**（回归题）或 **ROC 曲线**（0/1 题）。基线这张图放附录即可，正文用表。

**论文呈现**：对比表的第一行；正文一句话"基线逻辑回归 Brier 0.1904、AUC 0.7826"。

**常见坑**：
- 基线在训练集上评估、随机森林在测试集上评估——两个数不可比。
- 只给 R² 不给 Brier：0/1 目标上 R² 天然低（本案例 0.24 已属正常），必须一起报。

#### ③ 训练随机森林：先默认参数跑通

**做什么（按顺序）**：

1. `RandomForestRegressor(n_estimators=200, oob_score=True, random_state=42, n_jobs=-1)` 直接拟合。
2. 看 OOB 分数与训练/测试分数，判断调参空间。
3. **不要在这一步手动调参**。

```python
from sklearn.ensemble import RandomForestRegressor

rf0 = RandomForestRegressor(n_estimators=200, oob_score=True,
                            random_state=42, n_jobs=-1).fit(X_train, y_train)
print(rf0.oob_score_)                       # 袋外 R²
p0 = rf0.predict(X_test)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| OOB 分数 | `rf0.oob_score_`（每棵树对未抽中样本的预测） | — |
| 训练/测试 Brier | `brier_score_loss` | 默认模型测试 **0.1976** |
| 训练-测试差 | 训练指标 − 测试指标 | 差距大说明过拟合 |

**要画什么图**：**OOB 分数随树数变化**（`n_estimators` 从 50 加到 500），看曲线何时走平——这张图能回答"200 棵够不够"，可选。

**论文呈现**：一句话"默认参数（200 棵、叶节点 1 个样本）Brier = 0.1976"。

**常见坑**：
- `oob_score=True` 必须配合 `bootstrap=True`（默认是 True，别手动关掉）。
- 默认 `min_samples_leaf=1`，输出概率非 0 即 1，校准极差——这正是它输给逻辑回归的原因。

#### ④ 调参：用交叉验证分数驱动

**做什么（按顺序）**：

1. 圈定搜索空间：`n_estimators`、`max_depth`、`min_samples_leaf`、`max_features`。
2. 用 `GridSearchCV(cv=5, scoring='neg_mean_squared_error', n_jobs=1)`；**外层 n_jobs 必须是 1**，否则嵌套并行会返回 NaN。
3. 用最优参数重训，**在测试集上只评估一次**。

```python
from sklearn.model_selection import GridSearchCV

grid = {'n_estimators': [200, 400],
        'max_depth': [None, 6],
        'min_samples_leaf': [10, 30]}
gs = GridSearchCV(RandomForestRegressor(random_state=42),
                  grid, cv=5, scoring='neg_mean_squared_error', n_jobs=1)
gs.fit(X_train, y_train)
print(gs.best_params_, -gs.best_score_)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 最优超参 | `gs.best_params_` | `max_depth=6, min_samples_leaf=30, n_estimators=200` |
| 最优 CV 分数 | `-gs.best_score_`（MSE，对 0/1 即 Brier） | **0.1903** |
| CV 标准差 | `gs.cv_results_['std_test_score']` | 用来判断调参稳不稳 |
| 搜索次数 | 各参数取值数相乘 × cv | 2×2×2×5 = 40 次拟合 |

**要画什么图**：**参数-分数热力图**（两参数一格，颜色是 CV 分数），或折线图；放附录，正文一句"最优解落在树浅、叶子大的一端"。

**论文呈现**：小表"调参方法 / 搜索空间 / 最优参数 / 最优 CV 分数"，并说明为什么选这个 scoring。

**常见坑**：
- 外层 `n_jobs=-1` 套内层 `n_jobs=-1` → CV 分数变 NaN（本机踩过）。
- 拿 CV 分数当最终性能——它只是"选参"用的，权威数字只能是测试集。

#### ⑤ 检验：OOB、测试集、学习曲线各司其职

**做什么（按顺序）**：

1. **OOB**：看袋外分数，佐证没有严重过拟合。
2. **测试集**：用最终模型算三项指标，这是论文唯一权威数字。
3. **学习曲线**：`learning_curve(cv=5)`，看加数据还能不能涨。

```python
from sklearn.model_selection import learning_curve

sizes, tr, va = learning_curve(rf, X_train, y_train, cv=5,
                               train_sizes=np.linspace(0.1, 1.0, 8),
                               scoring='neg_mean_squared_error')
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| OOB R² | `rf.oob_score_` | **0.2388** |
| 测试集指标 | Brier / AUC / 准确率 | 0.1867 / 0.7891 / 0.7232 |
| 学习曲线首末 | 训练/验证误差两端值 | 训练 0.182→0.175；验证 0.205→0.190 |

**要画什么图**：**学习曲线**（横轴训练样本量、纵轴分数，两条线）。判读：两线收敛且接近=良好；训练高验证低=过拟合；两者都低=欠拟合。

**论文呈现**：OOB 一句话带过；测试指标进对比表；学习曲线配一句诊断结论。

**常见坑**：
- 把 OOB 当测试集用——它是训练阶段的内部估计。
- 0/1 目标的 R² 天花板只有 0.2–0.3，别拿它跟连续变量的回归比。

#### ⑥ 解释：置换重要性 + 偏依赖图

**做什么（按顺序）**：

1. 用 `permutation_importance(n_repeats=10)` 算置换重要性（**不用** `feature_importances_`）。
2. 取前 2–3 个特征画 PDP，看"关系是什么形状"。
3. 每张图配一句结论。

```python
from sklearn.inspection import permutation_importance, PartialDependenceDisplay

perm = permutation_importance(rf, X_test, y_test, n_repeats=10, random_state=42)
PartialDependenceDisplay.from_estimator(rf, X_test, ['momentum', 'rally_len'])
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 置换重要性 | 打乱一列后误差的平均涨幅 | momentum **0.2849**、prev_won 0.0766、serve_kmh 0.0036 |
| 重要性倍数 | 第一名 ÷ 第二名 | 0.2849 / 0.0766 ≈ 3.7 倍 |
| PDP 拐点 | 曲线上斜率突变处 | momentum ≈ 0.3；rally_len 第 8 拍 |

**要画什么图**：**特征重要性横向条形图** + **PDP 折线图**（2–3 个特征）。本案例的 `fig_rf_importance.png` 就是把重要性、两张 PDP、学习曲线拼成了一张。

**论文呈现**：重要性图放正文，图注写"permutation importance，10 次重复取均值"；PDP 每张配一句形状结论。

**常见坑**：
- 不纯度重要性偏爱高基数特征（发球速度有几十种切法，被高估 10 倍）。
- PDP 的 `X` 必须是带列名的 DataFrame，传 numpy 数组会报 `Feature not in feature_names`。
- PDP 假设特征之间独立，强相关时曲线会失真。

#### ⑦ 对比：用一张表把"提升"讲清楚

**做什么（按顺序）**：

1. 四个模型同一测试集：逻辑回归、单棵决策树、默认 RF、调参 RF。
2. 三项指标并列：Brier、LogLoss、AUC、准确率。
3. 表下一句话点明结论，**包括"提升有限"这件事**。

```python
models = {'逻辑回归': p_base, '单棵决策树': p_tree,
          '随机森林（默认）': p0, '随机森林（调参）': p_rf}
for name, p in models.items():
    print(name, brier_score_loss(y_test, p), roc_auc_score(y_test, p))
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 四模型 Brier | `brier_score_loss` | 0.1904 / 0.1972 / 0.1976 / **0.1867** |
| 相对提升 | (基线 − 本模型) / 基线 | (0.1904 − 0.1867) / 0.1904 = **1.9%** |
| AUC 变化 | 差值 | 0.7826 → 0.7891 |

**要画什么图**：**四模型指标柱状图**或 **ROC 叠图**（可选）；正文的表才是主角。

**论文呈现**：一张"模型 / Brier / LogLoss / AUC / 准确率"表；表下一句"调参后 Brier 降 1.9%，方向一致但幅度有限"。

**常见坑**：
- 只报 R² 不报 Brier，0/1 目标上会被质疑。
- 不敢写"提升只有 1.9%"——评委反而觉得你读懂了结果。

## 第五层：评价 —— 怎么判断它好不好

| 维度 | 表现 |
|---|---|
| **回归指标** | R²、RMSE、MAE、MAPE |
| **概率指标**（0/1 目标） | **Brier**、LogLoss、AUC、准确率 |
| **基线** | 线性回归 / 逻辑回归 / 单棵树 / 均值模型 |
| **对异常值** | 不敏感（这是优点） |
| **对噪声特征** | 不敏感（随机特征选择天然抗噪） |
| **小样本** | **很不稳**，重要性排序基本不可信 |
| **过拟合** | 中等风险：深树会记住噪声，但袋外样本 + 平均能缓解 |
| **防过拟合** | 限制 `max_depth` / 提高 `min_samples_leaf` / 增加树数 / 交叉验证 |
| **外推** | **不能用**（这是最大硬伤，写论文必须提） |

### 一条容易被忽略的规律

> **默认超参的随机森林，常常打不过调好参的逻辑回归。**
> 因为默认 `min_samples_leaf=1`，每个叶子只有 1 个样本，输出的"概率"非 0 即 1，校准极差。把叶节点样本数提到 20–50，Brier 会明显下降——本案例正是如此（0.1976 → 0.1867）。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 参数反演、代理模型 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐⭐ 主战场 | 表格数据预测 + 特征重要性 |
| D 运筹 | ⚠️ 偶尔 | 需求预测喂给优化 |
| **E 环境** | ⭐ 常见 | 多因子环境影响、风险分级 |
| **F 政策** | ⭐ 常见 | 政策效果异质性、影响因素排序 |

### 三个典型场景

1. **C 题·体育/行为预测**：逐分数据预测胜率，找出"势头"到底存不存在（本案例）。
2. **E 题·污染/灾害归因**：用气象、地理、人为因素预测 PM2.5，输出特征重要性排序。
3. **F 题·政策异质性**：哪些地区/人群对政策更敏感（随机森林 + 分组 PDP）。

### 论文呈现顺序

```
1. 特征表（含义、单位、来源）
2. 模型对比表（线性 / 逻辑 / 单树 / RF / RF调参）← 必须有
3. 调参过程（网格 + 交叉验证分数，证明不是拍脑袋）
4. 特征重要性条形图（置换重要性，别用不纯度）
5. 偏依赖图（讲清"关系长什么样"，这是 RF 唯一的解释窗口）
6. 学习曲线（证明没有过拟合）
```

### 局限性写法（可直接改）

> "随机森林不假设线性关系，能自动捕捉阈值与交互效应，但其预测值被限制在训练样本的取值范围内，**不具备外推能力**；同时特征重要性存在相关性摊薄与高基数偏差，本文采用置换重要性替代不纯度重要性以缓解该问题。模型在测试集上 Brier 为 0.187，较逻辑回归基线下降 1.9%，差距有限，说明本数据中线性结构已解释大部分变异；若关系更接近线性，应优先选择可解释性更强的逻辑回归。"

> 注意最后一句——**主动承认"提升有限"**，比硬吹"随机森林显著更优"更得分。

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **RF + 线性回归** | 线性基线 vs 非线性，最标准的"模型对比" |
| **RF 特征重要性 → 筛变量 → 回归** | 先用 RF 找重要变量，再用回归解释（两全其美） |
| **RF + SHAP** | 单样本级解释，E/F 题很出彩 |
| **RF + GBDT** | 集成方法内部的对比 |

### 三个常见扣分点

1. **只报准确率** → 类别不平衡时毫无意义，要报 AUC/Brier；
2. **用不纯度重要性下结论** → 高基数特征虚高，评委看得出来；
3. **声称"随机森林不需要假设"** → 它不能外推、要 iid，这两条必须写。

# 第二部分 · 案例（2024 MCM C 题风格：网球"势头"是否存在）

## 一、题目背景

网球解说常说"他现在起势了"。问题是：**势头（momentum）到底是不是真的存在？**

做法：用 5000 个逐分数据，预测"发球方赢下这一分"的概率，然后看：

1. 控制住发球速度、一发、回合长度、体能之后，**"势头"还有没有独立作用**？
2. 这个作用是什么形状（线性？还是有拐点）？
3. 用它预测比赛，比传统线性模型强多少？

> 数据说明：教学构造（5000 分 × 7 特征），关系里故意埋了阈值、交互、曲率三种非线性结构。换成真实的逐分数据（如 ATP 公开数据），流程一行不改。

### 变量说明

| 变量 | 含义 | 类型 | 预期方向 |
|---|---|---|---|
| `serve_kmh` | 发球速度 | 连续 | + |
| `first_serve` | 一发是否进区 | 0/1 | + |
| `rally_len` | 本回合拍数 | 计数 | − |
| `prev_won` | 上一分是否赢 | 0/1 | + |
| `momentum` | 势头指数（近 5 分加权） | 连续 −1.5~1.5 | + |
| `fatigue` | 体能消耗 | 0~1 | − |
| `is_clay` | 是否红土场 | 0/1 | ? |
| **`win`** | **本分是否赢（目标）** | **0/1** | — |

| 204 | 1 | 3 | 0 | −0.13 | 0.49 | 1 | 1 |

## 二、完整建模流程（7 步）

### 第 1 步：划分与基线

训练 3750 分 / 测试 1250 分，**分层抽样**保证两边胜率一致。

先建两个线性基线：

- **线性概率模型**（就是上一份文件的多元线性回归，只是 y 是 0/1）；
- **逻辑回归**（0/1 场景的正统方法）。

### 第 2 步：训练随机森林（默认超参）

`n_estimators=200`，其余全默认（`min_samples_leaf=1`）。

### 第 3 步：网格调参

5 折交叉验证，搜索空间：

```
n_estimators ∈ {200, 400}
max_depth    ∈ {None, 6}
min_samples_leaf ∈ {10, 30}
```

**最优**：`max_depth=6, min_samples_leaf=30, n_estimators=200`，交叉验证 Brier = **0.1903**。

> 注意最优解落在"树很浅、叶子很大"这一端——说明这份数据**不需要复杂的树**，需要的恰恰是"平滑的概率估计"。

### 第 4 步：袋外（OOB）评分

随机森林每棵树只用约 63% 的样本训练，剩下 37% 是"袋外样本"，相当于**自带一份免费验证集**。

```
OOB R² = 0.2388
```

> 0/1 目标上 R² 天然偏低（理论天花板也就 0.2–0.3），**别拿它跟连续变量的回归比**。

### 第 5 步：模型对比

| 模型 | Brier↓ | LogLoss↓ | AUC↑ | 准确率↑ |
|---|---|---|---|---|
| 线性回归（线性概率模型） | 0.1919 | 0.5685 | 0.7822 | 0.7176 |
| 逻辑回归 | 0.1904 | 0.5627 | 0.7826 | 0.7184 |
| 单棵决策树（深度 6） | 0.1972 | 0.6979 | 0.7709 | 0.7120 |
| 随机森林（默认超参） | 0.1976 | 0.5822 | 0.7673 | 0.6976 |
| **随机森林（调参后）** | **0.1867** | **0.5545** | **0.7891** | **0.7232** |

**三个必须讲出来的现象**：

1. **默认超参的 RF 输给了逻辑回归**（0.1976 vs 0.1904）——叶子只有 1 个样本，概率非 0 即 1，校准极差；
2. **调参后反超**（0.1867，Brier 降 1.9%，AUC 升 0.0065）——提升不大但方向一致；
3. **单棵树明显更差**（0.1972）——证明"集成"本身有价值，不是玄学。

> **诚实的结论**：这份数据的非线性结构不算极端，所以 RF 只领先一点点。如果关系更接近线性，逻辑回归会赢——**论文里要敢写这句话**。

### 第 6 步：特征重要性（两种口径）

| 特征 | 不纯度重要性 | 置换重要性 | 差异说明 |
|---|---|---|---|
| **momentum** | 0.6056 | **0.2849** | 都是第一，无争议 |
| prev_won | 0.1025 | 0.0766 | 一致 |
| rally_len | 0.1480 | 0.0659 | 不纯度偏高 |
| first_serve | 0.0386 | 0.0254 | 一致 |
| **fatigue** | 0.0630 | **0.0191** | **不纯度严重高估** |
| **serve_kmh** | 0.0389 | **0.0036** | **不纯度严重高估（10 倍）** |
| is_clay | 0.0035 | 0.0003 | 都不重要 |

**为什么要看两列**：不纯度重要性按"分裂次数 × 不纯度下降"累计，取值连续、切分点多的特征（如发球速度 160–235 有几十种切法）会被**系统性高估**。置换重要性直接问"打乱它，误差涨多少"，更接近"真的有用吗"。

> 论文里**只放置换重要性**，并在图注写明"permutation importance，10 次重复取均值"。

**实质结论**：控制住其他变量后，**势头是第一驱动**（置换重要性 0.285，是第二名的 3.7 倍）——"势头"在这份数据里是真实存在的。

### 第 7 步：偏依赖图（关系长什么样）

![随机森林：重要性 + 偏依赖 + 学习曲线](fig_rf_importance.png)

**三个图各说一件事**：

| 图 | 看到什么 | 结论 |
|---|---|---|
| 右上：momentum 的 PDP | 从 −0.7 到 +0.3 陡峭上升，之后**趋于平台** | 势头有作用，但**边际递减**，不是无限叠加 |
| 左下：rally_len 的 PDP | 1–7 拍平缓下降，**第 8 拍断崖式下跌**（0.51 → 0.19） | 典型**阈值效应**，线性模型永远学不到 |
| 右下：学习曲线 | 训练误差 0.182→0.175，验证误差 0.205→0.190，**两线接近且都在下降** | 没有过拟合；**加数据还能涨** |

> 这张左下角就是随机森林存在的意义：**"第 8 拍之后胜率腰斩"这种台阶，任何线性模型都表达不了。**

## 三、结果解读（论文结论段可直接用）

- 控制发球、回合、体能后，**势头对得分概率有显著且非线性的正向作用**（PDP 显示边际递减，拐点在 momentum ≈ 0.3）；
- 回合长度存在**阈值效应**：8 拍是分水岭，超过 8 拍后发球方胜率从 0.51 跌到 0.19；
- 随机森林调参后 Brier = 0.187、AUC = 0.789，**优于逻辑回归基线**（0.190 / 0.783）与单棵决策树（0.197 / 0.771）；
- 但提升幅度仅 1.9%，说明**线性结构已解释大部分变异**，"势头"的效应虽真实，却不是压倒性的。

**给教练的建议**（C 题必写的一段）：

> 训练重点应放在"把回合控制在 7 拍内"与"连续得分后的心理压制"，而非单纯提升发球速度——后者在置换重要性中几乎垫底（0.0036），说明在本数据中发球速度的边际价值远低于直觉。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 表格数据的非线性预测 + 特征重要性 |
| 核心思想？ | 很多棵"各看一部分数据、一部分特征"的树取平均，降方差 |
| 要什么假设？ | 只要 iid + 同分布；**不要**线性/正态/标准化 |
| 最大硬伤？ | **不能外推**；小样本不稳；重要性有偏 |
| 关键超参？ | `n_estimators`、`max_depth`、`min_samples_leaf` |
| 论文必写？ | 模型对比表 + 置换重要性 + 偏依赖图 + 学习曲线 |

## 自测三问

1. 随机森林和单棵决策树，差别到底在哪？为什么"多"就更好？
2. 为什么调参时最优解常常是"树很浅、叶子很大"？
3. 老板要你预测 2035 年的数据，模型训练样本只到 2024 年，随机森林能行吗？

<details>
<summary>参考答案</summary>

1. 单棵树方差大、对数据扰动极敏感；随机森林通过 bootstrap 抽样 + 随机特征子集让树之间"去相关"，再取平均，把方差项 `ρσ² + (1−ρ)σ²/B` 压下去。树越多、越不相关，平均越稳。
2. 因为叶子样本少时，叶子里的"胜率"只是个别样本的平均，噪声极大（概率非 0 即 1）。叶子样本多 → 概率估计被平滑 → Brier 更低。这不是欠拟合，而是**用偏差换方差**的正确取舍。
3. **不能**。树的预测值永远落在训练样本的取值范围内，对 2035 年这种超出范围的外推，它只会输出"历史最大值附近的平均值"。这种情况要用带趋势的模型（回归 + 时间项、ARIMA）或做情景外推。

</details>
