# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：把"人脑子里的主观偏好"翻译成"一串可计算的权重"。

| 问题 | 回答 |
|---|---|
| 核心问题 | 多准则决策中，**指标没法量化、也没有可信数据**时，怎么定权重、怎么排序？ |
| 输入 | **判断矩阵**：专家/你自己对指标两两比较打的 1–9 分（不需要任何原始数据） |
| 输出 | 权重向量 `w`（和 = 1）+ 各方案综合得分与排名 + 一致性指标 CR |
| 数据类型 | 主观打分、离散、截面、**无标签** |
| 方法类别 | 评价体系（evaluation）下的**主观赋权法**，且**自带排序**能力 |

### 同类竞品

| 竞品 | 和 AHP 的差别 | 什么时候换它 |
|---|---|---|
| **熵值法** | 客观赋权，靠数据差异定权；AHP 靠人判断 | 有可靠数据时 |
| **CRITIC** | 客观，还考虑指标间相关性 | 指标强相关时 |
| **变异系数法** | 客观，最简单 | 赶时间 |
| **德尔菲法** | 只做专家打分聚合，没有一致性检验 | 只要意见不要权重 |
| **ANP** | 允许同层元素相互影响（AHP 假设独立） | 指标间有依赖 |
| **模糊综合评判** | 处理"好/较好/一般"这类模糊评价 | 评价语言是定性的 |
| **TOPSIS** | **只排序、不定权重**，权重是外部输入 | 权重已有，缺排序 |
| **BWM（最优最差法）** | 只需 2n−3 次比较，比 AHP 少一半 | 指标多、专家时间少 |

### 三条"该用它"的判据（考场速判）

1. **没有数据，或数据不可信**（政策、社会、战略类问题）；
2. 要决定的是**"重要性"**而不是"数值大小"；
3. 能找到一个**说得上话的专家**（评委、你自己扮演的决策者都行）。

> 反过来：有干净历史数据还硬用 AHP，会被批"主观代替数据"。

## 第二层：假设 —— 它成立的前提

| # | 核心假设 | 含义 | 违反了会怎样 | 补救 |
|---|---|---|---|---|
| 1 | **层次可分解** | 问题能拆成 目标→准则→方案 的树 | 拆不出来就用不了 | 先做问题结构图 |
| 2 | **同层元素相互独立** | C1 和 C2 之间不互相影响 | 权重重复计算、失真 | 改用 **ANP** |
| 3 | **偏好可传递（一致性）** | 若 A>B、B>C，则必须 A>C | 权重不可信、出现"循环偏好" | 重填矩阵，直到 CR<0.1 |
| 4 | **1–9 标度能表达差异** | 重要性差异可以量化成倍数 | 极端重要（10 倍以上）表达不了 | 用模糊 AHP 或直接给区间 |
| 5 | **判断者专业可信** | 打分的人懂这个领域 | 权重反映的是偏见 | 多人打分 + 几何平均聚合 |

### 数据条件

- **不需要原始数据**（这是它最大的优势，也是最大的软肋）；
- 指标/方案个数 **n ≤ 9**（RI 表只到 9；而且比较次数 `n(n−1)/2` 会爆炸：5 个指标 10 次，9 个指标 36 次）；
- 缺失值、量纲、异常值：**统统不用管**——它不碰原始数据。

### 适用边界

- ✅ 适合：指标少（≤7）、缺数据、需要"讲得清理由"的决策；
- ❌ 不适合：指标几十个（比较次数上千）、有大量客观数据、需要精确预测。

> **写作提示**：AHP 的"假设"一节是全篇最好写的——五条列成表，再补一句"本文判断矩阵 CR = 0.019 < 0.1，假设 3 成立"，评委立刻知道你真做了。

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **人不会直接给 5 个指标分权重，但很会回答"A 比 B 重要几倍"。AHP 把"定权重"这个大问题，拆成 `n(n−1)/2` 个"两两比大小"的小问题。**

### 为什么"特征向量"就是权重？

这是 AHP 唯一需要理解的数学，讲清这一句就够：

假设存在一组"真实权重" `w₁…wₙ`，而且人的判断完全准确，那么判断矩阵的元素应该满足

```
a_ij = w_i / w_j        （i 比 j 重要几倍 = 两者权重之比）
```

把整个矩阵乘上权重向量 `w`：

```
A · w = n · w
```

也就是说，**`w` 恰好是矩阵 A 的特征向量，特征值等于 n**。

现实中人打分不可能完全一致，所以 `A·w ≈ λmax·w`，且 `λmax` 略大于 n。
**`λmax` 偏离 n 多少，就代表人打得有多不一致** —— 这就是一致性指标 CI 的来历：

```
CI = (λmax − n) / (n − 1)
```

### 关键参数

| 参数 | 作用 | 取值 |
|---|---|---|
| **1–9 标度** | 把"重要几倍"变成数字 | 1 同等 / 3 稍重要 / 5 明显 / 7 强烈 / 9 极端，2/4/6/8 中间 |
| **判断矩阵 A** | 全部信息的载体 | 正互反矩阵，`a_ij = 1/a_ji` |
| **λmax** | 最大特征值 | 越接近 n 越一致 |
| **RI** | 随机一致性指标（查表，n 决定） | n=3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45 |
| **CR 阈值** | 判断"能不能用"的红线 | **CR < 0.1** |

### 目标函数 / 评价准则

没有"损失函数"，它的准则是两个：

1. **权重**：`A w = λmax w` 的解，归一化后即权重（或方根法近似）；
2. **一致性**：`CR = CI / RI < 0.1`。

### 可解释性：★★★★★

- 权重 = "这个指标相对其他指标的重要性占比"，一句话能讲给外行听；
- 总分可以**逐项拆开**："P1 赢在治理效果（贡献 0.294），输在成本"；
- 这是 AHP 相对神经网络最大的优势，也是论文里最好写的一段。

## 第四层：操作 —— 怎么跑起来

### 五步流程

```
① 建层次结构      目标层 → 准则层 → 方案层（画成树状图）
② 构造判断矩阵    准则之间两两比较；再对每个准则，方案两两比较
③ 算权重          特征值法（标准）/ 方根法（手算、Excel）
④ 一致性检验      CR < 0.1，不过就回去改矩阵
⑤ 层次总排序      准则权重 × 方案得分，加权求和 → 排名
```

### 每步的具体动作

| 步 | 做什么 | 输出 |
|---|---|---|
| ① | 把问题写成三层树；准则 4–7 个最合适 | 层次结构图 |
| ② | 用 1–9 标度填上三角，下三角取倒数 | 1 个 `n×n` + `k` 个 `m×m` 矩阵 |
| ③ | 方根法：每行连乘 → 开 n 次方 → 归一化 | 权重向量 |
| ④ | `λmax = mean((Aw)ᵢ/wᵢ)`，`CI=(λmax−n)/(n−1)`，`CR=CI/RI` | 一张检验表 |
| ⑤ | `总分 = Σ(准则权重 × 该准则下方案得分)` | 排名表 |

### 工具

| 工具 | 适合 | 说明 |
|---|---|---|
| **Python + numpy** | 比赛主力 | `np.linalg.eig` 一行出特征向量 |
| **Excel** | 现场手算 | 方根法：`=PRODUCT(行)^(1/n)` 再除总和 |
| MATLAB | A/B 题 | `[V,D]=eig(A)` |
| yaahp | 教学 | 图形化，比赛别用（不可复现） |

### 预处理

- **不需要标准化**（不碰原始数据，这是优点）；
- 唯一要做的"预处理"是**语义统一**：成本类指标要反过来问——不问"成本多高"，问"**成本低**有多重要"，保证所有准则都是"越大越好"。

### 结果怎么检验

| 检验 | 做法 | 通过标准 |
|---|---|---|
| 一致性检验 | 每个矩阵都算 CR | 全部 < 0.1 |
| 权重合理性 | 权重排序是否符合常识 | 能自圆其说 |
| 敏感性分析 | 扰动某个准则权重 ±20%，看排名是否翻转 | 排名不变 = 稳健 |
| 多人一致性 | 多个专家矩阵取几何平均再算 | 差异可接受 |

## 第五层：评价 —— 怎么判断它好不好

| 维度 | AHP 的表现 |
|---|---|
| **评价指标** | CR（判断质量）、权重合理性、排序稳定性；**没有 R²/AUC 这类"准确率"** |
| **和竞品比** | 基线 = 熵值法（客观）；进阶 = 组合赋权（AHP+熵值法，几何平均或线性加权） |
| **对异常值** | **不敏感**（不碰数据）——这是它相对熵值法/回归的巨大优势 |
| **对小样本** | 无所谓样本量，但**指标数不能多**（n≤9） |
| **对噪声** | 不适用（无数据） |
| **对主观判断** | **高度敏感**：换个人打分，权重就变 → 必须做敏感性分析 |
| **过拟合** | 不会（无训练过程、无参数可拟合） |

### 四条软肋（论文"模型评价"直接抄）

1. **主观性**：权重来自人的判断，不同专家结果不同；
2. **一致性难满足**：指标一多，人很难保持前后一致，反复重填很痛苦；
3. **规模受限**：`n(n−1)/2` 次比较，指标超过 7 个就不可行；
4. **忽略相关性**：默认准则独立，实际常常不是（如"治理效果"和"技术可行性"高度相关）。

### 怎么和竞品"公平比较"

比赛里最稳的写法是**同一套数据、两套权重、比排名**：

| 权重来源 | 排名结果 | 结论 |
|---|---|---|
| AHP（主观） | P1 > P2 > P3 | — |
| 熵值法（客观） | 若一致 | "主客观结论互相印证，稳健" |
| 组合权重（几何平均） | 若一致 | "综合权重下结论不变" |

> 三种权重排名一致 = 论文里一句"结论稳健"；不一致 = 一段"差异分析"，同样是加分项。

## 第六层：比赛 —— 怎么把它写进论文

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ❌ 很少 | 偏机理、微分方程 |
| B 离散/物理 | ⚠️ 偶尔 | 方案/材料优选时可用 |
| C 数据科学 | ✅ 常见（当环节） | 常作"客观数据 + 主观权重"的补充 |
| D 运筹/网络 | ✅ 偶尔 | 选址、资源配置、方案比选 |
| E 环境可持续 | ⭐ 主战场 | 环境风险评价、治理方案比选（数据往往不全） |
| F 政策 | ⭐⭐ 最主场 | 政策方案评估、战略决策、利益相关方权衡 |

### 三个典型场景

1. **E 题·光污染治理**：三个治理方案在"效果/成本/可行性/公众接受度"下比选（本文件案例）。
2. **F 题·政策方案优选**：多项政策在"公平/效率/成本/可执行性"下排序，且很多指标没有数据。
3. **C 题·供应商/选址**：客观数据算一部分指标，主观权重补另一部分，AHP + 熵权组合。

### 论文里怎么呈现（顺序照抄）

```
1. 层次结构图（树状图，必画，评委最爱）
2. 判断矩阵（表格，标注 1–9 标度含义）
3. 权重表 + 一致性检验表（λmax / CI / RI / CR，把 CR<0.1 加粗）
4. 层次总排序表（方案 × 准则 × 总分 × 名次）
5. 敏感性分析（权重扰动表 + 一句结论）
6. 结果图：总得分柱状图 + 各方案雷达图（说明赢在哪、输在哪）
```

### 局限性写法（可直接改）

> "AHP 的权重依赖专家主观判断，存在主观性；且默认同一层各准则相互独立，未考虑准则间的相关性。本文通过一致性检验（CR = 0.019 < 0.1）保证判断矩阵的自洽性，并通过 ±20% 权重扰动验证排序稳健；对于准则相关性问题，可进一步采用 ANP 或与熵权法组合形成主客观综合权重。"

### 可替代 / 可组合

| 组合 | 用途 |
|---|---|
| **AHP + 熵值法（组合权重）** | 最显深度：主观 + 客观，论文里必写一段"为什么要组合" |
| **AHP + TOPSIS** | 主观定权 + 排序（三件套第二种合体） |
| **AHP + 模糊综合评判** | 评价语是"优/良/中/差"时 |
| **AHP + 敏感性分析** | 任何 AHP 论文的标配，不做会被问"换个专家结论变不变" |

### 三个常见扣分点

1. **只给权重、不做一致性检验** → 直接判"模型不完整"；
2. **判断矩阵来源不明** → 必须写"由 3 位队员独立打分后几何平均"或"依据文献 XX 的相对重要性"；
3. **单用 AHP 就下结论** → 至少配一个客观方法交叉验证。

# 第二部分 · 案例（2023 MCM E 题风格：光污染治理方案比选）

## 一、题目背景

某城市夜间光污染严重（天空亮度上升、居民睡眠受扰、生态节律紊乱）。市政府有三个候选治理方案，需要选一个最优的推荐给决策者。

> 数据说明：判断矩阵为教学用构造（模拟 3 名队员独立打分后的几何平均），换成真实专家打分时**流程完全不变**。

### 层次结构

```
                 ┌──────────── 最优治理方案（目标层）
                 │
   ┌─────────┬───┴─────┬──────────────┐
 C1治理效果  C2实施成本  C3技术可行性   C4公众接受度   （准则层）
   │         │          │             │
   └─────────┴────┬─────┴─────────────┘
                  │
   ┌──────────────┼──────────────┐
  P1灯具改造     P2分区熄灯      P3智慧照明        （方案层）
  +遮光罩
```

### 符号说明

- `A` ＝ 准则层判断矩阵（4×4）；`A_C1 … A_C4` ＝ 各准则下方案层判断矩阵（3×3）
- `w` ＝ 准则权重向量；`W` ＝ 方案在 4 个准则下的得分矩阵（3×4）
- `λmax` ＝ 最大特征值；`CI` ＝ 一致性指标；`RI` ＝ 随机一致性指标；`CR` ＝ 一致性比率
- `S` ＝ 方案综合得分

### 三个方案与四个准则

| 方案 | 做法 | 直觉 |
|---|---|---|
| P1 灯具改造+遮光罩 | 换 LED、加全截光型灯罩 | 效果直接，但要花钱、要施工 |
| P2 分区限时熄灯 | 划暗夜保护区，商业区 23:00 后限亮 | 最省钱、最容易执行，但居民/商户反对 |
| P3 智慧照明+动态调光 | 传感器 + 按需调光 | 体验最好，但贵且技术复杂 |

| 准则 | 含义 | 越大越好？ |
|---|---|---|
| C1 治理效果 | 减少向上光通量的能力 | ✅ |
| C2 实施成本 | **成本越低越好** → 打分时问"成本低有多重要" | ✅（已翻转语义） |
| C3 技术可行性 | 落地难度、维护难度 | ✅ |
| C4 公众接受度 | 居民与商户的支持度 | ✅ |

---

## 二、完整计算流程（6 步）

### 第 1 步：构造准则层判断矩阵

读法：第 i 行第 j 列 = "第 i 个准则比第 j 个准则重要多少倍"。

|  | C1 治理效果 | C2 实施成本 | C3 技术可行性 | C4 公众接受度 |
|---|---|---|---|---|
| **C1 治理效果** | 1 | 3 | 4 | 5 |
| **C2 实施成本** | 1/3 | 1 | 2 | 3 |
| **C3 技术可行性** | 1/4 | 1/2 | 1 | 2 |
| **C4 公众接受度** | 1/5 | 1/3 | 1/2 | 1 |

**含义**：治理效果比成本"稍微偏明显重要"（3），比技术可行性"介于稍微和明显之间"（4），比公众接受度"明显重要"（5）。

### 第 2 步：方根法求权重

**每行连乘 → 开 4 次方（n=4）→ 归一化**

| 准则 | 行乘积 | 开 4 次方 `g` | 权重 `w = g/Σg` |
|---|---|---|---|
| C1 | 1×3×4×5 = 60 | 60^0.25 = **2.7832** | 2.7832/5.1069 = **0.5450** |
| C2 | (1/3)×1×2×3 = 2 | 2^0.25 = **1.1892** | 1.1892/5.1069 = **0.2329** |
| C3 | (1/4)×(1/2)×1×2 = 0.25 | 0.25^0.25 = **0.7071** | 0.7071/5.1069 = **0.1385** |
| C4 | (1/5)×(1/3)×(1/2)×1 = 0.0333 | 0.0333^0.25 = **0.4273** | 0.4273/5.1069 = **0.0837** |
| **合计** | | **Σg = 5.1069** | **1.0000** |

代入示例（C1）：`60^(1/4) = e^(ln60/4) = e^1.0236 = 2.7832`，再除以列和 5.1069。

> 用 numpy 的特征值法会得到 `[0.5462, 0.2323, 0.1377, 0.0838]`，与方根法差在小数点后第三位——**两种方法都对，手算用方根法，程序用特征值法**。

### 第 3 步：一致性检验（AHP 的灵魂，不能省）

先算 `A·w`，再逐行除以 `w`：

| 行 | `(Aw)ᵢ` 的计算 | `(Aw)ᵢ` | `(Aw)ᵢ / wᵢ` |
|---|---|---|---|
| C1 | 1×0.5450 + 3×0.2329 + 4×0.1385 + 5×0.0837 | 2.2162 | 4.0664 |
| C2 | 0.3333×0.5450 + 1×0.2329 + 2×0.1385 + 3×0.0837 | 0.9427 | 4.0475 |
| C3 | 0.25×0.5450 + 0.5×0.2329 + 1×0.1385 + 2×0.0837 | 0.5586 | 4.0332 |

## 四、完整 Python 代码

完整代码见同目录 `ahp_demo.py`（约 200 行，每段带中文注释）。核心只有三个函数：

```python
import numpy as np

RI = {3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24, 7: 1.32, 8: 1.41, 9: 1.45}

def 方根法(A):
    """每行连乘 → 开 n 次方 → 归一化（手算/Excel 同款）"""
    n = A.shape[0]
    g = np.prod(A, axis=1) ** (1.0 / n)
    return g / g.sum(), g

def 一致性检验(A, w):
    """λmax = mean((Aw)/w)，再算 CI、CR"""
    n = A.shape[0]
    lam = float(np.mean((A @ w) / w))
    CI = (lam - n) / (n - 1)
    return lam, CI, CI / RI[n]

# 层次总排序：方案矩阵(3×4) 乘 准则权重(4,)
总分 = W_方案 @ w_准则
```

> **只记三行**：`g = prod(A,axis=1)**(1/n)`、`lam = mean((A@w)/w)`、`总分 = W @ w`。

2. CR = 0.3 意味着什么？该怎么处理？
3. 队友说"我们有 20 个指标要做 AHP"，你怎么劝他？

<details>
<summary>参考答案</summary>

1. 如果判断完全准确，`a_ij = w_i/w_j`，那么 `A·w = n·w`——权重向量就是特征向量，特征值等于指标个数 n；现实中 λmax 略大于 n，偏离程度就是不一致程度。
2. 判断矩阵内部矛盾严重（人打分前言不搭后语），权重不可信；必须重填矩阵，或减少指标数、改成分组层次。
3. 20 个指标要比较 190 次，人做不到自洽，CR 必然爆表。应改成：先聚类/分组（4–6 个准则），组内用熵值法客观定权，组间用 AHP 主观定权。
