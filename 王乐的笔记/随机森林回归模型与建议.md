# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：**种很多棵"各看一部分数据、各看一部分特征"的决策树，让它们投票/取平均**，得到比单棵树稳得多的预测。

| 问题 | 回答 |
|---|---|
| 核心问题 | 给定一堆特征，预测一个连续值（或概率），且**不假设关系是线性的** |
| 输入 | `n × k` 表格数据（数值/类别都行），**有标签** |
| 输出 | 预测值（回归）/ 概率（分类）+ **特征重要性** + 偏依赖曲线 |
| 数据类型 | 表格型（structured data）的绝对王者 |
| 方法类别 | **机器学习 → 集成学习 → Bagging（并行式）** |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **单棵决策树** | 随机森林的"退化版" | 只需要一个能画出来给评委看的规则树 |
| **GBDT / XGBoost / LightGBM** | 串行 Boosting，通常更准 | 追求精度、肯花调参时间（比赛常用） |
| **线性/逻辑回归** | 线性基线 | 关系接近线性、样本少、要解释系数 |
| **SVM** | 核方法 | 中小样本、高维 |
| **KNN** | 最近邻 | 特征少、样本少 |
| **神经网络** | 万能逼近 | 图像/文本/超大样本 |

### 一句话选型

> **表格数据 + 关系非线性 + 要特征重要性 → 随机森林；追求极致精度 → GBDT；要解释系数 → 回归。**

## 第二层：假设 —— 它成立的前提

随机森林的假设**比线性回归少得多**，这是它最大的优势。

| # | 假设 | 含义 | 违反了会怎样 |
|---|---|---|---|
| 1 | **样本独立同分布** | 每行数据互不影响 | 时序/重复测量数据要特殊处理（否则泄漏） |
| 2 | **训练集与测试集同分布** | 未来和过去长得像 | 分布漂移后精度暴跌 |
| 3 | **特征包含足够信息** | 该有的变量都在 | 再强的模型也救不回来（垃圾进垃圾出） |
| 4 | **样本量足够** | 经验：≥ 几百行 | 小样本时极不稳定，重要性排序随机 |
| 5 | **树足够多** | 200–500 棵以上 | 太少则方差大、结果随机 |

### 它**不需要**的假设（相对线性回归的巨大优势）

- ❌ 不需要线性
- ❌ 不需要正态
- ❌ 不需要同方差
- ❌ 不需要特征独立（共线不影响预测精度，但会**摊薄重要性**）
- ❌ 不需要标准化（树只看大小顺序，不看绝对尺度）

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **不能外推** | 树只会在"见过的取值范围内"做平均 | 预测 2030 年（超出训练区间）只能输出历史最大值附近 |
| **对高基数特征有偏** | 不纯度重要性偏爱取值多的特征 | 重要性排序可能骗人 |
| **小样本不稳** | n < 200 时结果每次都不一样 | 结论不可复现 |
| **类别不平衡** | 99:1 的数据会全预测成多数类 | 要看 AUC/召回率，不能只看准确率 |
| **数据泄漏** | 特征里混进了"未来信息" | 交叉验证分数虚高，一上测试集就崩 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | ≥ 几百；k 可以很多（几十上百都行） |
| 缺失值 | **sklearn 的随机森林不吃 NaN**，要先填补（均值/中位数/模型插补） |
| 类别变量 | 要编码（One-Hot 或 有序编码） |
| 异常值 | 不敏感（树按顺序切分），但极端值仍会影响 |
| 量纲 | 不用管 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **单棵树容易"过拟合 + 方差大"；让很多棵各不相同的树取平均，方差就被平掉了。**

数学上：若 B 棵树的方差都是 σ²、两两相关系数 ρ，则平均后的方差是

```
ρσ² + (1−ρ)σ²/B
```

- 树越多（B↑）→ 第二项趋于 0；
- **树之间越不相关（ρ↓）→ 第一项越小**。

随机森林的两处"随机"就是为了把 ρ 压下去：

| 随机 | 怎么做 | 作用 |
|---|---|---|
| **样本随机（Bootstrap）** | 每棵树有放回抽 n 个样本（约 63% 不重复） | 让每棵树看到不同的数据 |
| **特征随机** | 每次分裂只从**随机 k 个特征**里挑最优（分类默认 √k，回归默认 k/3） | 防止所有树都盯着同一个强特征 |

### 单棵树怎么长

在每个节点，遍历候选特征和切分点，选让**不纯度下降最多**的那个：

- 回归用**方差（MSE）**：`MSE = (1/n)Σ(yᵢ − ȳ)²`
- 分类用**基尼系数**：`Gini = 1 − Σpⱼ²`

一直分到满足停止条件（最大深度 / 叶节点最少样本）。

### 关键超参数

| 超参数 | 控制什么 | 调大/调小的后果 | 常用范围 |
|---|---|---|---|
| `n_estimators` | 树的数量 | 越大越稳，但收益递减、耗时线性增长 | 200–1000 |
| `max_depth` | 树的最大深度 | 大→过拟合；小→欠拟合 | 4–20 或 None |
| `min_samples_leaf` | 叶节点最少样本 | **大→更平滑、概率估计更准**（本案例的关键） | 1–50 |
| `max_features` | 每次分裂考虑几个特征 | 小→更去相关、更稳；大→单树更强 | sqrt / 0.3–0.6 |
| `oob_score` | 是否算袋外评分 | 开了就有一份免费验证 | True |

### 可解释性：★★★☆☆（比线性弱，比神经网络强得多）

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **不纯度重要性** | 这个特征在分裂时贡献了多少 | ⚠️ 偏爱高基数特征，会虚高 |
| **置换重要性** | 打乱这一列，误差涨多少 | ✅ 推荐写进论文 |
| **偏依赖图 PDP** | 这个特征和预测值是什么形状的关系 | ✅ 论文里最好看 |
| **SHAP** | 每个样本、每个特征的贡献 | ✅ 最细，但计算贵 |

## 第四层：操作 —— 怎么跑起来

### 七步流程（速览）

```
① 数据准备     缺失值填补、类别编码、划分训练/测试
② 基线模型     线性回归（没有基线就没有"提升"）
③ 训练随机森林  先默认超参跑一遍
④ 调参         用 CV 分数驱动超参选择（GridSearch / RandomizedSearch 内部含 CV）
⑤ 检验         OOB 评分 · 测试集指标 · 学习曲线（三者各司其职，不混为一谈）
⑥ 解释         特征重要性 + 偏依赖图
⑦ 对比         与基线、与单棵树、与 GBDT 放进同一张表
```

> **两个定位提醒**（实操与论文写作最容易混的地方）：
> 1. **第④步不是"交叉验证调参"这个独立动作**——交叉验证是 `GridSearchCV` / `RandomizedSearchCV` **内部**用来评估候选超参好坏的手段，嵌在搜索器里，不是调参之后再"额外做一次"。
> 2. **第⑤步要拆成三个不同层次的数据**：OOB 是训练阶段的内部估计、测试集指标是最终泛化能力的唯一权威数字、学习曲线是诊断过拟合/欠拟合的工具。三者角色不同，不能当"一步"随意带过。

### 七步详解

#### ① 数据准备：产出可复现的训练/测试集

**要做的**：缺失值填补、类别编码、划分训练集与测试集。随机森林对缺失值和量纲不敏感，但类别特征必须转为数值；划分时建议用 `train_test_split` 固定 `random_state`，保证全组跑出来的数据划分完全一致。

**需要算出的数据**：
- 训练集/测试集的行数、列数（论文附表列出）
- 各特征缺失率（若过高，需说明填补策略及其合理性）
- 类别编码后的特征清单

**论文呈现**：一张"数据清洗前后对比表"，列明样本量变化、缺失填补方法、最终入模特征数。

#### ② 基线模型：确立"提升"的参照系

**要做的**：用线性回归（回归问题）在同一训练集上拟合、在同一测试集上评估。基线的意义是告诉评委：随机森林的增益是相对于一个最简单模型而言的，没有基线，"提升"就没有说服力。

**需要算出的数据**：
- 基线模型在测试集上的 R²、RMSE、MAE
- 若目标变量偏态严重，可补一个"均值预测基线"作为更弱的参照

**论文呈现**：基线指标写入最终对比表第一行，后续所有模型都与这一行对齐。

#### ③ 训练随机森林：先拿默认参数跑通

**要做的**：用 `RandomForestRegressor` 默认参数（或仅设定 `n_estimators=100`、固定 `random_state`）在训练集上拟合，得到第一个可用模型。这一步的目的是先建立一个性能参照，而不是追求最优。

**需要算出的数据**：
- 默认参数下的 OOB 分数（若开启 `oob_score=True`）
- 训练集和测试集上的初步 R²/RMSE，用于判断后续调参空间大小

> 不要在这一步花时间手动调参，默认参数跑通即可进入第④步。

#### ④ 调参：用交叉验证分数驱动超参数选择

**要做的**：对 `n_estimators`、`max_depth`、`min_samples_split`、`max_features` 等关键超参，用 `GridSearchCV` 或 `RandomizedSearchCV` **在训练集内部做交叉验证**（常用 5 折或 10 折），以负 MSE 或负 MAE 为 `scoring` 指标，选出 CV 分数最优的参数组合。

**需要算出的数据**：
- 最优超参组合（如 `n_estimators=300, max_depth=12, max_features='sqrt'`）
- 最优 CV 分数及其标准差（用于说明调参稳定性）
- GridSearch 可附"参数-分数"热力图或折线图；RandomizedSearch 列出搜索空间与采样次数即可

**论文呈现**：用小表列出"调参方法 / 搜索空间 / 最优参数 / 最优CV分数"，并一句话说明为什么选这个 scoring 指标（例如"以负MAE为准则，因其与题目关注的绝对误差尺度一致"）。

> 交叉验证不是第④步的"前置工序"，它就嵌在搜索器内部——`GridSearchCV(..., cv=5)` 里的 `cv` 就是那道交叉验证。

#### ⑤ 检验：OOB、测试集指标与学习曲线各司其职

拆成三个互不替代的产出：

**5a. OOB 评分**：开启 `oob_score=True` 得到袋外 R²。OOB 是每棵树对未抽中样本的预测汇总，相当于一次"免费内部验证"，用来佐证模型没有严重过拟合。

**5b. 测试集指标**：用调参后的最终模型，在从未参与训练和调参的测试集上计算 R²、RMSE、MAE。这是论文中报告"模型性能"的**唯一权威数字**，OOB 和 CV 分数都不能替代它。

**5c. 学习曲线**：以训练样本量为横轴、训练分数和交叉验证分数为纵轴画图。两线收敛且接近=良好拟合；训练高验证低且差距大=过拟合；两者都低=欠拟合。

**论文呈现**：OOB 分数正文一句话带过（"OOB R²=0.xx，与测试集表现一致"）；测试集指标入对比表；学习曲线作一张图配一句诊断结论。

#### ⑥ 解释：特征重要性与偏依赖图，让评委"看懂"模型

**要做的**：
- **特征重要性**：用 `feature_importances_` 得到每个特征对预测的贡献排序，筛出前 5–10 个关键特征（论文里建议改用 `permutation_importance` 替代不纯度重要性，见第六层说明）。
- **偏依赖图 PDP**：对最重要的 2–3 个特征，画出该特征取值变化时预测值的平均变化趋势。

**需要算出的数据**：特征重要性排序表（特征名 + 数值）；每个 PDP 对应的特征及其取值区间。

**论文呈现**：特征重要性用横向条形图，PDP 用折线图，每张图配一句结论（如"特征 X 在取值区间 [a, b] 内对预测呈正向边际效应"）。时间允许可补 SHAP 摘要图，但 PDP + 特征重要性已能满足美赛基本要求。

#### ⑦ 对比：用一张表把"提升"讲清楚

**要做的**：将基线模型、单棵决策树、调参后随机森林、GBDT（或 XGBoost）放在同一测试集上，用 R²、RMSE、MAE 三个指标并列对比。

**需要算出的数据**：四个模型 × 三个指标，共 12 个数值；可选：训练耗时（体现随机森林与 GBDT 的效率权衡）。

**论文呈现**：一张"模型 / R² / RMSE / MAE / 训练耗时"表，表下一两句话点明核心结论（如"调参后随机森林在 R² 上较基线提升 xx%，且稳定性优于单棵决策树"）。若 GBDT 更好不必回避，可说明"随机森林在可解释性和调参稳健性上占优"，这本身也是合理的选型理由。

> **实操提醒**：美赛只有几天，调参不值得追求极致。用同一套数据、最多三组配置跑完即可，重点是把指标算全、图表画清、结论写明。**固定 `random_state` 贯穿始终**，否则论文里的数字会对不上。

### 预处理清单

| 处理 | 要不要做 | 说明 |
|---|---|---|
| 标准化 | ❌ 不用 | 树只看大小顺序 |
| 缺失值填补 | ✅ 必须 | sklearn 的 RF 不接受 NaN |
| 类别编码 | ✅ 必须 | One-Hot / 有序编码 |
| 特征筛选 | ⚠️ 可选 | 特征太多时先筛，能提速 |
| 训练/测试划分 | ✅ 必须 | 时间序列要**按时间切**，不能随机切（否则泄漏） |

### 结果怎么检验

| 检验 | 指标 | 通过标准 |
|---|---|---|
| 袋外评分 | `oob_score_` | 与测试集接近 = 没泄漏 |
| 交叉验证 | R² / RMSE / Brier | 与训练集差距小 |
| 学习曲线 | 训练/验证误差曲线 | 两线收敛 = 数据够了；差距大 = 过拟合 |
| 重要性稳定性 | 多次训练排序是否一致 | 前几名稳定才算数 |

## 第五层：评价 —— 怎么判断它好不好

| 维度 | 表现 |
|---|---|
| **回归指标** | R²、RMSE、MAE、MAPE |
| **概率指标**（0/1 目标） | **Brier**、LogLoss、AUC、准确率 |
| **基线** | 线性回归 / 逻辑回归 / 单棵树 / 均值模型 |
| **对异常值** | 不敏感（这是优点） |
| **对噪声特征** | 不敏感（随机特征选择天然抗噪） |
| **小样本** | **很不稳**，重要性排序基本不可信 |
| **过拟合** | 中等风险：深树会记住噪声，但袋外样本 + 平均能缓解 |
| **防过拟合** | 限制 `max_depth` / 提高 `min_samples_leaf` / 增加树数 / 交叉验证 |
| **外推** | **不能用**（这是最大硬伤，写论文必须提） |

### 一条容易被忽略的规律

> **默认超参的随机森林，常常打不过调好参的逻辑回归。**
> 因为默认 `min_samples_leaf=1`，每个叶子只有 1 个样本，输出的"概率"非 0 即 1，校准极差。把叶节点样本数提到 20–50，Brier 会明显下降——本案例正是如此（0.1976 → 0.1867）。

## 第六层：比赛 —— 怎么把它写进论文

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 参数反演、代理模型 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐⭐ 主战场 | 表格数据预测 + 特征重要性 |
| D 运筹 | ⚠️ 偶尔 | 需求预测喂给优化 |
| **E 环境** | ⭐ 常见 | 多因子环境影响、风险分级 |
| **F 政策** | ⭐ 常见 | 政策效果异质性、影响因素排序 |

### 三个典型场景

1. **C 题·体育/行为预测**：逐分数据预测胜率，找出"势头"到底存不存在（本案例）。
2. **E 题·污染/灾害归因**：用气象、地理、人为因素预测 PM2.5，输出特征重要性排序。
3. **F 题·政策异质性**：哪些地区/人群对政策更敏感（随机森林 + 分组 PDP）。

### 论文呈现顺序

```
1. 特征表（含义、单位、来源）
2. 模型对比表（线性 / 逻辑 / 单树 / RF / RF调参）← 必须有
3. 调参过程（网格 + 交叉验证分数，证明不是拍脑袋）
4. 特征重要性条形图（置换重要性，别用不纯度）
5. 偏依赖图（讲清"关系长什么样"，这是 RF 唯一的解释窗口）
6. 学习曲线（证明没有过拟合）
```

### 局限性写法（可直接改）

> "随机森林不假设线性关系，能自动捕捉阈值与交互效应，但其预测值被限制在训练样本的取值范围内，**不具备外推能力**；同时特征重要性存在相关性摊薄与高基数偏差，本文采用置换重要性替代不纯度重要性以缓解该问题。模型在测试集上 Brier 为 0.187，较逻辑回归基线下降 1.9%，差距有限，说明本数据中线性结构已解释大部分变异；若关系更接近线性，应优先选择可解释性更强的逻辑回归。"

> 注意最后一句——**主动承认"提升有限"**，比硬吹"随机森林显著更优"更得分。

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **RF + 线性回归** | 线性基线 vs 非线性，最标准的"模型对比" |
| **RF 特征重要性 → 筛变量 → 回归** | 先用 RF 找重要变量，再用回归解释（两全其美） |
| **RF + SHAP** | 单样本级解释，E/F 题很出彩 |
| **RF + GBDT** | 集成方法内部的对比 |

### 三个常见扣分点

1. **只报准确率** → 类别不平衡时毫无意义，要报 AUC/Brier；
2. **用不纯度重要性下结论** → 高基数特征虚高，评委看得出来；
3. **声称"随机森林不需要假设"** → 它不能外推、要 iid，这两条必须写。

# 第二部分 · 案例（2024 MCM C 题风格：网球"势头"是否存在）

## 一、题目背景

网球解说常说"他现在起势了"。问题是：**势头（momentum）到底是不是真的存在？**

做法：用 5000 个逐分数据，预测"发球方赢下这一分"的概率，然后看：

1. 控制住发球速度、一发、回合长度、体能之后，**"势头"还有没有独立作用**？
2. 这个作用是什么形状（线性？还是有拐点）？
3. 用它预测比赛，比传统线性模型强多少？

> 数据说明：教学构造（5000 分 × 7 特征），关系里故意埋了阈值、交互、曲率三种非线性结构。换成真实的逐分数据（如 ATP 公开数据），流程一行不改。

### 变量说明

| 变量 | 含义 | 类型 | 预期方向 |
|---|---|---|---|
| `serve_kmh` | 发球速度 | 连续 | + |
| `first_serve` | 一发是否进区 | 0/1 | + |
| `rally_len` | 本回合拍数 | 计数 | − |
| `prev_won` | 上一分是否赢 | 0/1 | + |
| `momentum` | 势头指数（近 5 分加权） | 连续 −1.5~1.5 | + |
| `fatigue` | 体能消耗 | 0~1 | − |
| `is_clay` | 是否红土场 | 0/1 | ? |
| **`win`** | **本分是否赢（目标）** | **0/1** | — |

## 二、完整建模流程（7 步）

### 第 1 步：划分与基线

训练 3750 分 / 测试 1250 分，**分层抽样**保证两边胜率一致。

先建两个线性基线：

- **线性概率模型**（就是上一份文件的多元线性回归，只是 y 是 0/1）；
- **逻辑回归**（0/1 场景的正统方法）。

### 第 2 步：训练随机森林（默认超参）

`n_estimators=200`，其余全默认（`min_samples_leaf=1`）。

### 第 3 步：网格调参

5 折交叉验证，搜索空间：

```
n_estimators ∈ {200, 400}
max_depth    ∈ {None, 6}
min_samples_leaf ∈ {10, 30}
```

**最优**：`max_depth=6, min_samples_leaf=30, n_estimators=200`，交叉验证 Brier = **0.1903**。

> 注意最优解落在"树很浅、叶子很大"这一端——说明这份数据**不需要复杂的树**，需要的恰恰是"平滑的概率估计"。

### 第 4 步：袋外（OOB）评分

随机森林每棵树只用约 63% 的样本训练，剩下 37% 是"袋外样本"，相当于**自带一份免费验证集**。

```
OOB R² = 0.2388
```

> 0/1 目标上 R² 天然偏低（理论天花板也就 0.2–0.3），**别拿它跟连续变量的回归比**。

### 第 5 步：模型对比

| 模型 | Brier↓ | LogLoss↓ | AUC↑ | 准确率↑ |
|---|---|---|---|---|
| 线性回归（线性概率模型） | 0.1919 | 0.5685 | 0.7822 | 0.7176 |
| 逻辑回归 | 0.1904 | 0.5627 | 0.7826 | 0.7184 |
| 单棵决策树（深度 6） | 0.1972 | 0.6979 | 0.7709 | 0.7120 |
| 随机森林（默认超参） | 0.1976 | 0.5822 | 0.7673 | 0.6976 |
| **随机森林（调参后）** | **0.1867** | **0.5545** | **0.7891** | **0.7232** |

**三个必须讲出来的现象**：

1. **默认超参的 RF 输给了逻辑回归**（0.1976 vs 0.1904）——叶子只有 1 个样本，概率非 0 即 1，校准极差；
2. **调参后反超**（0.1867，Brier 降 1.9%，AUC 升 0.0065）——提升不大但方向一致；
3. **单棵树明显更差**（0.1972）——证明"集成"本身有价值，不是玄学。

> **诚实的结论**：这份数据的非线性结构不算极端，所以 RF 只领先一点点。如果关系更接近线性，逻辑回归会赢——**论文里要敢写这句话**。

### 第 6 步：特征重要性（两种口径）

| 特征 | 不纯度重要性 | 置换重要性 | 差异说明 |
|---|---|---|---|
| **momentum** | 0.6056 | **0.2849** | 都是第一，无争议 |
| prev_won | 0.1025 | 0.0766 | 一致 |
| rally_len | 0.1480 | 0.0659 | 不纯度偏高 |
| first_serve | 0.0386 | 0.0254 | 一致 |
| **fatigue** | 0.0630 | **0.0191** | **不纯度严重高估** |
| **serve_kmh** | 0.0389 | **0.0036** | **不纯度严重高估（10 倍）** |
| is_clay | 0.0035 | 0.0003 | 都不重要 |

**为什么要看两列**：不纯度重要性按"分裂次数 × 不纯度下降"累计，取值连续、切分点多的特征（如发球速度 160–235 有几十种切法）会被**系统性高估**。置换重要性直接问"打乱它，误差涨多少"，更接近"真的有用吗"。

> 论文里**只放置换重要性**，并在图注写明"permutation importance，10 次重复取均值"。

**实质结论**：控制住其他变量后，**势头是第一驱动**（置换重要性 0.285，是第二名的 3.7 倍）——"势头"在这份数据里是真实存在的。

### 第 7 步：偏依赖图（关系长什么样）

![随机森林：重要性 + 偏依赖 + 学习曲线](fig_rf_importance.png)

**三个图各说一件事**：

| 图 | 看到什么 | 结论 |
|---|---|---|
| 右上：momentum 的 PDP | 从 −0.7 到 +0.3 陡峭上升，之后**趋于平台** | 势头有作用，但**边际递减**，不是无限叠加 |
| 左下：rally_len 的 PDP | 1–7 拍平缓下降，**第 8 拍断崖式下跌**（0.51 → 0.19） | 典型**阈值效应**，线性模型永远学不到 |
| 右下：学习曲线 | 训练误差 0.182→0.175，验证误差 0.205→0.190，**两线接近且都在下降** | 没有过拟合；**加数据还能涨** |

> 这张左下角就是随机森林存在的意义：**"第 8 拍之后胜率腰斩"这种台阶，任何线性模型都表达不了。**

## 三、结果解读（论文结论段可直接用）

- 控制发球、回合、体能后，**势头对得分概率有显著且非线性的正向作用**（PDP 显示边际递减，拐点在 momentum ≈ 0.3）；
- 回合长度存在**阈值效应**：8 拍是分水岭，超过 8 拍后发球方胜率从 0.51 跌到 0.19；
- 随机森林调参后 Brier = 0.187、AUC = 0.789，**优于逻辑回归基线**（0.190 / 0.783）与单棵决策树（0.197 / 0.771）；
- 但提升幅度仅 1.9%，说明**线性结构已解释大部分变异**，"势头"的效应虽真实，却不是压倒性的。

**给教练的建议**（C 题必写的一段）：

> 训练重点应放在"把回合控制在 7 拍内"与"连续得分后的心理压制"，而非单纯提升发球速度——后者在置换重要性中几乎垫底（0.0036），说明在本数据中发球速度的边际价值远低于直觉。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 表格数据的非线性预测 + 特征重要性 |
| 核心思想？ | 很多棵"各看一部分数据、一部分特征"的树取平均，降方差 |
| 要什么假设？ | 只要 iid + 同分布；**不要**线性/正态/标准化 |
| 最大硬伤？ | **不能外推**；小样本不稳；重要性有偏 |
| 关键超参？ | `n_estimators`、`max_depth`、`min_samples_leaf` |
| 论文必写？ | 模型对比表 + 置换重要性 + 偏依赖图 + 学习曲线 |

## 自测三问

1. 随机森林和单棵决策树，差别到底在哪？为什么"多"就更好？
2. 为什么调参时最优解常常是"树很浅、叶子很大"？
3. 老板要你预测 2035 年的数据，模型训练样本只到 2024 年，随机森林能行吗？

<details>
<summary>参考答案</summary>

1. 单棵树方差大、对数据扰动极敏感；随机森林通过 bootstrap 抽样 + 随机特征子集让树之间"去相关"，再取平均，把方差项 `ρσ² + (1−ρ)σ²/B` 压下去。树越多、越不相关，平均越稳。
2. 因为叶子样本少时，叶子里的"胜率"只是个别样本的平均，噪声极大（概率非 0 即 1）。叶子样本多 → 概率估计被平滑 → Brier 更低。这不是欠拟合，而是**用偏差换方差**的正确取舍。
3. **不能**。树的预测值永远落在训练样本的取值范围内，对 2035 年这种超出范围的外推，它只会输出"历史最大值附近的平均值"。这种情况要用带趋势的模型（回归 + 时间项、ARIMA）或做情景外推。

</details>
