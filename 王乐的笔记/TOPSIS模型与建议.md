# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：给每个对象算"离**理想解**有多远、离**负理想解**有多远"，用两者的比值（贴近度 C）排出名次。

| 问题 | 回答 |
|---|---|
| 核心问题 | 权重已知时，这批对象谁最好、谁最差？ |
| 输入 | `n × m` 数值矩阵 + **一组权重 w**（外生：熵权/AHP/主观） |
| 输出 | 贴近度 `C ∈ [0,1]` + 排名 |
| 数据类型 | 表格型、连续数值；指标方向要能统一 |
| 方法类别 | 评价类 → **多属性决策（MADM）** → 距离型排序 |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **SAW（简单加权求和）** | 最直接：加权得分排序 | 指标体系"可补偿"且差距线性时可替代 |
| **熵权-TOPSIS** | 熵权定权重 + TOPSIS 排序 | 默认组合，最常用 |
| **AHP-TOPSIS** | 主观权重 + TOPSIS | 有专家、要体现偏好 |
| **VIKOR** | 折中排序，兼顾"群体效用"和"个体遗憾" | 想要"最不坏"的方案，而非"最接近理想" |
| **灰色关联** | 看曲线形状相似度 | 样本少、序列型指标 |
| **模糊综合评价** | 处理"好/较好/一般"这类定性等级 | 指标本身是语言变量 |

### 一句话选型

> **权重已经有了、指标可补偿、要一个 0–1 的排序分 → TOPSIS；只要加权总分 → SAW；要"最不坏" → VIKOR；指标是定性等级 → 模糊综合评价。**

## 第二层：假设 —— 它成立的前提

**一句话**：TOPSIS 的核心假设是"**好坏可以互相补偿**"——一项极强能补另一项极弱，这正是它和"一票否决"型方法的根本区别。

| # | 假设 | 含义（大白话） | 违反了会怎样 |
|---|---|---|---|
| 1 | **完全可补偿** | A 的短板可以被长板抵消 | 有"一票否决"指标时（如安全不达标），TOPSIS 会给出错误排名 |
| 2 | **指标单调** | 每个指标都是"越大越好"（已同向化） | 方向没统一，理想解取错 |
| 3 | **权重外生且可信** | 权重不是 TOPSIS 算的 | 权重错了，排名全错（TOPSIS 不纠错） |
| 4 | **距离有意义** | 归一化后各指标可比 | 不归一化，量纲大的指标垄断距离 |
| 5 | **指标数适度** | 一般 4–15 个 | 太多时"每个都差一点"会摊薄，C 挤在一起 |

### 它**不需要**的假设

- ❌ 不需要正态分布
- ❌ 不需要样本量很大（5 个对象也能排，但结论不稳）
- ❌ 不需要线性关系
- ❌ 不需要标签

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **补偿性** | 一项极强可掩盖一项极弱 | "偏科生"可能排到"均衡生"前面（与直觉相反时要想清楚） |
| **理想解由样本决定** | Z+ 取每列最大值 | 加一个离群点，基准就变了，全体排名可能变 |
| **C 是相对值** | 只在本次样本内有意义 | 不能跨批次比较，也不代表"得分率" |
| **对权重敏感** | 权重动 20%，排名可能翻转 | 必须做敏感性分析 |
| **丢掉"距离分布"信息** | 只用 D+ 与 D- 的比值 | 两个对象 C 相同但"错的方向"可能完全不同 |

### 数据条件

| 项 | 要求 |
|---|---|
| 对象数 | ≥3；5–30 最常见 |
| 指标数 | 4–15；太多先筛或降维 |
| 权重 | 必须给，且和为 1（熵权/AHP 均可） |
| 缺失值 | 先补，否则距离算不出 |
| 量纲 | 靠"平方和归一化"统一，不需要 min-max |
| 异常值 | 先处理：极值会成为理想解，影响全体 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **先造一个"完美对象"（每项都取最好）和一个"最差对象"（每项都取最差），谁离完美近、离最差远，谁就排前面。**

### 关键公式（六步）

```
① 正向化：极大型不变；极小型 x' = max − x
② 平方和归一化：z_ij = x'_ij / sqrt(Σ_i x'_ij²)       ← 分母是"列模长"
③ 加权：v_ij = z_ij × w_j
④ 理想解 / 负理想解：Z+_j = max_i v_ij ，Z−_j = min_i v_ij
⑤ 距离：D+_i = sqrt(Σ_j (v_ij − Z+_j)²)
        D−_i = sqrt(Σ_j (v_ij − Z−_j)²)
⑥ 贴近度：C_i = D−_i / (D+_i + D−_i)                   ← 0~1，越大越好
```

三句话读懂：

- **平方和归一化**把每列变成"单位向量"，消除了量纲，同时保留相对大小。
- **理想解**不是真实存在的对象，是"每项都拿第一"的虚拟点。
- **C 是"离最差有多远"占"总跨度"的比例**：C=1 表示就是理想解，C=0 表示就是最差点。

### 核心一步：平方和归一化

为什么不用 min-max？因为后面算的是**欧氏距离**：

- 距离要求各维度"同一把尺子"，平方和归一化后每列模长为 1，正好满足；
- min-max 会把值压到 0~1，最小值的对象在该维度贡献为 0，距离被"削平"，区分度下降。

> 一句话：**熵值法要"概率分布"所以用 min-max；TOPSIS 要"欧氏距离"所以用平方和归一化。** 这是两个方法最容易混的地方。

### 机制拆解

| 机制 | 怎么做 | 作用 |
|---|---|---|
| **正向化** | 负向指标 `max − x` | 统一成"越大越好" |
| **平方和归一化** | 除以列模长 | 去量纲、保留相对差异 |
| **加权** | 乘权重 | 让重要指标在距离里占更大分量 |
| **双基准** | 理想解 + 负理想解 | 同时看"好"和"差"两端 |
| **贴近度** | `D−/(D+ + D−)` | 把两个距离压成 0~1 的一个数 |

### 关键参数

| 参数 | 作用 | 取值 | 说明 |
|---|---|---|---|
| 权重 `w` | 决定每个维度在距离里的分量 | 和为 1 | 来自熵权/AHP，**不是 TOPSIS 自己算的** |
| 指标类型 | 正向化公式 | 极大/极小/中间/区间 | 标错方向，理想解取错 |
| 距离度量 | 欧氏（默认）/ 曼哈顿 / 马氏 | 欧氏最常用 | 马氏距离可处理相关性 |

> TOPSIS **没有需要"调"的超参数**——它的质量 90% 取决于权重和指标方向。

### 和 SAW（简单加权求和）的对照

| 环节 | SAW（熵值法最后一步） | TOPSIS |
|---|---|---|
| 打分方式 | `S = Σ w·x'` 直接加权 | 先算到理想解的距离，再算贴近度 |
| 对"偏科"的态度 | **不惩罚**：一项高就能拉分 | **惩罚**：短板会拉大 D+ |
| 结果范围 | 0~1 的加权和 | 0~1 的贴近度（含义不同） |
| 本案例差异 | D 排第 3、E 排第 4 | **E 排第 3、D 排第 4**（见案例第五节） |

### 可解释性：★★★☆☆

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **贴近度 C** | 综合排名 | ✅ 主结果 |
| **D+ / D− 对比图** | 它离"好"近还是离"差"近 | ✅ 解释 C 从哪来 |
| **权重敏感性** | 排名稳不稳 | ✅ 论文加分项 |
| **与 SAW 对比** | 换方法排名变不变 | ✅ 稳健性证据 |

## 第四层：操作 —— 怎么跑起来

### 七步流程（速览）

```
① 指标与权重     选指标、定方向、拿一组权重（熵权/AHP）
② 正向化         负向指标翻转成"越大越好"
③ 平方和归一化    每列除以列模长
④ 加权           乘权重 w
⑤ 理想解/负理想解 每列的最大 / 最小值
⑥ 距离与贴近度    D+、D−、C = D−/(D+ + D−)
⑦ 排序与敏感性    C 排序 + 权重扰动检验
```

### 七步详解

> 每一步给五样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**要画什么图**、**论文呈现**、**常见坑**。

#### ① 指标与权重：权重是"外来的"

**做什么（按顺序）**：

1. 定指标、定方向（同熵值法）。
2. **先拿到一组权重**：熵权（本例）、AHP、或组合赋权。
3. 校验 `Σw = 1`，并记录权重来源（论文必须写）。

```python
# 权重来自熵值法第 6 步
w = [0.2473, 0.1998, 0.2575, 0.2954]
assert abs(sum(w) - 1) < 1e-6
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 权重和 | `sum(w)` | 1.0000 |
| 最大/最小权重 | `max/min` | 0.2954 / 0.1998 |
| 权重来源 | 熵权 / AHP / 组合 | 熵值法（`..\熵值法\`） |

**要画什么图**：**权重条形图**（可与熵值法共用一张），或在附录给权重表。

**论文呈现**：一句话"权重由熵值法客观确定（见 5.2 节）"，并给权重表。

**常见坑**：
- 换一批数据却照抄旧权重：熵权随数据变，必须重算。
- 权重来源不写清，评委会怀疑是拍的。

#### ② 正向化：把所有指标变成"越大越好"

**做什么（按顺序）**：

1. 按指标类型套公式：极大型不变、极小型 `max − x`、中间型 `1 − |x−x*|/max|x−x*|`。
2. 检查正向化后是否全部非负、且方向一致。

```python
def positivize(X, positive):
    n, m = len(X), len(X[0])
    Xp = [[X[i][j] for j in range(m)] for i in range(n)]
    for j in range(m):
        if not positive[j]:
            mx = max(X[i][j] for i in range(n))
            for i in range(n):
                Xp[i][j] = mx - X[i][j]      # 极小型翻转
    return Xp
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 负向指标最大值 | `max` | PM2.5：62 |
| 翻转示例（A） | `62 − 45` | **17** |
| 翻转后列最小值 | — | B：0（原本最高 62） |

**要画什么图**：**正向化前后对比表**（不是图）；若指标多，画一张热力图看方向。

**论文呈现**：正向化公式 + 一句话"PM2.5 为极小型，按 max−x 翻转"。

**常见坑**：
- 用 `1/x` 翻转：数值分布被扭曲，且 0 值会炸。
- 中间型/区间型指标直接用极大型公式，基准全错。

#### ③ 平方和归一化：不是 min-max

**做什么（按顺序）**：

1. 每列求平方和、开根号（列模长）。
2. 每格除以列模长。

```python
import math
norm = [math.sqrt(sum(Xp[i][j] ** 2 for i in range(n))) for j in range(m)]
Z = [[Xp[i][j] / norm[j] for j in range(m)] for i in range(n)]
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 列平方和 | `Σ x'²` | 人均 GDP：615.65 |
| 列模长 | `sqrt(Σ x'²)` | 24.8123 |
| 归一化示例（A） | `12.5 / 24.8123` | **0.5038** |

**要画什么图**：不出图。

**论文呈现**：归一化公式 + 一张 z 矩阵（或放附录）。

**常见坑**：
- 习惯性用 min-max（因为熵值法刚用过），导致距离被压扁。
- 列模长为 0（整列全 0）：极罕见，但要防除零。

#### ④ 加权：乘上权重

**做什么（按顺序）**：

1. `v_ij = z_ij × w_j`。
2. 检查加权后每列的最大值出现在哪——那就是理想解。

```python
V = [[Z[i][j] * w[j] for j in range(m)] for i in range(n)]
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 加权值示例（A，人均 GDP） | `0.5038 × 0.2473` | **0.1246** |
| 加权后总和 | `Σ_j v_ij` | 不是 1，也不要求是 1 |

**要画什么图**：**加权矩阵热力图**（可选），看哪一列最"重"。

**论文呈现**：v 矩阵放附录；正文给理想解那一行就够。

**常见坑**：
- 权重没归一化（和≠1），距离尺度全变。
- 加权后再归一化一次，等于把权重抹掉。

#### ⑤ 理想解 / 负理想解

**做什么（按顺序）**：

1. 每列取最大值 → 理想解 Z+；取最小值 → 负理想解 Z−。
2. 检查 Z+ 是否等于某个真实对象（若等，说明这个对象四项全优）。

```python
Zp = [max(V[i][j] for i in range(n)) for j in range(m)]
Zn = [min(V[i][j] for i in range(n)) for j in range(m)]
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| Z+ | 各列最大 | 0.1515 / 0.0984 / 0.1930 / 0.1938 |
| Z− | 各列最小 | 0.0678 / 0.0780 / 0.0000 / 0.0831 |
| Z+ 来自哪个对象 | `argmax` | 人均、优良、PM2.5 都是 C；森林是 D |

**要画什么图**：**理想解/负理想解示意图**（可选）：每条指标画一条数轴，标出两个基准点。

**论文呈现**：一张 Z+/Z− 表（4 行 × 指标列）。

**常见坑**：
- 用原始数据取理想解（没加权/没归一化），量纲不同不能比。
- 负向指标忘了翻转，Z+ 会取到"污染最重"的对象。

#### ⑥ 距离与贴近度

**做什么（按顺序）**：

1. 算每个对象到 Z+、Z− 的欧氏距离。
2. `C = D− / (D+ + D−)`。
3. 检查 C 是否落在 0~1。

```python
Dp, Dn, C = [], [], []
for i in range(n):
    dp = math.sqrt(sum((V[i][j] - Zp[j]) ** 2 for j in range(m)))
    dn = math.sqrt(sum((V[i][j] - Zn[j]) ** 2 for j in range(m)))
    Dp.append(dp); Dn.append(dn); C.append(dn / (dp + dn))
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| D+（A） | `sqrt(Σ(v−Z+)²)` | **0.1272** |
| D−（A） | `sqrt(Σ(v−Z−)²)` | **0.1489** |
| C（A） | `0.1489/(0.1272+0.1489)` | **0.5392** |
| C 的范围 | — | 0.1441 ~ 0.7978 |

**要画什么图**：**D+ / D− 对比条形图**（必画，左右成对），一眼看出谁"离好近、离差远"。

**论文呈现**：D+/D−/C 表 + 双柱图；正文一句"C 越大越接近理想解"。

**常见坑**：
- 用曼哈顿距离却说欧氏（两者排序可能不同），方法要写清。
- 分母 `D+ + D−` 为 0（所有对象完全相同），除零。

#### ⑦ 排序与敏感性

**做什么（按顺序）**：

1. 按 C 降序排名。
2. 把某个权重 ±20% 重算，看排名是否翻转。
3. 与 SAW（熵值法加权得分）对比，解释差异。

```python
rank = sorted(range(n), key=lambda i: C[i], reverse=True)

def topsis_with(w2):
    V2 = [[Z[i][j] * w2[j] for j in range(m)] for i in range(n)]
    ... # 重算 Zp/Zn/D/C
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 排名 | `argsort(-C)` | C > A > E > D > B |
| 权重扰动 ±20% | 重算 C | 排名不变（本例） |
| 与 SAW 差异 | 两套排名对比 | D、E 互换 |

**要画什么图**：**贴近度排名条形图**（必画）+ **敏感性折线/热力图**（可选）。

**论文呈现**：排名表 + 条形图；正文说明"与熵值法加权得分相比，D/E 互换，原因是 TOPSIS 惩罚偏科"。

**常见坑**：
- 只报排名不报 C，读者看不出差距（C 0.80 vs 0.14）。
- 不做敏感性就说"结论稳健"。

## 第五层：评价 —— 怎么判断它好不好

**一句话**：TOPSIS 给的是"**相对**这次样本的相对位置"，不是绝对分数，也不是概率。

| 维度 | 表现 |
|---|---|
| **主指标** | 贴近度 C、排名稳定性 |
| **基线** | SAW（加权求和）、等权 TOPSIS、AHP-TOPSIS |
| **对异常值** | 较敏感（极值成为理想解） |
| **对权重** | **极敏感**（权重变了排名可能翻） |
| **对小样本** | 5 个对象能排，但结论脆 |
| **可解释性** | 中：能讲清"离理想多远"，讲不清"为什么这项权重高" |
| **外推** | 不能：C 只在本次样本内有意义 |

### 三条容易被忽略的规律

> **① C 不是"得分"，是"相对位置"。**
> C=0.54 不表示"得了 54 分"，只表示"离理想解的相对距离"。换一批对象，同一个对象的 C 会变。

> **② TOPSIS 会惩罚偏科，SAW 不会。**
> 本案例 D（森林覆盖第一、人均 GDP 垫底）在 SAW 里排第 3，在 TOPSIS 里掉到第 4；均衡型的 E 反超。这是**方法差异**，不是算错。

> **③ 理想解是"本批样本里的最好"，不是"理论最好"。**
> 加一个更优的对象，Z+ 会变，所有人的 C 都会变——所以不能跨批次比较。

## 第六层：比赛 —— 怎么把它写进论文

**一句话**：TOPSIS 在论文里通常和熵权一起出现，写成"**熵权-TOPSIS 综合评价模型**"，重点是权重来源 + 排名 + 稳健性。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 多方案比选 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐ 常见 | 多指标排名 |
| D 运筹 | ⭐ 常见 | 方案优选 |
| **E 环境** | ⭐⭐ 主战场 | 区域/城市综合评价（本例） |
| **F 政策** | ⭐⭐ 常见 | 政策效果、地区发展水平排序 |

### 三个典型场景

1. **E 题·区域综合评价**：熵权定权重 + TOPSIS 排序（本例的标准配置）。
2. **D 题·方案比选**：几个方案在成本/效果/风险下排序，权重可由 AHP 给。
3. **F 题·政策效果**：政策实施前后各算一次 C，看提升幅度。

### 论文呈现顺序

```
1. 指标表 + 权重来源（熵权/AHP，给权重表）
2. 正向化与归一化公式
3. 理想解 / 负理想解表
4. D+ / D− / C 表
5. 排名图（条形）
6. 敏感性分析 或 与 SAW 对比            ← 加分项
```

### 局限性写法（可直接改）

> "TOPSIS 以'到理想解的相对距离'排序，能同时考虑各指标的最优与最差状态；但它**假设指标之间完全可补偿**——某项极差可被其他项抵消，若存在'一票否决'型指标（如安全达标），结论会失真。此外，理想解与负理想解均由本批样本决定，新增或剔除对象会改变基准，故贴近度只在本次样本内可比，不能跨年份直接比较。本文权重由熵值法给出（见 5.2 节），并做了 ±20% 扰动检验，排名未发生翻转。"

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **熵权-TOPSIS** | 最标准的评价组合（本例） |
| **AHP-TOPSIS** | 主观权重 + 客观排序 |
| **熵权-AHP 组合 + TOPSIS** | 主客观结合，论文更稳 |
| **TOPSIS + 聚类** | 先排序再分档（高/中/低） |
| **VIKOR 替代** | 想要"最不坏"而非"最接近理想" |
| **模糊综合评价替代** | 指标是定性等级时 |

### 三个常见扣分点

1. **把 C 说成"得分/概率"** → 它是相对贴近度，不是百分比得分。
2. **权重来源不交代** → 评委第一句就问"权重哪来的"。
3. **不做敏感性** → 权重一动排名就翻，结论站不住。

# 第二部分 · 案例（5 城市可持续发展评价，承接熵值法）

> 逐行代入版见同目录 `TOPSIS案例.md`。

## 一、数据与权重

原始数据同熵值法案例（5 城市 × 4 指标），权重直接取熵值法结果：

```
w = [0.2473, 0.1998, 0.2575, 0.2954]
     人均GDP   优良率   PM2.5   森林覆盖
```

## 二、关键中间结果

**理想解 / 负理想解**（加权后）：

| | 人均 GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|
| Z+ | 0.1515 | 0.0984 | 0.1930 | 0.1938 |
| Z− | 0.0678 | 0.0780 | 0.0000 | 0.0831 |

**距离与贴近度**：

| 城市 | D+ | D− | C |
|---|---|---|---|
| A | 0.1272 | 0.1489 | 0.5392 |
| B | 0.2195 | 0.0370 | 0.1441 |
| C | 0.0554 | 0.2185 | **0.7978** |
| D | 0.1818 | 0.1156 | 0.3886 |
| E | 0.1421 | 0.1053 | 0.4256 |

**排名**：C > A > **E** > **D** > B。

![TOPSIS：距离与贴近度排名](fig_topsis_rank.png)

## 三、为什么 D 和 E 互换了

| 方法 | 排名 |
|---|---|
| 熵值法（加权求和 SAW） | C > A > **D** > **E** > B |
| TOPSIS | C > A > **E** > **D** > B |

- **D**：森林覆盖全场第一（0.1938），但人均 GDP 最低、PM2.5 很差——典型"偏科"；
- **E**：四项都居中，没有短板——"均衡型"。

TOPSIS 用**到理想解的直线距离**衡量，短板会显著拉大 D+，所以均衡的 E 反超偏科的 D。**这不是算错，是两种方法的价值取向不同**，写进论文就是很好的"方法对比/稳健性"素材。

## 四、结果解读

- C 排第一（0.7978）：三项最优、一项中游，D+ 只有 0.055（离理想解最近）；
- B 垫底（0.1441）：三项靠后，D+ 高达 0.2195；
- A 第二（0.5392）：没有明显短板，但也没有突出项；
- D 与 E 的差距（0.3886 vs 0.4256）主要来自"偏科惩罚"，与熵值法结论相反，正好说明要报告方法差异。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 权重已知时，按"离理想解的相对距离"排序 |
| 核心思想？ | 离完美越近、离最差越远 → C 越大 |
| 要什么假设？ | 指标可补偿、已正向化、权重可信、距离有意义 |
| 最大硬伤？ | 补偿性；理想解随样本变；C 不可跨批比 |
| 关键参数？ | 权重（外生）、指标方向、距离度量 |
| 论文必写？ | 权重来源 + Z± 表 + C 表 + 排名图 + 敏感性 |

## 自测三问

1. TOPSIS 为什么用平方和归一化，而不是像熵值法那样用 min-max？
2. 某个对象"森林覆盖第一，但人均 GDP 垫底"，你预计它在 TOPSIS 里排高还是排低？为什么？
3. C = 0.80 能不能说"这个城市得了 80 分"？

<details>
<summary>参考答案</summary>

1. TOPSIS 后面要算**欧氏距离**，各维度必须同一把尺子；平方和归一化让每列模长为 1，正好满足，而且保留了相对差异。min-max 会把最小值压成 0，距离被"削平"，区分度下降。熵值法要的是"概率分布"（非负、列和为 1），所以用 min-max。

2. 排低。TOPSIS 算的是到理想解的**距离**，短板会显著拉大 D+；一项极强只能缩小它自己那一维的距离，抵不过其他维度拉大的部分。这正是它和 SAW（加权求和）的区别，本案例 D 被 E 反超就是这个原因。

3. 不能。C 是"相对贴近度"：D−/(D+ + D−)。它只表示"在本次这批对象里，离理想解有多近"，换一批对象或换一组权重都会变。说成"80 分"会误导读者以为它是绝对评分。

</details>
