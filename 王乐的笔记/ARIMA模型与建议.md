# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：**只用这条曲线自己的历史，预测它接下来的走势。**

| 问题 | 回答 |
|---|---|
| 核心问题 | 一条时间序列，未来 h 期大概是多少？（不需要解释变量） |
| 输入 | 一条**等间隔**的时间序列 `y₁, y₂, …, y_T`（日/周/月/年） |
| 输出 | 未来 h 期预测值 + **置信区间** + 模型阶数 (p,d,q) |
| 数据类型 | 时序、连续、**无标签**（自监督：用过去预测未来） |
| 方法类别 | **统计模型** → 时间序列分析（线性、参数化） |

### 同类竞品

| 竞品 | 特点 | 什么时候换 |
|---|---|---|
| **指数平滑（Holt-Winters）** | 更简单，趋势+季节直接建模 | 只要"跟着走"，不想定阶 |
| **灰色 GM(1,1)** | 4–10 个点就能算 | 数据极少（<15） |
| **多元回归 / ARIMAX** | 有解释变量 | 有气象、政策等外生因素 |
| **Prophet** | 自动处理节假日、缺失 | 有节假日效应、数据脏 |
| **树模型 + 滞后特征** | 能抓非线性 | 样本多、关系非线性 |
| **LSTM / Transformer** | 万能 | 上万条数据 + GPU，比赛基本不划算 |

### 三条"该用它"的判据

1. 只有**一条**序列，没有靠谱的解释变量；
2. 序列有**趋势**或**周期**，且未来会延续；
3. 需要**区间预测**（ARIMA 天然给置信区间，这是相对树模型的优势）。

## 第二层：假设 —— 它成立的前提

| # | 假设 | 含义 | 违反了会怎样 | 怎么查 |
|---|---|---|---|---|
| 1 | **平稳性** | 差分 d 次后，均值/方差不随时间变 | 预测系统性偏移（越预测越离谱） | **ADF 检验** |
| 2 | **线性** | 未来是过去的**线性**组合 | 拐点抓不住 | 残差图、对比树模型 |
| 3 | **误差白噪声** | 模型榨干了所有信息 | 还有规律没提取，预测不够准 | **Ljung-Box 检验** |
| 4 | **参数时不变** | 过去的关系未来还成立 | 结构突变（疫情、政策）后崩盘 | 分段建模、滚动检验 |
| 5 | **等间隔、无缺失** | 日就是日，不能跳 | 频率错乱，周期项全废 | 补全/重采样 |
| 6 | **样本足够长** | 经验上 **n ≥ 50**（季节模型 ≥ 3 个周期） | 参数估不准，AIC 不可靠 | 看数据长度 |

### 什么时候会被违反

- **平稳性**：几乎所有经济/人口序列都不平稳（有趋势）→ 差分是标配；
- **参数时不变**：2020 年疫情把无数序列打断，这是 ARIMA 在真实数据上最大的坑；
- **白噪声**：定阶不足时残差还有自相关 → 看 ACF 还有没有峰。

### 数据条件

| 项 | 要求 |
|---|---|
| 长度 | 非季节 ≥ 50；季节模型 ≥ 3–4 个完整周期（周季节 → ≥ 21–28 天，月季节 → ≥ 36–48 月） |
| 间隔 | 严格等间隔；缺失要插值（线性/前值） |
| 异常值 | 敏感（一个离群点会污染差分），先识别再处理 |
| 量纲 | 不影响，但**取对数**常能让方差更稳（本案例就取了 log） |

### 适用边界

- ✅ 短期预测（1–2 个周期内）最靠谱，**预测越长，区间越宽、越不可信**；
- ❌ 不能解释"为什么"（没有因果）；
- ❌ 抓不住结构突变、政策拐点；
- ❌ 多条序列相互影响时，单变量 ARIMA 会漏信息（要 VAR）。

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **"明天 ≈ 今天 + 一点修正"** —— ARIMA 把序列拆成三部分：**自回归（看过去的值）、差分（去掉趋势）、移动平均（看过去的误差）**。

### 三个字母各管什么

| 字母 | 名称 | 管什么 | 直觉 |
|---|---|---|---|
| **AR(p)** | 自回归 | 用过去 **p 个观测值**预测现在 | "昨天高，今天大概也高" |
| **I(d)** | 差分 | 把不平稳变平稳，**d = 差分几次** | "减去趋势，只留下变化量" |
| **MA(q)** | 移动平均 | 用过去 **q 个预测误差**修正 | "上次预测高了，这次往下调一点" |

写成式子（以 ARIMA(1,1,1) 为例，`Δyₜ = yₜ − yₜ₋₁`）：

```
Δyₜ = c + φ₁·Δyₜ₋₁ + εₜ + θ₁·εₜ₋₁
       ↑        ↑              ↑
     漂移    AR 项(看昨天)    MA 项(看昨天的误差)
```

**SARIMA 多出来的一组括号** `(P,D,Q,s)`：在**季节尺度**上再做一次同样的操作，`s` 是周期长度（周数据 s=7，月数据 s=12）。本案例最终选的是 `SARIMA(1,1,1)(1,0,1,7)`，意思是：日尺度 1 阶自回归 + 1 阶差分 + 1 阶移动平均，外加 7 天周期的季节自回归和季节移动平均。

### 怎么定阶（不用背表，记两条）

| 图形 | 特征 | 含义 |
|---|---|---|
| **ACF**（自相关图） | 拖尾（慢慢衰减） | 需要 AR 项 |
| **ACF** | 在 q 阶后**截断**（突然掉到 0） | MA(q) |
| **PACF**（偏自相关图） | 在 p 阶后**截断** | AR(p) |
| **ACF 在 lag s、2s、3s 有峰** | 明显的周期 | 加季节项，周期 = s |

> **实战建议**：别死磕 ACF/PACF，**列几个候选、比 AIC** 更快更稳（本案例就是这么做的）。ACF/PACF 用来"看出有没有季节、大概几阶"就够了。

### 关键参数

| 参数 | 控制什么 | 怎么定 |
|---|---|---|
| p（AR 阶数） | 记住多少天的历史 | PACF / AIC |
| d（差分阶数） | 去趋势的力度 | **ADF 检验**（本案例 d=1） |
| q（MA 阶数） | 用多少过去的误差 | ACF / AIC |
| P, D, Q, s | 季节部分 | ACF 在 lag s 的峰 |
| 漂移项 c | 是否允许长期增长 | 有持续增长趋势时加 |

### 可解释性：★★☆☆☆

- 系数（φ、θ）本身不好讲成人话；
- 但**预测区间**很好讲："未来两周日活大概在 149 万到 200 万之间，置信度 95%"；
- 论文里别硬解释 φ=0.6 的含义，重点讲**预测效果 + 检验通过**。

## 第四层：操作 —— 怎么跑起来

### 七步流程（照这个顺序，不会乱）

```
① 画图           看趋势 / 季节 / 方差 / 异常点
② ADF 检验       平稳吗？不平就差分（d+1），再检验
③ 看 ACF/PACF    有没有季节？大概几阶？
④ 列候选模型     几个 (p,d,q) 和季节组合，比 AIC
⑤ 残差检验       Ljung-Box：p>0.05 才算榨干
⑥ 预测           点预测 + 95% 区间
⑦ 与基线对比     naive / seasonal naive，赢不了就白干
```

### 工具

| 工具 | 用途 |
|---|---|
| **statsmodels `SARIMAX`** | 比赛主力，`order=(p,d,q)`、`seasonal_order=(P,D,Q,s)` |
| `pmdarima.auto_arima` | 自动搜阶（省事，但要知道它在干嘛） |
| `statsmodels.tsa.stattools.adfuller` | ADF 平稳性检验 |
| `acorr_ljungbox` | 残差白噪声检验 |
| R 的 `forecast::auto.arima` | 同类工具，思路一样 |

### 预处理清单

| 处理 | 为什么 | 怎么做 |
|---|---|---|
| **取对数** | 增长型序列方差随水平放大 | `log(y)`，预测后 `exp` 回来 |
| **差分** | 去趋势 | `y.diff()`；交给模型内部做也行（设 d） |
| 缺失值 | ARIMA 不容缺失 | 线性插值 / 前值填充 |
| 异常值 | 会污染差分 | 3σ / IQR 识别后平滑或剔除 |
| 重采样 | 保证等间隔 | `resample('D').mean()` |

### 结果怎么检验

| 检验 | 通过标准 | 不过怎么办 |
|---|---|---|
| ADF（差分后） | p < 0.05 | 再差分一次（d+1），但别超过 2 |
| Ljung-Box（残差） | p > 0.05 | 加阶 / 加季节项 |
| 残差均值 | ≈ 0 | 检查是否漏了漂移项 |
| 预测误差 | 赢过 naive 基线 | 换模型（指数平滑/树模型） |
| 滚动预测 | 每期重新拟合，误差稳定 | 说明参数时变，需分段 |

## 第五层：评价 —— 怎么判断它好不好

| 维度 | 表现 |
|---|---|
| **拟合优度** | AIC / BIC（越小越好，**只在同一批数据上可比**） |
| **预测精度** | RMSE、MAE、**MAPE**（百分比，跨量级可比） |
| **基线** | naive（用最后一个值）、seasonal naive（用上周同一天）——**必须赢** |
| **区间质量** | 实际值落在 95% 区间内的比例应≈95% |
| **对异常值** | 敏感（差分会把异常放大成两个） |
| **对结构突变** | **非常敏感**，这是最大软肋 |
| **过拟合** | 会：p、q 越大参数越多，AIC/BIC 有惩罚，但样本短时仍会过拟合 |
| **防过拟合** | 限制阶数（p,q ≤ 3）、用 BIC、留出测试集、滚动验证 |

### 一条铁律

> **ARIMA 的预测如果打不过"上周同一天"，说明这条序列根本没有可提取的自相关结构，直接用 seasonal naive 更诚实。**

这句话写进论文的"模型对比"，评委会觉得你真懂。

## 第六层：比赛 —— 怎么把它写进论文

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 传感器时序、振动信号 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐⭐ 主战场 | 预测未来销量/人数/价格 |
| D 运筹 | ⚠️ 偶尔 | 需求预测喂给库存模型 |
| **E 环境** | ⭐ 常见 | PM2.5、气温、海平面、碳排放的短期预测 |
| **F 政策** | ⭐ 常见 | 人口、就业、医保支出的趋势外推 |

### 三个典型场景

1. **C 题·平台日活/销量预测**：Wordle 日参与人数、电商日订单（本案例）。
2. **E 题·空气质量**：某城市 PM2.5 日均值的未来 7 天预测，输出预警。
3. **F 题·人口/医保支出**：年度序列外推 10 年，注意区间会非常宽。

### 论文呈现顺序

```
1. 时序图（标出趋势、周期、异常点）
2. 平稳性检验表（ADF 统计量 + p 值，差分前后各一次）
3. ACF / PACF 图（说明为什么这么定阶）
4. 候选模型 AIC 对比表（≥4 个，显出你是"选"出来的，不是"猜"的）
5. 残差检验（Ljung-Box 的 Q 和 p，p>0.05 加粗）
6. 预测图（历史 + 预测 + 95% 区间，三条线）
7. 误差对比表（vs naive、vs seasonal naive）
```

### 局限性写法（可直接改）

> "ARIMA 假设序列在差分后平稳、且参数不随时间变化，因此对结构性突变（如政策调整、突发事件）较为敏感；同时它仅利用序列自身历史，无法纳入外生解释变量。本文通过 ADF 检验确定 d=1、以 AIC 在 6 个候选中定阶、并用 Ljung-Box 检验（p=0.68）确认残差为白噪声；14 天预测的 MAPE 为 2.1%，显著优于 seasonal naive 基线（15.2%）。若需纳入气象、政策等外生变量，可扩展为 ARIMAX。"

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **ARIMA + 回归（ARIMAX）** | 回归解释结构，ARIMA 处理残差自相关 |
| **ARIMA + 分解（STL）** | 先拆趋势/季节/残差，再分别建模 |
| **ARIMA + 树模型** | 用 ARIMA 抓线性趋势，树模型抓非线性残差 |
| **ARIMA + 情景分析** | 给不同政策情景下的预测区间，E/F 题很好用 |

### 三个常见扣分点

1. **不做平稳性检验直接建模** → 预测发散；
2. **只报一个模型、没有候选对比** → 显得是"套模板"；
3. **不跟 naive 基线比** → 无法证明模型有用。

# 第二部分 · 案例（2023 MCM C 题风格：Wordle 日活预测）

## 一、题目背景

某在线文字游戏每天出一道 5 字母单词题，玩家每天可玩一次。运营方想预测**未来两周的日参与人数**，用于安排服务器与广告投放。

数据是 120 天的日度序列（2022-01-03 起，周一为第 1 天）。

> 数据说明：教学构造（指数增长 + 周内周期 + 自相关噪声），保证流程可复现。换成真实的 Wordle 推文数/日活数据，**流程一行不改**。

### 符号说明

- `yₜ` ＝ 第 t 天参与人数；`log yₜ` ＝ 取对数后的序列（稳定方差）
- `Δ` ＝ 一阶差分算子，`Δyₜ = yₜ − yₜ₋₁`
- `p, d, q` ＝ 非季节部分的 AR 阶、差分阶、MA 阶
- `P, D, Q, s` ＝ 季节部分，`s = 7`（周）
- `h` ＝ 预测步长（本案例 h = 14）

### 数据（前 3 周，完整 120 天见代码）

| 日期 | 星期 | 参与人数 | 日期 | 星期 | 参与人数 |
|---|---|---|---|---|---|
| 2022-01-03 | 一 | 288,338 | 2022-01-13 | 四 | 336,452 |
| 2022-01-04 | 二 | 280,654 | 2022-01-14 | 五 | 355,045 |
| 2022-01-05 | 三 | 300,736 | 2022-01-15 | 六 | 403,644 |
| 2022-01-06 | 四 | 323,187 | 2022-01-16 | 日 | 419,807 |
| 2022-01-07 | 五 | 334,441 | 2022-01-17 | 一 | 379,204 |
| 2022-01-08 | 六 | 389,603 | 2022-01-18 | 二 | 371,350 |
| 2022-01-09 | 日 | 396,216 | 2022-01-19 | 三 | 373,387 |
| 2022-01-10 | 一 | 354,442 | 2022-01-20 | 四 | 394,841 |
| 2022-01-11 | 二 | 338,880 | 2022-01-21 | 五 | 388,213 |
| 2022-01-12 | 三 | 331,293 | 2022-01-22 | 六 | 436,302 |

**一眼能看出的三件事**：①整体在涨（趋势）；②周末明显高于工作日（周内周期）；③波动越来越大（方差随水平放大 → 该取对数）。

## 二、完整建模流程（7 步）

### 第 1 步：画图看形态

![ARIMA 四联图](fig_arima_forecast.png)

左上图：120 天从 28 万涨到 200 万，**强趋势 + 锯齿状周内周期**，典型的"不平稳 + 季节性"。

### 第 2 步：平稳性检验（ADF）

| 序列 | ADF 统计量 | p 值 | 5% 临界值 | 结论 |
|---|---|---|---|---|
| 原序列 `log y` | 0.148 | **0.9692** | −2.889 | **不平稳** ❌ |
| 一阶差分 `Δ log y` | −6.056 | **0.0000** | −2.889 | 平稳 ✅ |

**解读**：ADF 的 H0 是"存在单位根（不平稳）"。原序列 p=0.97 完全不能拒绝 → 必须差分；差分后 p≈0 → **d = 1**。

> 若差分后仍不平稳，就再差分一次（d=2），但 d>2 基本不用——过度差分会引入人为的负自相关。

### 第 3 步：看 ACF / PACF 定阶

右上图（差分后的 ACF）：
- lag 1 有显著负相关（−0.37），之后迅速衰减 → **q 取 1 就够**；
- **lag 7 = 0.619、lag 14、lag 21、lag 28 都有尖峰** → 强烈的 **7 天周期**，必须加季节项。

左下图（差分后的 PACF）：
- lag 1 后截断，lag 7 附近有负峰 → **p 取 1**，季节 P 取 1。

**初步判断**：`ARIMA(1,1,1)` + 季节 `(1,0,1,7)` 附近。

### 第 4 步：列候选、比 AIC

训练集取前 106 天，最后 14 天做测试（**绝对不能用测试集定阶**）。

| 模型 | AIC | BIC | 收敛 |
|---|---|---|---|
| ARIMA(0,1,1) | −240.41 | −235.14 | ✅ |
| ARIMA(1,1,1) | −240.52 | −232.62 | ✅ |
| ARIMA(2,1,1) | −249.82 | −239.28 | ✅ |
| ARIMA(2,1,2) | −244.67 | −231.55 | ✅ |
| ARIMA(1,1,1) + 漂移 | −242.16 | −231.62 | ✅ |
| SARIMA(1,1,1)(1,0,0,7) | −304.94 | −294.64 | ✅ |
| **SARIMA(1,1,1)(1,0,1,7)** | **−354.87** | **−342.04** | ✅ |
| SARIMA(1,1,1)(1,1,0,7) | −310.14 | −300.14 | ✅ |

**结论**：`SARIMA(1,1,1)(1,0,1,7)` 的 AIC 比次优模型低 **44**（AIC 差 >10 就是"决定性优势"）。

> **教学点**：只加非季节项，AIC 卡在 −240 上下；一旦加上 7 天周期，AIC 直接掉到 −354。**这就是"发现周期"的价值**——不做这一步，模型等于白建。

### 第 5 步：残差检验

| 检验 | 结果 | 判断 |
|---|---|---|
| Ljung-Box Q(10) | **7.440**，p = **0.6834** | 残差已是白噪声 ✅ |
| 残差均值 | +0.0033 | ≈0 ✅ |
| 残差标准差 | 0.0360（对数尺度，约 ±3.7%） | 与噪声量级一致 ✅ |

**解读**：p=0.68 远大于 0.05，说明**残差里已经没有可利用的规律**了，模型"榨干"了信息。

### 第 6 步：预测 14 天

## 四、完整 Python 代码

见同目录 `arima_demo.py`（约 190 行）。核心只有四行：

```python
from statsmodels.tsa.stattools import adfuller
from statsmodels.stats.diagnostic import acorr_ljungbox
import statsmodels.api as sm

adfuller(log_s)                              # ① 平稳性
m = sm.tsa.SARIMAX(train, order=(1,1,1),
                   seasonal_order=(1,0,1,7)).fit()   # ② 拟合
acorr_ljungbox(m.resid.iloc[14:], lags=[10])         # ③ 残差白噪声
m.get_forecast(14).conf_int()                        # ④ 预测区间
```

> `resid.iloc[14:]`：状态空间模型用"扩散初始化"，**开头十几个残差是启动瞬态**，不剔掉会把 Ljung-Box 拉爆（我第一次跑就踩了这个坑，p 从 0.68 变成 0.007）。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 用一条序列自己的历史预测未来 + 给区间 |
| 三个字母？ | AR 看过去的值、I 差分去趋势、MA 看过去的误差 |
| 怎么定 d？ | **ADF 检验**，不平稳就差分 |
| 怎么定 p、q？ | ACF/PACF 看形状 + AIC 比候选 |
| 怎么算合格？ | Ljung-Box p>0.05（残差白噪声）+ 赢过 seasonal naive |
| 最大软肋？ | 结构突变、不能解释因果、长期预测区间极宽 |
| 论文必画？ | 时序图 + ACF/PACF + 预测区间图 |

## 自测三问

1. ADF 的 p = 0.8，你会做什么？做完再检验还是不显著呢？
2. Ljung-Box 的 p = 0.001，说明什么？怎么修？
3. 预测 30 天后，置信区间宽得没意义，这正常吗？论文里该怎么写？

<details>
<summary>参考答案</summary>

1. p=0.8 不能拒绝"有单位根"→ 先做一阶差分；若差分后仍不显著，再差分一次（d=2）；还不行说明序列有结构突变或异方差，考虑分段建模或换模型（指数平滑/树模型）。
2. 残差还有自相关，模型没榨干信息 → 加阶（p 或 q +1）、加季节项、或检查是否漏了周期/异常值。
3. 正常。ARIMA 的预测方差随步长线性增长，30 天后区间必然很宽。论文里应**明确给出预测有效步长**（如"7 天内可信，14 天后仅供参考"），并配合滚动预测或情景分析，而不是硬报一个点值。

</details>
