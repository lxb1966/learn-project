# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：把"人脑子里的主观偏好"翻译成"一串可计算的权重"。

| 问题 | 回答 |
|---|---|
| 核心问题 | 多准则决策中，**指标没法量化、也没有可信数据**时，怎么定权重、怎么排序？ |
| 输入 | **判断矩阵**：专家/你自己对指标两两比较打的 1–9 分（不需要任何原始数据） |
| 输出 | 权重向量 `w`（和 = 1）+ 各方案综合得分与排名 + 一致性指标 CR |
| 数据类型 | 主观打分、离散、截面、**无标签** |
| 方法类别 | 评价体系（evaluation）下的**主观赋权法**，且**自带排序**能力 |

### 同类竞品

| 竞品 | 和 AHP 的差别 | 什么时候换它 |
|---|---|---|
| **熵值法** | 客观赋权，靠数据差异定权；AHP 靠人判断 | 有可靠数据时 |
| **CRITIC** | 客观，还考虑指标间相关性 | 指标强相关时 |
| **变异系数法** | 客观，最简单 | 赶时间 |
| **德尔菲法** | 只做专家打分聚合，没有一致性检验 | 只要意见不要权重 |
| **ANP** | 允许同层元素相互影响（AHP 假设独立） | 指标间有依赖 |
| **模糊综合评判** | 处理"好/较好/一般"这类模糊评价 | 评价语言是定性的 |
| **TOPSIS** | **只排序、不定权重**，权重是外部输入 | 权重已有，缺排序 |
| **BWM（最优最差法）** | 只需 2n−3 次比较，比 AHP 少一半 | 指标多、专家时间少 |

### 三条"该用它"的判据（考场速判）

1. **没有数据，或数据不可信**（政策、社会、战略类问题）；
2. 要决定的是**"重要性"**而不是"数值大小"；
3. 能找到一个**说得上话的专家**（评委、你自己扮演的决策者都行）。

> 反过来：有干净历史数据还硬用 AHP，会被批"主观代替数据"。

## 第二层：假设 —— 它成立的前提

| # | 核心假设 | 含义 | 违反了会怎样 | 补救 |
|---|---|---|---|---|
| 1 | **层次可分解** | 问题能拆成 目标→准则→方案 的树 | 拆不出来就用不了 | 先做问题结构图 |
| 2 | **同层元素相互独立** | C1 和 C2 之间不互相影响 | 权重重复计算、失真 | 改用 **ANP** |
| 3 | **偏好可传递（一致性）** | 若 A>B、B>C，则必须 A>C | 权重不可信、出现"循环偏好" | 重填矩阵，直到 CR<0.1 |
| 4 | **1–9 标度能表达差异** | 重要性差异可以量化成倍数 | 极端重要（10 倍以上）表达不了 | 用模糊 AHP 或直接给区间 |
| 5 | **判断者专业可信** | 打分的人懂这个领域 | 权重反映的是偏见 | 多人打分 + 几何平均聚合 |

### 数据条件

- **不需要原始数据**（这是它最大的优势，也是最大的软肋）；
- 指标/方案个数 **n ≤ 9**（RI 表只到 9；而且比较次数 `n(n−1)/2` 会爆炸：5 个指标 10 次，9 个指标 36 次）；
- 缺失值、量纲、异常值：**统统不用管**——它不碰原始数据。

### 适用边界

- ✅ 适合：指标少（≤7）、缺数据、需要"讲得清理由"的决策；
- ❌ 不适合：指标几十个（比较次数上千）、有大量客观数据、需要精确预测。

> **写作提示**：AHP 的"假设"一节是全篇最好写的——五条列成表，再补一句"本文判断矩阵 CR = 0.019 < 0.1，假设 3 成立"，评委立刻知道你真做了。

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **人不会直接给 5 个指标分权重，但很会回答"A 比 B 重要几倍"。AHP 把"定权重"这个大问题，拆成 `n(n−1)/2` 个"两两比大小"的小问题。**

### 为什么"特征向量"就是权重？

这是 AHP 唯一需要理解的数学，讲清这一句就够：

假设存在一组"真实权重" `w₁…wₙ`，而且人的判断完全准确，那么判断矩阵的元素应该满足

```
a_ij = w_i / w_j        （i 比 j 重要几倍 = 两者权重之比）
```

把整个矩阵乘上权重向量 `w`：

```
A · w = n · w
```

也就是说，**`w` 恰好是矩阵 A 的特征向量，特征值等于 n**。

现实中人打分不可能完全一致，所以 `A·w ≈ λmax·w`，且 `λmax` 略大于 n。
**`λmax` 偏离 n 多少，就代表人打得有多不一致** —— 这就是一致性指标 CI 的来历：

```
CI = (λmax − n) / (n − 1)
```

### 关键参数

| 参数 | 作用 | 取值 |
|---|---|---|
| **1–9 标度** | 把"重要几倍"变成数字 | 1 同等 / 3 稍重要 / 5 明显 / 7 强烈 / 9 极端，2/4/6/8 中间 |
| **判断矩阵 A** | 全部信息的载体 | 正互反矩阵，`a_ij = 1/a_ji` |
| **λmax** | 最大特征值 | 越接近 n 越一致 |
| **RI** | 随机一致性指标（查表，n 决定） | n=3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45 |
| **CR 阈值** | 判断"能不能用"的红线 | **CR < 0.1** |

### 目标函数 / 评价准则

没有"损失函数"，它的准则是两个：

1. **权重**：`A w = λmax w` 的解，归一化后即权重（或方根法近似）；
2. **一致性**：`CR = CI / RI < 0.1`。

### 可解释性：★★★★★

- 权重 = "这个指标相对其他指标的重要性占比"，一句话能讲给外行听；
- 总分可以**逐项拆开**："P1 赢在治理效果（贡献 0.294），输在成本"；
- 这是 AHP 相对神经网络最大的优势，也是论文里最好写的一段。

## 第四层：操作 —— 怎么跑起来

### 六步流程

```
① 建层次结构      目标层 → 准则层 → 方案层（画成树状图）
② 构造判断矩阵    准则之间两两比较；再对每个准则，方案两两比较
③ 算权重          特征值法（标准）/ 方根法（手算、Excel）
④ 一致性检验      CR < 0.1，不过就回去改矩阵
⑤ 层次总排序      准则权重 × 方案得分，加权求和 → 排名
⑥ 敏感性分析      扰动权重，看排名什么时候翻转
```

### 六步详解

> 每一步给五样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**要画什么图**、**论文呈现**、**常见坑**。
> 本案例是 2023 E 题风格：三个光污染治理方案（P1 灯具改造 / P2 分区限时 / P3 智慧照明）在四个准则下比选。

#### ① 建层次结构：把问题写成三层树

**做什么（按顺序）**：

1. 顶层写目标（唯一），中层写准则（4–7 个最合适），底层写方案（2–5 个）。
2. 每个准则要能**独立打分**，不要互相包含（"成本"和"预算"不能并列）。
3. 统一方向：所有准则都写成"越大越好"。成本类要反过来问——不问"成本多高"，问"**成本低**有多重要"。

```python
# 结构就是一个字典，后面构造矩阵时按它遍历
HIERARCHY = {
    '目标': '光污染治理方案比选',
    '准则': ['C1 治理效果', 'C2 实施成本(低)', 'C3 技术可行性', 'C4 公众接受度'],
    '方案': ['P1 灯具改造+遮光罩', 'P2 分区限时熄灯', 'P3 智慧照明'],
}
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 准则个数 n | `len(准则)` | 4 |
| 方案个数 m | `len(方案)` | 3 |
| 需要构造的矩阵数 | 1 个 n×n + n 个 m×m | 1 + 4 = **5 个** |
| 需要填的比较次数 | `n(n−1)/2` + `n·m(m−1)/2` | 6 + 4×3 = **18 次** |

**要画什么图**：**层次结构树状图**（必画）。三层，用方框和连线画；准则层标注"越大越好"的方向。

**论文呈现**：放正文第一张图，图注写清"目标—准则—方案"三层；准则后面标方向。

**常见坑**：
- 准则超过 7 个：判断矩阵 21 次以上比较，人脑填不出自洽的结果，CR 必炸。
- 准则之间语义重叠（"经济性"和"成本"），权重会被重复计算。
- 方案层要先确定，不能边算边加。

#### ② 构造判断矩阵：1–9 标度、上三角、倒数

**做什么（按顺序）**：

1. 用 1–9 标度填**上三角**（1 同等、3 稍重要、5 明显、7 强烈、9 极端；2/4/6/8 取中间）。
2. 下三角自动取倒数：`a_ji = 1 / a_ij`。
3. 对角线全为 1。
4. 每填一个数，问自己"反过来成不成立"，不自洽就改。

```python
import numpy as np

A = np.array([
    [1,   3,   4,   5],
    [1/3, 1,   2,   3],
    [1/4, 1/2, 1,   2],
    [1/5, 1/3, 1/2, 1],
])
assert np.allclose(A * A.T, 1)     # 检查互反性
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 矩阵阶数 | `A.shape` | 4×4 |
| 互反性检查 | `A[i,j]·A[j,i] = 1` | 全部通过 |
| 最大比值 | `A.max()` | 5（治理效果 vs 公众接受度） |

**要画什么图**：**判断矩阵热力图**（可选，附录）。颜色深浅=重要性倍数，一眼看出谁压谁。

**论文呈现**：正文给一张准则层矩阵表（4×4），方案层的 4 张矩阵放附录。

**常见坑**：
- 忘取下三角倒数，矩阵不对称，特征值直接算错。
- 用 1–9 以外的标度（比如 10、100），失去心理学依据，也没法查 RI 表。
- 为了"好看"把矩阵填成完全一致（`a_ij·a_jk = a_ik`），CR=0 反而不真实。

#### ③ 算权重：方根法（手算）或特征值法（程序）

**做什么（按顺序）**：

1. **方根法**：每行连乘 → 开 n 次方 → 归一化。手算、Excel 用这个。
2. **特征值法**：`np.linalg.eig(A)` 取最大特征值对应的特征向量，归一化。程序用这个。
3. 两种方法结果差在小数点后第三位，**都要会**，答辩时说得清区别。

```python
def weight_sqrt(A):
    g = np.prod(A, axis=1) ** (1 / A.shape[0])   # 行连乘后开 n 次方
    return g / g.sum()

def weight_eig(A):
    val, vec = np.linalg.eig(A)
    k = np.argmax(val.real)
    w = np.abs(vec[:, k].real)
    return w / w.sum(), val[k].real               # 同时返回 λmax
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 行乘积 | `np.prod(A, axis=1)` | 60 / 2 / 0.25 / 0.0333 |
| 开 n 次方 | `prod ** (1/n)` | 2.7832 / 1.1892 / 0.7071 / 0.4273 |
| 权重 | `g / g.sum()` | **0.5450 / 0.2329 / 0.1385 / 0.0837** |
| 特征值法结果 | 同上 | 0.5462 / 0.2323 / 0.1377 / 0.0838 |
| 权重和 | `w.sum()` | 1.0000（必须） |

**要画什么图**：**权重条形图**（必画），四个准则按权重大小排序，标数值。比表格直观。

**论文呈现**：权重表（准则 / 方根法 / 特征值法 / 差值）+ 一张条形图；正文说明"两种方法差在 0.002 以内"。

**常见坑**：
- 归一化前先开方，顺序反了结果全错。
- 只报一种方法，被问"为什么不用特征值法"会卡住。

#### ④ 一致性检验：AHP 的灵魂

**做什么（按顺序）**：

1. 算 `Aw`，逐行除 `w`，取平均得 λmax。
2. `CI = (λmax − n) / (n − 1)`。
3. 查 RI 表（n=1..9：0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45），`CR = CI / RI`。
4. CR < 0.1 通过；不过就回去改矩阵里最不自洽的那个数。

```python
RI = {1: 0, 2: 0, 3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24, 7: 1.32, 8: 1.41, 9: 1.45}

def consistency(A, w):
    n = len(w)
    lam = np.mean((A @ w) / w)          # λmax
    ci = (lam - n) / (n - 1)
    cr = ci / RI[n] if RI[n] else 0
    return lam, ci, cr
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| λmax | `mean((Aw)ᵢ / wᵢ)` | **4.0511** |
| CI | `(λmax − n)/(n − 1)` | **0.0170** |
| RI | 查表（n=4） | 0.90 |
| CR | `CI / RI` | **0.0189 < 0.1** ✅ |

**要画什么图**：不用画图，出一张**检验表**（λmax / CI / RI / CR / 结论）。5 个矩阵就 5 行。

**论文呈现**：一张检验表覆盖全部矩阵，正文一句"所有矩阵 CR < 0.1，最大 0.019"。

**常见坑**：
- 只算准则层，忘了方案层 4 个矩阵也要各自检验。
- RI 用错阶数（3 阶用 0.90），CR 立刻失真。
- CR 过了不代表判断合理，只是"自洽"；权重排序还要符合常识。

#### ⑤ 层次总排序：加权求和出排名

**做什么（按顺序）**：

1. 把每个准则下的方案权重排成矩阵 `W`（m×n）。
2. 总分 `S = W @ w_criteria`。
3. 排序，并检查 `ΣS = 1`（归一化的天然验证）。

```python
W = np.array([            # 行=方案，列=准则
    [0.5396, 0.3196, 0.2970, 0.3196],
    [0.2970, 0.5584, 0.5396, 0.1220],
    [0.1634, 0.1220, 0.1634, 0.5584],
])
S = W @ w_criteria        # w_criteria = [0.5450, 0.2329, 0.1385, 0.0837]
print(S, S.sum())         # 和必须为 1
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 总分 | `S_i = Σ_j w_j · W_ij` | P1 **0.4364** / P2 0.3768 / P3 0.1868 |
| 总和 | `S.sum()` | 1.0000 ✅ |
| 第一名领先幅度 | `S₁ − S₂` | 0.0596 |

**要画什么图**：**总排序条形图**（必画），三个方案按分数排序；可叠加"各准则贡献"的堆叠段，看清分数从哪来。

**论文呈现**：总排序表（方案 × 各准则得分 × 总分 × 名次）+ 堆叠条形图。

**常见坑**：
- 把方案权重直接相加（没乘准则权重），排名会全错。
- 总分不归一化就去比大小，虽然排名不变，但没法解释"0.44 意味着什么"。

#### ⑥ 敏感性分析：排名会不会翻

**做什么（按顺序）**：

1. 选一个准则，权重乘 `t`，其余按比例压缩保持和为 1。
2. `t` 从 0.5 扫到 1.5，每步重算总分与排名。
3. 找到排名翻转的临界 `t`，写进论文。

```python
def perturb(w, j, t):
    w2 = w.copy()
    w2[j] *= t
    return w2 / w2.sum()

for t in [0.5, 0.8, 1.0, 1.2, 1.5]:
    S2 = W @ perturb(w_criteria, 0, t)
    print(t, S2.argmax() + 1)      # 第几名
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 扰动后权重 | `w_j·t` 再归一化 | t=0.5 时 C1 从 0.545 → 0.35 |
| 扰动后排名 | `S.argmax()` | ±20% 内恒为 P1>P2>P3 |
| 翻转临界 t | 二分或扫描找第一处变化 | C1 降到 **0.54 倍**；C2 升到 **2.08 倍** |

**要画什么图**：**敏感性折线图**（横轴 t、纵轴总分，三条线），或"t × 排名"的热力图。图上标出翻转点。

**论文呈现**：一张敏感性表（准则 × t 取值 × 排名）+ 一句话结论"±20% 内排名不变"。

**常见坑**：
- 只扰动一个准则就说"稳健"——至少把权重最大的两个都扰动一遍。
- 扰动后不做归一化，权重和≠1，结果没意义。
- 翻转临界值很接近 1（比如 1.05），说明结论脆弱，必须如实写。

### 预处理

- **不需要标准化**（不碰原始数据，这是优点）；
- 唯一要做的"预处理"是**语义统一**：成本类指标要反过来问——不问"成本多高"，问"**成本低**有多重要"，保证所有准则都是"越大越好"。

### 结果怎么检验

| 检验 | 做法 | 通过标准 |
|---|---|---|
| 一致性检验 | 每个矩阵都算 CR | 全部 < 0.1 |
| 权重合理性 | 权重排序是否符合常识 | 能自圆其说 |
| 敏感性分析 | 扰动某个准则权重 ±20%，看排名是否翻转 | 排名不变 = 稳健 |
| 多人一致性 | 多个专家矩阵取几何平均再算 | 差异可接受 |

---

## 第五层：评价 —— 怎么判断它好不好

| 维度 | AHP 的表现 |
|---|---|
| **评价指标** | CR（判断质量）、权重合理性、排序稳定性；**没有 R²/AUC 这类"准确率"** |
| **和竞品比** | 基线 = 熵值法（客观）；进阶 = 组合赋权（AHP+熵值法，几何平均或线性加权） |
| **对异常值** | **不敏感**（不碰数据）——这是它相对熵值法/回归的巨大优势 |
| **对小样本** | 无所谓样本量，但**指标数不能多**（n≤9） |
| **对噪声** | 不适用（无数据） |
| **对主观判断** | **高度敏感**：换个人打分，权重就变 → 必须做敏感性分析 |
| **过拟合** | 不会（无训练过程、无参数可拟合） |

### 四条软肋（论文"模型评价"直接抄）

1. **主观性**：权重来自人的判断，不同专家结果不同；
2. **一致性难满足**：指标一多，人很难保持前后一致，反复重填很痛苦；
3. **规模受限**：`n(n−1)/2` 次比较，指标超过 7 个就不可行；
4. **忽略相关性**：默认准则独立，实际常常不是（如"治理效果"和"技术可行性"高度相关）。

### 怎么和竞品"公平比较"

比赛里最稳的写法是**同一套数据、两套权重、比排名**：

| 权重来源 | 排名结果 | 结论 |
|---|---|---|
| AHP（主观） | P1 > P2 > P3 | — |
| 熵值法（客观） | 若一致 | "主客观结论互相印证，稳健" |
| 组合权重（几何平均） | 若一致 | "综合权重下结论不变" |

> 三种权重排名一致 = 论文里一句"结论稳健"；不一致 = 一段"差异分析"，同样是加分项。

## 第六层：比赛 —— 怎么把它写进论文

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ❌ 很少 | 偏机理、微分方程 |
| B 离散/物理 | ⚠️ 偶尔 | 方案/材料优选时可用 |
| C 数据科学 | ✅ 常见（当环节） | 常作"客观数据 + 主观权重"的补充 |
| D 运筹/网络 | ✅ 偶尔 | 选址、资源配置、方案比选 |
| E 环境可持续 | ⭐ 主战场 | 环境风险评价、治理方案比选（数据往往不全） |
| F 政策 | ⭐⭐ 最主场 | 政策方案评估、战略决策、利益相关方权衡 |

### 三个典型场景

1. **E 题·光污染治理**：三个治理方案在"效果/成本/可行性/公众接受度"下比选（本文件案例）。
2. **F 题·政策方案优选**：多项政策在"公平/效率/成本/可执行性"下排序，且很多指标没有数据。
3. **C 题·供应商/选址**：客观数据算一部分指标，主观权重补另一部分，AHP + 熵权组合。

### 论文里怎么呈现（顺序照抄）

```
1. 层次结构图（树状图，必画，评委最爱）
2. 判断矩阵（表格，标注 1–9 标度含义）
3. 权重表 + 一致性检验表（λmax / CI / RI / CR，把 CR<0.1 加粗）
4. 层次总排序表（方案 × 准则 × 总分 × 名次）
5. 敏感性分析（权重扰动表 + 一句结论）
6. 结果图：总得分柱状图 + 各方案雷达图（说明赢在哪、输在哪）
```

### 局限性写法（可直接改）

> "AHP 的权重依赖专家主观判断，存在主观性；且默认同一层各准则相互独立，未考虑准则间的相关性。本文通过一致性检验（CR = 0.019 < 0.1）保证判断矩阵的自洽性，并通过 ±20% 权重扰动验证排序稳健；对于准则相关性问题，可进一步采用 ANP 或与熵权法组合形成主客观综合权重。"

### 可替代 / 可组合

| 组合 | 用途 |
|---|---|
| **AHP + 熵值法（组合权重）** | 最显深度：主观 + 客观，论文里必写一段"为什么要组合" |
| **AHP + TOPSIS** | 主观定权 + 排序（三件套第二种合体） |
| **AHP + 模糊综合评判** | 评价语是"优/良/中/差"时 |
| **AHP + 敏感性分析** | 任何 AHP 论文的标配，不做会被问"换个专家结论变不变" |

### 三个常见扣分点

1. **只给权重、不做一致性检验** → 直接判"模型不完整"；
2. **判断矩阵来源不明** → 必须写"由 3 位队员独立打分后几何平均"或"依据文献 XX 的相对重要性"；
3. **单用 AHP 就下结论** → 至少配一个客观方法交叉验证。

# 第二部分 · 案例（2023 MCM E 题风格：光污染治理方案比选）

## 一、题目背景

某城市夜间光污染严重（天空亮度上升、居民睡眠受扰、生态节律紊乱）。市政府有三个候选治理方案，需要选一个最优的推荐给决策者。

> 数据说明：判断矩阵为教学用构造（模拟 3 名队员独立打分后的几何平均），换成真实专家打分时**流程完全不变**。

### 层次结构

```
                 ┌──────────── 最优治理方案（目标层）
                 │
   ┌─────────┬───┴─────┬──────────────┐
 C1治理效果  C2实施成本  C3技术可行性   C4公众接受度   （准则层）
   │         │          │             │
   └─────────┴────┬─────┴─────────────┘
                  │
   ┌──────────────┼──────────────┐
  P1灯具改造     P2分区熄灯      P3智慧照明        （方案层）
  +遮光罩
```

### 符号说明

- `A` ＝ 准则层判断矩阵（4×4）；`A_C1 … A_C4` ＝ 各准则下方案层判断矩阵（3×3）
- `w` ＝ 准则权重向量；`W` ＝ 方案在 4 个准则下的得分矩阵（3×4）
- `λmax` ＝ 最大特征值；`CI` ＝ 一致性指标；`RI` ＝ 随机一致性指标；`CR` ＝ 一致性比率
- `S` ＝ 方案综合得分

### 三个方案与四个准则

| 方案 | 做法 | 直觉 |
|---|---|---|
| P1 灯具改造+遮光罩 | 换 LED、加全截光型灯罩 | 效果直接，但要花钱、要施工 |
| P2 分区限时熄灯 | 划暗夜保护区，商业区 23:00 后限亮 | 最省钱、最容易执行，但居民/商户反对 |
| P3 智慧照明+动态调光 | 传感器 + 按需调光 | 体验最好，但贵且技术复杂 |

| 准则 | 含义 | 越大越好？ |
|---|---|---|
| C1 治理效果 | 减少向上光通量的能力 | ✅ |
| C2 实施成本 | **成本越低越好** → 打分时问"成本低有多重要" | ✅（已翻转语义） |
| C3 技术可行性 | 落地难度、维护难度 | ✅ |
| C4 公众接受度 | 居民与商户的支持度 | ✅ |

## 二、完整计算流程（6 步）

### 第 1 步：构造准则层判断矩阵

读法：第 i 行第 j 列 = "第 i 个准则比第 j 个准则重要多少倍"。

|  | C1 治理效果 | C2 实施成本 | C3 技术可行性 | C4 公众接受度 |
|---|---|---|---|---|
| **C1 治理效果** | 1 | 3 | 4 | 5 |
| **C2 实施成本** | 1/3 | 1 | 2 | 3 |
| **C3 技术可行性** | 1/4 | 1/2 | 1 | 2 |
| **C4 公众接受度** | 1/5 | 1/3 | 1/2 | 1 |

**含义**：治理效果比成本"稍微偏明显重要"（3），比技术可行性"介于稍微和明显之间"（4），比公众接受度"明显重要"（5）。

### 第 2 步：方根法求权重

**每行连乘 → 开 4 次方（n=4）→ 归一化**

| 准则 | 行乘积 | 开 4 次方 `g` | 权重 `w = g/Σg` |
|---|---|---|---|
| C1 | 1×3×4×5 = 60 | 60^0.25 = **2.7832** | 2.7832/5.1069 = **0.5450** |
| C2 | (1/3)×1×2×3 = 2 | 2^0.25 = **1.1892** | 1.1892/5.1069 = **0.2329** |
| C3 | (1/4)×(1/2)×1×2 = 0.25 | 0.25^0.25 = **0.7071** | 0.7071/5.1069 = **0.1385** |
| C4 | (1/5)×(1/3)×(1/2)×1 = 0.0333 | 0.0333^0.25 = **0.4273** | 0.4273/5.1069 = **0.0837** |
| **合计** | | **Σg = 5.1069** | **1.0000** |

代入示例（C1）：`60^(1/4) = e^(ln60/4) = e^1.0236 = 2.7832`，再除以列和 5.1069。

> 用 numpy 的特征值法会得到 `[0.5462, 0.2323, 0.1377, 0.0838]`，与方根法差在小数点后第三位——**两种方法都对，手算用方根法，程序用特征值法**。

### 第 3 步：一致性检验（AHP 的灵魂，不能省）

先算 `A·w`，再逐行除以 `w`：

| 行 | `(Aw)ᵢ` 的计算 | `(Aw)ᵢ` | `(Aw)ᵢ / wᵢ` |
|---|---|---|---|
| C1 | 1×0.5450 + 3×0.2329 + 4×0.1385 + 5×0.0837 | 2.2162 | 4.0664 |
| C2 | 0.3333×0.5450 + 1×0.2329 + 2×0.1385 + 3×0.0837 | 0.9427 | 4.0475 |
| C3 | 0.25×0.5450 + 0.5×0.2329 + 1×0.1385 + 2×0.0837 | 0.5586 | 4.0332 |
| C4 | 0.20×0.5450 + 0.3333×0.2329 + 0.5×0.1385 + 1×0.0837 | 0.3396 | 4.0571 |

```
λmax = (4.0664 + 4.0475 + 4.0332 + 4.0571) / 4 = 4.0511
CI   = (4.0511 − 4) / (4 − 1) = 0.0170
CR   = 0.0170 / 0.90（n=4 查表 RI）= 0.0189 < 0.1   ✅ 通过
```

**解读**：CR 只有 0.019，说明这套判断非常自洽（离"完美一致"只差 1.9%）。

### 第 4 步：每个准则下的方案层判断矩阵

**C1 治理效果**（P1 直接挡住向上光，最有效）

| | P1 | P2 | P3 |
|---|---|---|---|
| P1 | 1 | 2 | 3 |
| P2 | 1/2 | 1 | 2 |
| P3 | 1/3 | 1/2 | 1 |

**C2 实施成本**（问"成本低谁更好" → P2 法规管制最省钱）

| | P1 | P2 | P3 |
|---|---|---|---|
| P1 | 1 | 1/2 | 3 |
| P2 | 2 | 1 | 4 |
| P3 | 1/3 | 1/4 | 1 |

**C3 技术可行性**（P2 只需发文件，最容易落地）

| | P1 | P2 | P3 |
|---|---|---|---|
| P1 | 1 | 1/2 | 2 |
| P2 | 2 | 1 | 3 |
| P3 | 1/2 | 1/3 | 1 |

**C4 公众接受度**（P3 能调光体验最好；P2 强制熄灯最招骂）

| | P1 | P2 | P3 |
|---|---|---|---|
| P1 | 1 | 3 | 1/2 |
| P2 | 1/3 | 1 | 1/4 |
| P3 | 2 | 4 | 1 |

四个矩阵的权重与检验结果：

| 准则 | P1 | P2 | P3 | λmax | CI | CR | 结论 |
|---|---|---|---|---|---|---|---|
| C1 治理效果 | 0.5396 | 0.2970 | 0.1634 | 3.0092 | 0.0046 | 0.0079 | 通过 |
| C2 实施成本 | 0.3196 | 0.5584 | 0.1220 | 3.0183 | 0.0091 | 0.0158 | 通过 |
| C3 技术可行性 | 0.2970 | 0.5396 | 0.1634 | 3.0092 | 0.0046 | 0.0079 | 通过 |
| C4 公众接受度 | 0.3196 | 0.1220 | 0.5584 | 3.0183 | 0.0091 | 0.0158 | 通过 |

> 四个 CR 全部远小于 0.1，判断矩阵可用。

### 第 5 步：层次总排序

```
S_i = Σ_j ( w_j × W_ij )        i = 方案，j = 准则
```

**代入示例（P1）**：

```
S_P1 = 0.5450×0.5396 + 0.2329×0.3196 + 0.1385×0.2970 + 0.0837×0.3196
     = 0.2941 + 0.0744 + 0.0411 + 0.0268
     = 0.4364
```

| 方案 | C1(0.5450) | C2(0.2329) | C3(0.1385) | C4(0.0837) | **总分 S** | 名次 |
|---|---|---|---|---|---|---|
| **P1 灯具改造+遮光罩** | 0.5396 | 0.3196 | 0.2970 | 0.3196 | **0.4364** | **1** |
| P2 分区限时熄灯 | 0.2970 | 0.5584 | 0.5396 | 0.1220 | 0.3768 | 2 |
| P3 智慧照明+动态调光 | 0.1634 | 0.1220 | 0.1634 | 0.5584 | 0.1868 | 3 |
| **合计** | | | | | **1.0000** | |

> 总分加起来 = 1，这是 AHP 的天然性质（权重归一化），也顺便验证了代码没错。

### 第 6 步：敏感性分析

把某个准则权重乘上倍数 `t`（其余按比例压缩，保持和为 1），看排名何时翻转：

| 准则 | t=0.5 | t=0.8 | t=1.0 | t=1.2 | t=1.5 | 翻转临界 |
|---|---|---|---|---|---|---|
| C1 治理效果 | 213 | 123 | 123 | 123 | 123 | 降到 **0.54 倍** |
| C2 实施成本 | 123 | 123 | 123 | 123 | 123 | 升到 **2.08 倍** |
| C3 技术可行性 | 123 | 123 | 123 | 123 | 123 | 升到 2.78 倍 |
| C4 公众接受度 | 123 | 123 | 123 | 123 | 123 | 不翻转 |

（`123` 表示 P1 第 1、P2 第 2、P3 第 3；`213` 表示 P1 第 2、P2 第 1、P3 第 3。）

**结论**：权重在 ±20% 内怎么扰动，排名都是 P1 > P2 > P3。只有把"治理效果"的权重砍到 0.54 倍（即从 0.545 砍到 0.29 左右），P2 才会反超——这意味着 P1 的领先是**真实存在但不算碾压**的，论文里必须这么诚实地写。

## 三、结果解读（论文"结论"段落可直接用）

**推荐 P1（灯具改造 + 全截光型灯罩）**，得分 0.436，领先第二名 P2 约 6 个百分点。

- **赢在哪**：治理效果权重最高（0.545），而 P1 在这项上得分 0.540，接近一半的领先来自这里；
- **输在哪**：成本（0.320，低于 P2 的 0.558），说明它不是"最便宜的方案"；
- **为什么 P3 垫底**：贵 + 技术复杂，两个准则都垫底，只有"公众接受度"第一，但这项权重仅 0.084，救不回来。

**政策建议**（美赛 E/F 题必写的一段）：

> 优先实施 P1 作为主体方案；对成本敏感的区域，用 P2 做补充（暗夜保护区）；P3 建议先在 1–2 个街区试点，待成本下降后再推广。

## 四、完整 Python 代码

完整代码见同目录 `ahp_demo.py`（约 200 行，每段带中文注释）。核心只有三个函数：

```python
import numpy as np

RI = {3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24, 7: 1.32, 8: 1.41, 9: 1.45}

def 方根法(A):
    """每行连乘 → 开 n 次方 → 归一化（手算/Excel 同款）"""
    n = A.shape[0]
    g = np.prod(A, axis=1) ** (1.0 / n)
    return g / g.sum(), g

def 一致性检验(A, w):
    """λmax = mean((Aw)/w)，再算 CI、CR"""
    n = A.shape[0]
    lam = float(np.mean((A @ w) / w))
    CI = (lam - n) / (n - 1)
    return lam, CI, CI / RI[n]

# 层次总排序：方案矩阵(3×4) 乘 准则权重(4,)
总分 = W_方案 @ w_准则
```

> **只记三行**：`g = prod(A,axis=1)**(1/n)`、`lam = mean((A@w)/w)`、`总分 = W @ w`。
