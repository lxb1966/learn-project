# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：看哪个指标在**样本之间差异最大**——差异越大，说明它越能把对象区分开，就给它越高的权重。

| 问题 | 回答 |
|---|---|
| 核心问题 | 多个指标评价同一批对象时，每个指标该占多少权重？ |
| 输入 | `n × m` 数值矩阵（n 个对象、m 个指标），**不需要标签、不需要专家打分** |
| 输出 | 每个指标的权重 `w`（和为 1）+ 综合得分 `S` + 排名 |
| 数据类型 | 表格型、连续数值；指标方向要能统一（同向化） |
| 方法类别 | 评价类 → **客观赋权**（信息熵 → 差异系数 → 权重） |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **AHP 层次分析法** | 主观赋权，靠专家两两比较 | 指标没法量化、要体现"决策者偏好" |
| **CRITIC 法** | 客观赋权，同时考虑"对比强度"和"冲突性" | 指标之间相关性差异大，熵权会重复计权 |
| **变异系数法** | 客观赋权，用标准差/均值 | 只想看离散程度、不想算熵 |
| **主成分分析** | 降维 + 赋权，权重来自方差贡献 | 指标高度相关、要压缩维度 |
| **等权法** | 最笨的基线 | 各指标确实同等重要，或数据太少 |

### 一句话选型

> **指标能算、方向能统一、又没有专家可问 → 熵值法；有专家、要体现偏好 → AHP；要同时考虑指标冲突 → CRITIC；指标高度相关 → 先 PCA 再赋权。**

## 第二层：假设 —— 它成立的前提

**一句话**：熵值法的假设很少，但有一条很硬——**它默认"差异 = 信息"**，而"差异大"不等于"更重要"。

| # | 假设 | 含义（大白话） | 违反了会怎样 |
|---|---|---|---|
| 1 | **指标可量化、可同向化** | 每个指标都能变成"越大越好"的数 | 方向没统一，权重算出来是反的 |
| 2 | **差异 = 信息** | 某指标在样本间越分散，越有区分力 | 一个"噪声指标"（随机波动大）会拿到高权重 |
| 3 | **样本能代表总体** | 这批对象就是你要评的那批 | 换一批样本，权重全变（案例里会演示） |
| 4 | **指标之间相对独立** | 不重复度量同一个维度 | 两个高度相关的指标会各自拿到一份权重，等于重复计权 |
| 5 | **数据非负、无零列** | 标准化后要算"比重 p" | 整列全相同（极差=0）时 p 无定义，权重崩 |

### 它**不需要**的假设

- ❌ 不需要专家打分（这是它相对 AHP 的最大优势）
- ❌ 不需要标签
- ❌ 不需要线性关系
- ❌ 不需要正态分布

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **权重 = 区分度，不是重要性** | 大家都差不多的指标，权重自然低 | 误删"权重低但业务重要"的指标 |
| **权重随样本变** | 换城市、换年份，权重全变 | 不同年份的得分不可直接比 |
| **对异常值敏感** | min-max 标准化由极值决定 | 一个离群点能把整列压扁 |
| **0 与负值难处理** | 比重 p 要非负、且列和不为 0 | 用平移或对数处理，处理不当会失真 |
| **重复计权** | 指标相关时各拿一份权重 | 综合得分被某个维度绑架 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | 至少 5 个对象；3 个以下极差没意义 |
| 指标数 | 4–15 个比较合适；太多先做相关筛选 |
| 缺失值 | 先补；补出来的值会改变极差，进而改权重 |
| 负值 | 标准化后必须非负（min-max 天然满足） |
| 量纲 | 必须标准化（否则极差被量纲绑架） |
| 异常值 | 先处理，否则极值主导权重 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **把每个指标看成一份"概率分布"：哪一列的数据越均匀，它的熵越大、能提供的信息越少，权重就该越小。**

### 关键公式（四个，够用）

```
① 标准化（同向化 + 压到 0~1）：
   正向：x' = (x − min) / (max − min)
   负向：x' = (max − x) / (max − min)

② 比重：p_ij = x'_ij / Σ_i x'_ij          （每列加起来 = 1）

③ 信息熵：e_j = −k · Σ_i p_ij · ln p_ij    ，k = 1 / ln(n)
   约定 p=0 时 p·ln p 记作 0

④ 差异系数与权重：d_j = 1 − e_j ，w_j = d_j / Σ_j d_j
```

三句话读懂：

- **p 是把一列变成"分布"**：5 个城市在人均 GDP 上的占比，加起来等于 1。
- **e 衡量"均匀程度"**：若 5 个城市完全平均（各 0.2），e = 1，一点信息都没有；越集中，e 越小。
- **w 与 e 反着来**：e 小 → d 大 → 权重大。

### 核心一步：算比重 p

这一步是熵值法的"命门"：

- p 必须**非负**（所以要先 min-max 压到 0~1，不能直接用原始值）；
- 每列 p 之和必须为 **1**（否则不是概率分布，熵没有意义）；
- **整列相同**时（极差=0），该列标准化后全 0，列和为 0，p 无法计算——这种指标直接删掉或赋 0 权重。

> 这也是"为什么不能跳过标准化直接算熵"的原因：原始数据带量纲、可能有负数，不构成概率分布。

### 机制拆解

| 机制 | 怎么做 | 作用 |
|---|---|---|
| **min-max 同向化** | 正负指标两套公式 | 既统一方向，又把值压到 0~1 |
| **比重化** | 除以列和 | 变成概率分布，才能算熵 |
| **信息熵** | `−kΣp ln p`，k=1/ln n | 度量"这列的分散程度" |
| **差异系数** | `1 − e` | 把"熵小"翻译成"权重大" |

### 关键参数

| 参数 | 作用 | 取值 | 说明 |
|---|---|---|---|
| `k` | 熵的归一化常数 | `1 / ln(n)` | n 是样本数，不是指标数 |
| 正向/负向标记 | 决定标准化用哪套公式 | 手工标注 | 标错方向，结论全反 |
| 平移量 ε | 处理 0 值的技巧 | 0.0001~0.01 | 加了会引入微小偏差，论文要说明 |

> 熵值法**没有需要"调"的超参数**——真正要决策的是"选哪些指标、方向怎么标、0 值怎么处理"。

### 和 AHP 的对照（评价类两兄弟）

| 环节 | AHP | 熵值法 |
|---|---|---|
| 权重来源 | 专家两两比较（1–9 标度） | 数据本身的离散程度 |
| 需要人吗 | 需要（主观） | 不需要（客观） |
| 一致性检验 | 必须 CR < 0.1 | 没有这一步，但要防重复计权 |
| 权重含义 | "决策者认为多重要" | "数据上多能区分" |
| 适合场景 | 指标难量化、要体现偏好 | 数据齐、指标客观 |

### 可解释性：★★★☆☆

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **权重条形图** | 谁被数据"认为"更重要 | ✅ 主结果 |
| **信息熵表** | 每列的均匀程度 | ✅ 解释权重从哪来 |
| **敏感性分析** | 权重扰动后排名变不变 | ✅ 论文加分项 |
| **与 AHP 权重对比** | 主观 vs 客观差多少 | ✅ 组合赋权的依据 |

## 第四层：操作 —— 怎么跑起来

### 七步流程（速览）

```
① 建指标体系     选指标、标方向（正向/负向/区间）
② 同向化标准化   min-max，负向指标翻转
③ 算比重 p       每列除以列和
④ 算信息熵 e      e = −k Σ p ln p，k = 1/ln(n)
⑤ 算差异系数 d    d = 1 − e
⑥ 算权重 w        w = d / Σd
⑦ 综合得分与排序  S = Σ(w × x')，排序 + 解读
```

### 七步详解

> 每一步给五样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**要画什么图**、**论文呈现**、**常见坑**。

#### ① 建指标体系：选指标、标方向

**做什么（按顺序）**：

1. 确定评价对象（本例 5 个城市）和指标（本例 4 个）。
2. 给每个指标标方向：越大越好（正向）、越小越好（负向）、越接近某值越好（中间型）。
3. 检查指标之间是否高度相关——相关 >0.8 的两个指标，考虑合并或删一个。

```python
cities = ['A', 'B', 'C', 'D', 'E']
col_names = ['人均GDP', '优良率', 'PM2.5', '森林覆盖']
X = [[12.5, 78, 45, 18],
     [8.6,  65, 62, 25],
     [15.2, 82, 38, 30],
     [6.8,  71, 58, 42],
     [10.4, 75, 50, 22]]
positive = [True, True, False, True]      # PM2.5 是负向
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 对象数 n | `len(X)` | 5 |
| 指标数 m | `len(X[0])` | 4 |
| 正/负向个数 | 数 `positive` | 3 正 / 1 负 |
| 指标间最大相关 | `np.corrcoef(X.T)` | 本例未做，指标独立 |

**要画什么图**：**指标方向示意图**（可选）：一列指标名 + 箭头（↑/↓），论文里用一张小表代替也可以。

**论文呈现**：指标表（指标 / 单位 / 方向 / 数据来源）。

**常见坑**：
- 方向标错（把 PM2.5 当正向），排名直接反过来。
- 指标太多（>15）且高度相关，等于同一维度被计权多次。

#### ② 同向化标准化：min-max

**做什么（按顺序）**：

1. 每列求 min、max。
2. 正向：`(x − min)/(max − min)`；负向：`(max − x)/(max − min)`。
3. 检查是否所有值落在 0~1，且每列至少有一个 0、一个 1。

```python
min_j = [min(X[i][j] for i in range(n)) for j in range(m)]
max_j = [max(X[i][j] for i in range(n)) for j in range(m)]

X_std = [[0.0] * m for _ in range(n)]
for j in range(m):
    span = max_j[j] - min_j[j] or 1e-12        # 防整列相同
    for i in range(n):
        X_std[i][j] = ((X[i][j] - min_j[j]) if positive[j]
                       else (max_j[j] - X[i][j])) / span
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 每列 min / max | `min()`、`max()` | 人均 GDP：6.8 / 15.2 |
| 极差 | `max − min` | 8.4 |
| 标准化值示例 | `(12.5−6.8)/8.4` | **0.6786** |
| 负向示例（A 的 PM2.5） | `(62−45)/(62−38)` | **0.7083** |

**要画什么图**：**标准化前后箱线图**（可选），看分布是否被压扁。

**论文呈现**：标准化公式 + 一张"标准化后矩阵"表（本例 5×4）。

**常见坑**：
- 整列数值相同：极差=0，除零；该指标无区分力，直接删。
- 用 z-score 代替 min-max：会出现负值，后面的比重与熵全部失效。

#### ③ 算比重 p

**做什么（按顺序）**：

1. 求每列总和。
2. 每格除以所在列的总和。
3. 验证每列加起来等于 1。

```python
col_sum = [sum(X_std[i][j] for i in range(n)) for j in range(m)]
P = [[X_std[i][j] / col_sum[j] for j in range(m)] for i in range(n)]
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 列和 | `Σ_i x'_ij` | 人均 GDP：2.3214 |
| 比重示例 | `0.6786 / 2.3214` | **0.2923** |
| 列和校验 | `Σ_i p_ij` | 1.0000（每列） |

**要画什么图**：不出图（表即可）。

**论文呈现**：比重矩阵表，或直接跳过、在附录给。

**常见坑**：
- 列和为 0（整列标准化后全 0）→ 除零。
- 有人用"原始值/列和"算 p，必须用**标准化后**的值。

#### ④ 算信息熵 e

**做什么（按顺序）**：

1. 算常数 `k = 1/ln(n)`。
2. 每列算 `Σ p·ln p`（p=0 的项记 0）。
3. 乘 `−k` 得 e。

```python
import math
k = 1 / math.log(n)
e = []
for j in range(m):
    s = sum(P[i][j] * math.log(P[i][j]) for i in range(n) if P[i][j] > 0)
    e.append(-k * s)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| k | `1/ln(5)` | **0.6213** |
| Σp ln p（人均 GDP） | 见案例逐行 | −1.2542 |
| e（人均 GDP） | `−0.6213 × (−1.2542)` | **0.7792** |
| 四个指标的 e | 同上 | 0.7792 / 0.8217 / 0.7701 / 0.7363 |

**要画什么图**：**信息熵条形图**（左半张图），按 e 升序，直观看出谁最"均匀"。

**论文呈现**：e 表 + 一句"优良率熵最大（0.8217），说明城市间差别最小"。

**常见坑**：
- `math.log(0)` 会报错，必须先判 p>0。
- n 用错（把指标数当样本数），k 就错了。

#### ⑤ 算差异系数 d

**做什么（按顺序）**：

1. `d = 1 − e`。
2. 检查 d 是否都为正（e ∈ [0,1]，所以 d ∈ [0,1]）。

```python
d = [1 - e[j] for j in range(m)]
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| d | `1 − e` | 0.2208 / 0.1783 / 0.2299 / 0.2637 |
| Σd | `sum(d)` | **0.8927** |

**要画什么图**：与 e 画在同一张双子图里（熵 vs 差异系数），看两者镜像关系。

**论文呈现**：d 表（通常与 e 合并成一张表）。

**常见坑**：
- d 全都很小（数据太均匀），说明这批对象本来就难分高下，结论要谨慎。

#### ⑥ 算权重 w

**做什么（按顺序）**：

1. `w = d / Σd`。
2. 校验 `Σw = 1`。
3. 按权重排序，看哪个指标最高、是否符合业务直觉。

```python
w = [d[j] / sum(d) for j in range(m)]
print(sum(w))     # 必须 = 1
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 权重 | `d_j / Σd` | **0.2473 / 0.1998 / 0.2575 / 0.2954** |
| 最大权重 | `argmax` | 森林覆盖 0.2954 |
| 最小权重 | `argmin` | 优良率 0.1998 |

**要画什么图**：**权重条形图**（右半张图），降序排、标数值。这是论文里最该放的一张。

**论文呈现**：权重表 + 条形图；正文一句"森林覆盖权重最高，因为 5 城市间跨度最大（18%→42%）"。

**常见坑**：
- 把权重解读成"重要性"：它只是"区分度"。优良率权重最低，不代表它不重要。
- 权重不该人为改：改了就不是熵权法了。

#### ⑦ 综合得分与排序

**做什么（按顺序）**：

1. `S_i = Σ_j w_j · x'_ij`。
2. 按 S 降序排名。
3. 结合指标解释"为什么它第一"。

```python
scores = [sum(w[j] * X_std[i][j] for j in range(m)) for i in range(n)]
rank = sorted(range(n), key=lambda i: scores[i], reverse=True)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 综合得分 | `Σ w_j x'_ij` | A 0.5030 / B 0.1392 / C **0.8523** / D 0.4088 / E 0.4015 |
| 排名 | `argsort(-S)` | C > A > D > E > B |
| 首末差距 | `S_max − S_min` | 0.7131 |

**要画什么图**：**得分排名条形图**（必画），或雷达图（对象少时）。

**论文呈现**：排名表 + 条形图；正文 2–3 句解释"C 为什么第一、B 为什么垫底"。

**常见坑**：
- 得分只在本批对象内有意义，不能跨年份/跨批次比。
- 只报排名不报得分，读者看不出差距大小（C 0.85 vs B 0.14 是天壤之别）。

## 第五层：评价 —— 怎么判断它好不好

**一句话**：熵值法给出的权重是"数据说话"的结果，**能反推、不能解释因果**。

| 维度 | 表现 |
|---|---|
| **主指标** | 权重分布是否合理、综合得分的区分度 |
| **基线** | 等权法（w=1/m）、AHP 权重、变异系数法 |
| **对异常值** | 敏感（min-max 由极值决定） |
| **对样本量** | 样本少时极差不可靠，权重跳变 |
| **对指标相关** | 不敏感 → 会重复计权 |
| **可解释性** | 中：能说清"为什么这个权重大"，说不出"为什么这个指标重要" |
| **外推** | 不能：权重绑定在这批样本上 |

### 三条容易被忽略的规律

> **① 权重低 ≠ 指标不重要。**
> 本案例"优良率"权重最低（0.1998），因为 5 个城市在 65–82 之间差别最小。但它在业务上仍是核心指标，**不能因为权重低就删掉**。

> **② 换一批样本，权重全变。**
> 多加一个"森林覆盖率 80%"的城市，森林覆盖的极差变大，它的权重会进一步上升。所以**不同年份的得分不能直接比**。

> **③ 熵值法不排序，排的是加权求和。**
> 严格说熵值法只产出权重，最后一步"综合得分"其实是**简单加权求和（SAW）**。这一点在论文里写清楚，能显示你懂方法边界。

## 第六层：比赛 —— 怎么把它写进论文

**一句话**：评委看的是"**权重是不是数据算出来的、有没有解释为什么**"，而不是"你用了熵值法"。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 多指标综合评分 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐ 常见 | 指标一堆、要给权重 |
| D 运筹 | ⚠️ 偶尔 | 方案评价的前置 |
| **E 环境** | ⭐⭐ 主战场 | 区域可持续性、污染程度综合评价 |
| **F 政策** | ⭐⭐ 常见 | 政策效果评分、地区发展指数 |

### 三个典型场景

1. **E 题·综合环境评价**：5–30 个地区、6–12 个指标，先熵权再 TOPSIS 排序（本例）。
2. **F 题·发展指数**：把经济、社会、环境指标合成一个分数，用于地区比较。
3. **与 AHP 组合**：熵权 + AHP 各算一套，取几何平均（组合赋权），论文里显得严谨。

### 论文呈现顺序

```
1. 指标表（含义、单位、方向、来源）
2. 标准化公式 + 标准化后矩阵              ← 证明方向没错
3. 信息熵 / 差异系数 / 权重表              ← 核心
4. 权重条形图
5. 综合得分与排名表
6. 敏感性分析（扰动权重）或与 AHP 对比      ← 加分项
```

### 局限性写法（可直接改）

> "熵值法依据指标在样本间的离散程度客观赋权，避免了专家打分的主观性；但其权重反映的是**区分度而非重要性**，且完全依赖样本——更换样本或增减指标都会改变权重，故不同年份的综合得分不能直接比较。此外，熵权法不处理指标间的相关性，本文 4 个指标相关性较低（最大 |r| < 0.5），重复计权问题不严重；若指标高度相关，应先做主成分分析或改用 CRITIC 法。"

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **熵权 + TOPSIS** | 最经典的评价类组合：熵权定权重，TOPSIS 排序 |
| **熵权 + AHP（组合赋权）** | 主客观结合，取几何平均或加权平均 |
| **熵权 + 灰色关联** | 样本少、要看"相似度"时 |
| **CRITIC 替代熵权** | 指标相关性强、要惩罚重复信息 |
| **变异系数法替代** | 数据量小、不想算对数 |

### 三个常见扣分点

1. **把权重说成"重要性"** → 熵权的本质是区分度，说错会暴露不理解。
2. **不同年份直接比得分** → 权重每年不同，得分不可比。
3. **不报标准化方法** → min-max 还是 z-score，结果差很多；必须写清。

- **森林覆盖权重最高（0.2954）**：5 个城市从 18% 到 42%，跨度 24 个百分点，区分度最强；

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 按"指标在样本间的差异"客观定权重 |
| 核心思想？ | 越均匀 → 熵越大 → 信息越少 → 权重越小 |
| 要什么假设？ | 指标可同向化、差异=信息、样本有代表性 |
| 最大硬伤？ | 权重≠重要性；换样本就变；不管指标相关 |
| 关键参数？ | 没有超参，只有 `k = 1/ln(n)` 和方向标记 |
| 论文必写？ | 指标方向表 + 权重表 + 权重条形图 + 局限性 |

## 自测三问

1. 为什么熵值法要先 min-max 标准化，不能直接用原始数据算比重？
2. 某个指标权重只有 0.05，说明它不重要吗？该不该删？
3. 今年的综合得分 0.72，去年 0.68，能不能说"今年更好"？

<details>
<summary>参考答案</summary>

1. 因为熵是在"概率分布"上定义的：比重 p 必须非负、且每列加起来等于 1。原始数据带量纲、可能有负数，不构成分布。min-max 同时解决两件事：统一方向（负向翻转）和压到 0~1（保证非负）。

2. 不能。熵权的含义是"这个指标在样本间有多能区分"，不是"业务上多重要"。权重 0.05 只说明各对象在该指标上差不多。是否删要看业务逻辑与相关性；如果它重要但区分度低，可以保留并在论文里说明，或改用组合赋权。

3. 不能直接比。熵权每年重算，权重随样本变；得分是"相对这批对象"的，跨年份比较需要固定权重，或者改成"同一套权重下的标准化得分"再比。

</details>
