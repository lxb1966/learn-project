# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：用若干个"因"，去解释/预测一个"果"，并且量化每个因贡献多少。

| 问题 | 回答 |
|---|---|
| 核心问题 | 一个连续变量 y，受哪些因素影响？影响多大？给定 x 能否预测 y？ |
| 输入 | `n × k` 数值表：1 列 y（连续）+ k 列 x（连续/虚拟变量） |
| 输出 | 回归系数 β（每个 x 的边际效应）+ 预测值 ŷ + 区间 + 一堆检验统计量 |
| 数据类型 | 截面或时序都行，**连续型**，**有标签**（监督学习） |
| 方法类别 | **统计模型**（parametric，可解释），也是机器学习里的"线性基线" |

### 它回答两种不同的问题（**比赛里最容易混**）

| 目的 | 关心什么 | 怎么写进论文 |
|---|---|---|
| **解释**（inference） | 系数大小、正负、显著性（哪个因素最重要） | "实际利率每上升 1 个百分点，金价平均下降 114.7 美元" |
| **预测**（prediction） | 预测误差（RMSE、交叉验证） | "模型对未来 6 个月金价的预测误差为 ±21 美元" |

> 同一套代码，两种目的；但**评价标准完全不同**——解释看 t 检验和 VIF，预测看交叉验证误差。写论文前先想清楚你要哪个。

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **一元线性回归** | 特例（k=1） | 只有一个因素 |
| **岭回归 / Lasso** | 加了正则化的线性回归 | 共线严重、变量多（Lasso 还能自动选变量） |
| **逻辑回归** | y 是 0/1 时 | 分类问题 |
| **ARIMA** | 时序专用，只用 y 自己的历史 | 没有像样的解释变量，只有时间序列 |
| **随机森林 / GBDT** | 非线性、自动捕捉交互 | 关系明显非线性、变量多、只要预测不要解释 |
| **灰色 GM(1,1)** | 小样本（4–10 个点）时序预测 | 数据极少 |
| **神经网络** | 万能逼近 | 样本量大（上万）、有 GPU 预算 |

## 第二层：假设 —— 它成立的前提

### 六大经典假设（高斯-马尔可夫 + 正态）

| # | 假设 | 一句话含义 | 违反了会怎样 | 怎么查 / 怎么救 |
|---|---|---|---|---|
| 1 | **线性** | y 是 x 的线性组合（对**参数**线性即可） | 系统性偏差，残差有形状 | 残差图；加平方项/对数变换 |
| 2 | **误差零均值** | 没有系统性遗漏 | 截距有偏 | 残差均值≈0 |
| 3 | **同方差** | 误差的波动不随 x 变 | 系数仍无偏，但**标准误错 → t 检验失效** | Breusch-Pagan 检验；稳健标准误 / 加权最小二乘 |
| 4 | **无自相关** | 误差之间不相关（**时序数据最易违反**） | 标准误被低估，假显著 | Durbin-Watson；Newey-West 标准误 |
| 5 | **无完全共线** | x 之间不能线性表出 | 系数爆炸、符号反直觉 | **VIF**；删变量 / 岭回归 / PCA |
| 6 | **误差正态** | 用于小样本的 t/F 检验 | 大样本靠中心极限定理自动缓解 | Jarque-Bera、Q-Q 图 |

### 数据条件

| 项 | 要求 | 说明 |
|---|---|---|
| 样本量 | 经验法则 **n ≥ 10k**（k = 变量个数） | n=36、k=4 刚好够；n < k 直接无解 |
| 量纲 | 不要求统一，但**比较重要性必须先标准化** | 否则"系数大"只是单位大 |
| 缺失值 | 不能有 | 删行 / 均值插补 / 多重插补 |
| 异常值 | **敏感**（杠杆点能把整条线拉歪） | 标准化残差 >3、Cook 距离 |
| 外推 | **危险** | x 超出样本范围，预测不可信 |

### 适用边界

- ✅ 关系大致线性、变量不多、需要**说清"为什么"**；
- ❌ 强非线性、强交互、变量几百个、样本上万 → 上树模型；
- ❌ 时序且只有 y 自身历史 → 上 ARIMA；
- ⚠️ **时序数据直接做水平值回归，很容易"伪回归"**（两个都在涨的变量，R² 天然很高但毫无因果）。

## 第三层：原理 —— 它为什么 work

### 3.1 先把字母认全

模型本身只有一行：

```
yᵢ = β₀ + β₁xᵢ₁ + β₂xᵢ₂ + … + βₖxᵢₖ + εᵢ        （i = 1, 2, …, n）
```

代入本案例（n = 36，k = 4）：

```
GOLDᵢ = β₀ + β₁·CPIᵢ + β₂·DXYᵢ + β₃·REALᵢ + β₄·BTCᵢ + εᵢ
```

**每个字母的含义、维度和本案例的取值**：

| 符号 | 叫什么 | 含义 | 本案例 |
|---|---|---|---|
| `n` | 样本量 | 多少行数据 | 36 |
| `k` | 解释变量个数 | 有几列 x（不含常数） | 4 |
| `p` | 待估参数个数 | `p = k + 1`（含截距） | 5 |
| `yᵢ` | 被解释变量 | 第 i 行的真实值 | 金价 |
| `xᵢⱼ` | 第 i 行第 j 个 x | 第 i 个月第 j 个指标 | CPI / DXY / REAL / BTC |
| `βⱼ` | 回归系数 | **要求的东西**，共 p 个 | β₀…β₄ |
| `εᵢ` | 误差项 | 真实世界里的随机扰动，永远看不到 | — |
| `ŷᵢ` | 拟合值 | `ŷᵢ = β̂₀ + β̂₁xᵢ₁ + … + β̂ₖxᵢₖ` | 模型算出的金价 |
| `eᵢ` | 残差 | `eᵢ = yᵢ − ŷᵢ`（**能算出来**，是 ε 的估计） | 残差 |
| `SSE` | 残差平方和 | `Σeᵢ²` | 见 3.4 |
| `SST` | 总平方和 | `Σ(yᵢ − ȳ)²` | 见 3.4 |
| `SSR` | 回归平方和 | `SST − SSE` | 见 3.4 |
| `σ̂²` | 残差方差 | `SSE/(n − k − 1)` | 见 3.5 |
| `R²` / `adjR²` | 拟合优度 | 见 3.4 | 0.9292 / 0.9200 |
| `se(β̂ⱼ)` | 系数标准误 | 见 3.5 | 见案例表 |
| `tⱼ` | t 统计量 | `β̂ⱼ / se(β̂ⱼ)` | 见案例表 |
| `F` | 整体显著性 | 见 3.6 | 101.66 |
| `VIFⱼ` | 方差膨胀因子 | 见 3.7 | 见案例表 |
| `AIC` / `BIC` | 信息准则 | 见 3.9 | 326.78 |

> **一句话**：`y = Xβ + ε`，字母只有四类——**数据（y、X）、待估的（β）、算出来的（ŷ、e）、检验用的（SSE、se、t、F）**。

### 3.2 目标函数：最小二乘在最小化什么

```
SSE(β) = Σᵢ eᵢ² = Σᵢ (yᵢ − ŷᵢ)² = (y − Xβ)ᵀ(y − Xβ)
```

**β̂ = 让 SSE 最小的那组 β**。

几何直觉：把 y 这个向量**投影**到由 X 的列张成的空间上，投影点就是 ŷ，残差就是那段垂线——所以残差和每个 x 都正交（`Xᵀe = 0`），这正是"残差与拟合值不相关"的由来。

### 3.3 怎么解出来：正规方程与闭式解

对 `SSE(β)` 关于 β 求导、令导数为 0，得到**正规方程**：

```
XᵀX · β̂ = Xᵀy          →          β̂ = (XᵀX)⁻¹ Xᵀy
```

**维度**：`X` 是 `n×p`，`XᵀX` 是 `p×p`，`Xᵀy` 是 `p×1`，解出的 `β̂` 是 `p×1`。

**这几个矩阵怎么来的（手算就靠它俩）**：

```
        ⎡ 1  x₁₁  x₁₂ … x₁ₖ ⎤            ⎡ y₁ ⎤
    X = ⎢ 1  x₂₁  x₂₂ … x₂ₖ ⎥        y = ⎢ y₂ ⎥
        ⎢ ⋮   ⋮    ⋮   ⋱  ⋮  ⎥            ⎢ ⋮  ⎥
        ⎣ 1  xₙ₁  xₙ₂ … xₙₖ ⎦            ⎣ yₙ ⎦
```

- `XᵀX` 的每个元素 = **两列的内积**：第 (j,l) 个元素是 `Σᵢ xᵢⱼ·xᵢₗ`（第 1 列全是 1，所以第一行/列就是各列的求和）；
- `Xᵀy` 的每个元素 = **每列与 y 的内积**：第 j 个是 `Σᵢ xᵢⱼ·yᵢ`。

所以手算时**只要算出这 8 个和**（`Σx₁、Σx₂、Σy、Σx₁²、Σx₂²、Σx₁x₂、Σx₁y、Σx₂y`），就能把方程拼出来——完整演示见第四层的「手算演示」。

**k = 1 时退化成一个初中公式**（最简单的一元回归）：

```
β̂₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
β̂₀ = ȳ − β̂₁·x̄
```

### 3.4 拟合得好不好：SSE / SST / SSR 与 R²

```
SST = Σ(yᵢ − ȳ)²          总平方和（y 自己有多散）
SSE = Σ(yᵢ − ŷᵢ)²         残差平方和（模型没解释的部分）
SSR = SST − SSE           回归平方和（模型解释掉的部分）

R²    = SSR / SST = 1 − SSE / SST
adjR² = 1 − (1 − R²)·(n − 1)/(n − k − 1)
```

**为什么要调整 R²**：每加一个变量，SSE 必减 → R² 必升（哪怕加的是随机噪声）。乘上 `(n−1)/(n−k−1)` 就是在惩罚"变量多"，所以比模型看 `adjR²`。

本案例：`R² = 0.9292`，`adjR² = 1 − (1−0.9292)×35/31 = 0.9200`。

### 3.5 系数准不准：标准误与 t 检验

```
σ̂²        = SSE / (n − k − 1)                残差方差的无偏估计（自由度 n−p）
Var(β̂)    = σ̂² · (XᵀX)⁻¹                     系数的协方差矩阵
se(β̂ⱼ)    = √( σ̂² · [(XᵀX)⁻¹]ⱼⱼ )            取对角线的第 j 个元素开根号
tⱼ        = β̂ⱼ / se(β̂ⱼ)                      服从 t(n − k − 1)
95% 区间  = β̂ⱼ ± t₀.₀₂₅,ₙ₋ₖ₋₁ · se(β̂ⱼ)
```

**t 值在问什么**：这个系数离 0 有几倍标准误。|t| > 2 大约对应 p < 0.05。

本案例（REAL 这一行）：`t = −114.7359 / 24.0989 = −4.761`，对应 `p < 0.0001`。

### 3.6 整体显著：F 检验

```
F = (SSR / k) / (SSE / (n − k − 1))        服从 F(k, n−k−1)
```

**直觉**：分子是"平均每个变量解释了多少方差"，分母是"残差方差"。F 大 = 模型解释的远多于没解释的。

本案例：`F = 101.66`，`p = 2.32×10⁻¹⁷`——模型整体高度显著。

### 3.7 共线：VIF 怎么算

把第 j 个 x **当成因变量**，用其余所有 x 去回归它，得到 `Rⱼ²`，则

```
VIFⱼ = 1 / (1 − Rⱼ²)
```

| VIF | 对应 Rⱼ² | 含义 |
|---|---|---|
| 1 | 0 | 与其他变量毫无关系 |
| 5 | 0.8 | 有 80% 的信息能被别人替代 |
| 10 | 0.9 | 严重共线，系数开始不稳 |

### 3.8 谁更重要：标准化系数

原始系数带单位，不能直接比。把 y 和所有 x 都标准化（减均值除标准差）再回归，得到的系数就是：

```
β*ⱼ = β̂ⱼ · s(xⱼ) / s(y)          s() 为样本标准差
```

本案例：`β*_REAL = −114.74 × 0.41 / 75.08 ≈ −0.62`，而 BTC 只有 `+0.16`——**实际利率的重要性是比特币的近 4 倍**。

### 3.9 选模型：AIC / BIC

```
AIC = n·ln(SSE/n) + 2p
BIC = n·ln(SSE/n) + p·ln(n)
```

拟合越好 SSE 越小、第一项越小；参数越多 p 越大、第二项越大。**越小越好**，且只能在**同一批数据**上比。

### 3.10 预测：点、置信区间、预测区间

给定一组新 x₀：

```
点预测   ŷ₀ = x₀ᵀβ̂

均值置信区间  ŷ₀ ± t · √( σ̂² · x₀ᵀ(XᵀX)⁻¹x₀ )
单次预测区间  ŷ₀ ± t · √( σ̂² · (1 + x₀ᵀ(XᵀX)⁻¹x₀) )
```

差别只在那个 **1**：它代表"这一个具体观测自身的随机波动 ε"，所以预测区间永远比置信区间宽。

### 3.11 可解释性：★★★★★（所有模型里最高）

- 系数直接就是"边际效应"，带单位，能写成一句人话；
- 标准化系数可以横向比"谁更重要"；
- 缺点也在这：**它强行假设"其他条件不变"**，现实里变量是一起动的。

> 线性回归**没有超参数**（岭回归才有 α）——这是它"跑起来最快"的原因，也是它"不够灵活"的原因。

## 第四层：操作 —— 怎么跑起来

### 八步流程

```
① 明确目的（解释 or 预测）
② 数据清洗：缺失值、异常值、量纲
③ 画散点图/相关矩阵，初步看关系
④ 建模：OLS 拟合
⑤ 看整体：R²、调整 R²、F 检验
⑥ 看个体：系数、t、p、VIF（共线）
⑦ 残差诊断：正态 / 同方差 / 自相关 / 线性
⑧ 检验与对比：交叉验证 + 基线模型 + 预测区间
```

### 手算演示：n = 8 的两变量回归，从原始数据一路算到 t 值

> 36 行不可能手算，但原理必须能手算一遍。下面用 8 个样本把 **3.2–3.7 的每个公式**都代一遍数，结果与 Python 完全一致，你可以逐行核对。

**数据**（x₁ = 学习时长，x₂ = 上次成绩，y = 本次成绩）：

| i | x₁ | x₂ | y |
|---|---|---|---|
| 1 | 1 | 60 | 52 |
| 2 | 2 | 55 | 58 |
| 3 | 3 | 70 | 66 |
| 4 | 4 | 65 | 70 |
| 5 | 5 | 80 | 78 |
| 6 | 6 | 75 | 84 |
| 7 | 7 | 90 | 92 |
| 8 | 8 | 85 | 98 |

#### 第 1 步：把求和算出来（这是手算的全部工作量）

| 和 | 值 | 和 | 值 |
|---|---|---|---|
| n | 8 | Σx₁² | 204 |
| Σx₁ | 36 | Σx₂² | 43,100 |
| Σx₂ | 580 | Σx₁x₂ | 2,800 |
| Σy | 598 | Σx₁y | 2,968 |
| ȳ = Σy/n | 74.75 | Σx₂y | 44,630 |
| Σy² | 46,532 | | |

#### 第 2 步：拼出 XᵀX 和 Xᵀy

第一列全是 1，所以 `XᵀX` 的第一行/列就是各列的**求和**：

```
        ⎡  8    36    580  ⎤          ⎡  598  ⎤
XᵀX  =  ⎢ 36   204   2800  ⎥    Xᵀy = ⎢ 2968  ⎥
        ⎣ 580  2800  43100 ⎦          ⎣ 44630 ⎦
```

对照 3.3：`(1,1)=n`、`(1,2)=Σx₁`、`(2,2)=Σx₁²`、`(2,3)=Σx₁x₂`……完全对上。

#### 第 3 步：求逆

```
              ⎡  14.88125    1.13125   −0.27375 ⎤
(XᵀX)⁻¹  =    ⎢   1.13125    0.13125   −0.02375 ⎥
              ⎣  −0.27375   −0.02375    0.00525 ⎦
```

（手算 3×3 逆矩阵：`A⁻¹ = adj(A)/|A|`；比赛里这一步交给 `np.linalg.inv`，你只要知道它在算什么。）

#### 第 4 步：β̂ = (XᵀX)⁻¹ Xᵀy，逐行乘

```
β̂₀ = 14.88125×598 + 1.13125×2968 + (−0.27375)×44630
    = 8898.99 + 3357.55 − 12217.46
    = 39.08

β̂₁ = 1.13125×598 + 0.13125×2968 + (−0.02375)×44630
    = 676.49 + 389.55 − 1059.96
    = 6.08

β̂₂ = (−0.27375)×598 + (−0.02375)×2968 + 0.00525×44630
    = −163.70 − 70.49 + 234.31
    = 0.12
```

**模型**：`本次成绩 = 39.08 + 6.08×学习时长 + 0.115×上次成绩`

读法：多学 1 小时，本次成绩平均高 **6.08 分**；上次成绩高 1 分，本次平均高 **0.115 分**（控制学习时长不变）。

#### 第 5 步：拟合值、残差、R²

| i | y | ŷ | e = y − ŷ | e² |
|---|---|---|---|---|
| 1 | 52 | 52.05 | −0.05 | 0.0025 |
| 2 | 58 | 57.55 | +0.45 | 0.2025 |
| 3 | 66 | 65.35 | +0.65 | 0.4225 |
| 4 | 70 | 70.85 | −0.85 | 0.7225 |
| 5 | 78 | 78.65 | −0.65 | 0.4225 |
| 6 | 84 | 84.15 | −0.15 | 0.0225 |
| 7 | 92 | 91.95 | +0.05 | 0.0025 |
| 8 | 98 | 97.45 | +0.55 | 0.3025 |
| **Σ** | | | | **SSE = 2.10** |

```
SST = Σy² − n·ȳ² = 46532 − 8×74.75² = 46532 − 44700.5 = 1831.5
SSR = SST − SSE = 1831.5 − 2.10 = 1829.4

R²    = 1829.4 / 1831.5 = 0.9989
adjR² = 1 − (1 − 0.9989)×(8−1)/(8−3) = 1 − 0.0011×1.4 = 0.9984
```

> 这个例子 `R² = 0.999` 是因为数据是刻意造的（近乎完美线性），**真实赛题一般在 0.6–0.95**，别拿它当预期。

#### 第 6 步：σ̂²、标准误、t 值

```
σ̂² = SSE/(n − k − 1) = 2.10 / (8 − 2 − 1) = 2.10/5 = 0.42
σ̂  = √0.42 = 0.648
```

`se(β̂ⱼ) = √( σ̂² × [(XᵀX)⁻¹]ⱼⱼ )`，**只看对角线**：

| 参数 | β̂ⱼ | [(XᵀX)⁻¹]ⱼⱼ | √(0.42×对角) | se | t = β̂/se | p |
|---|---|---|---|---|---|---|
| β₀ | 39.075 | 14.88125 | √6.250 = 2.500 | 2.500 | 15.63 | <0.001 |
| β₁ | 6.075 | 0.13125 | √0.0551 = 0.2348 | 0.2348 | **25.87** | <0.001 |
| β₂ | 0.115 | 0.00525 | √0.00221 = 0.0470 | 0.0470 | 2.449 | **0.058** |

**怎么读 p 值**：`t = 2.449`、自由度 5，查 t 表（双侧）得 p ≈ 0.058 → 在 5% 水平上**边缘显著**（"上次成绩"的作用被"学习时长"部分替代了）。

#### 第 7 步：VIF（验证 3.7 的公式）

用 x₂ 对 x₁ 回归：`R₂² = 0.8186`

```
VIF₂ = 1/(1 − 0.8186) = 5.51
```

同理 `VIF₁ = 5.51`。**VIF > 5 说明两个变量已经高度重叠**——这正是系数 p 值勉强的原因。

#### 第 8 步：预测（验证 3.10 的公式）

设 `x₀ = (1, 9, 88)ᵀ`（学 9 小时、上次 88 分）：

```
ŷ₀ = 39.075 + 6.075×9 + 0.115×88 = 103.87
s  = √(0.42 × (1 + x₀ᵀ(XᵀX)⁻¹x₀)) = 0.853
95% 预测区间 = 103.87 ± 2.571×0.853 = [101.7, 106.1]
```

#### 与程序结果对照

```python
# 同一组数据，statsmodels 输出：
# β = [39.075, 6.075, 0.115]   se = [2.500, 0.235, 0.047]
# t = [15.63, 25.87, 2.449]    R² = 0.9989   adjR² = 0.9984   F = 2177.9
```

手算结果与程序**逐位一致**——这就说明你已经掌握了"字母 → 公式 → 数字"的全过程。

> **比赛里怎么办**：3 个变量以内可以手算核对；4 个以上一律交给 `statsmodels`，但你必须能指着输出表说清每一列是用 3.4–3.7 哪个公式算的。

## 第五层：评价 —— 怎么判断它好不好

### 5.1 误差指标（每个都有公式）

| 指标 | 公式 | 含义 | 本案例（金价） |
|---|---|---|---|
| **RMSE** | `√( (1/n)Σ(yᵢ − ŷᵢ)² )` | 均方根误差，和 y 同单位 | 21.23 美元 |
| **MAE** | `(1/n)Σ\|yᵢ − ŷᵢ\|` | 平均绝对误差，抗异常值 | — |
| **MAPE** | `(1/n)Σ\|(yᵢ − ŷᵢ)/yᵢ\|×100%` | 百分比误差，跨量级可比 | — |
| **R²** | `1 − SSE/SST` | 解释了多少方差 | 0.9292 |
| **adjR²** | `1 − (1−R²)(n−1)/(n−k−1)` | 罚过复杂度 | 0.9200 |
| **LOOCV-RMSE** | 每次留 1 个样本，`n` 次预测的 RMSE | 泛化误差的近似 | 22.91 |

**为什么还要 LOOCV**：训练集 RMSE 一定比真实泛化误差小（模型"见过"这些点）。留一交叉验证每次拿掉 1 个样本重新拟合，用没见过的那个算误差，才接近"未来预测"的真实水平。

### 5.2 综合判断

| 维度 | 表现 |
|---|---|
| **核心指标** | R²、调整 R²、RMSE、MAE、MAPE、AIC/BIC、交叉验证误差 |
| **基线模型** | ①均值模型（永远预测 ȳ）②一元回归 ③上一个时间点的值（naive）——**没有基线就没有"好"** |
| **对异常值** | **敏感**（一个杠杆点能改符号），要先查 Cook 距离 |
| **对共线** | 敏感（系数不稳，但预测值往往还行） |
| **过拟合** | 会。变量越多 R² 越高，但泛化可能更差 |
| **防过拟合** | 调整 R²、交叉验证、AIC/BIC、正则化（岭/Lasso）、变量筛选 |
| **外推** | 最大软肋，超出样本范围基本靠猜 |

**Cook 距离**（判断"哪个点把线拉歪了"）：

```
Dᵢ = eᵢ² / (p·σ̂²) × [ hᵢᵢ / (1 − hᵢᵢ)² ]
```

其中 `hᵢᵢ` 是第 i 个样本的杠杆值（hat 矩阵 `H = X(XᵀX)⁻¹Xᵀ` 的对角线）。经验上 **Dᵢ > 1** 就值得逐个检查；`hᵢᵢ > 2p/n` 是高杠杆点。

### 和竞品的对比怎么写

| 对比对象 | 你的论点 |
|---|---|
| vs 一元回归 | 多变量带来多少 R² 提升、LOOCV 误差降了多少 |
| vs 岭回归 | 共线严重时，岭回归系数更稳、预测误差更小 |
| vs 随机森林 | 线性模型可解释、样本少时更稳；RF 能抓非线性但说不清"为什么" |
| vs ARIMA | 有解释变量用回归，只有时间序列用 ARIMA |


### 局限性写法（可直接改）

> "多元线性回归假设变量间关系为线性、误差同方差且相互独立。本文数据为月度宏观序列，CPI 与比特币价格均含明显趋势，导致 VIF 偏高（13.9 / 15.1），系数估计的稳定性受限；本文通过岭回归与留一交叉验证验证了预测稳健性，并对残差进行了正态性、异方差与自相关检验。若要进一步消除趋势影响，可改用差分序列或加入时间趋势项。"

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **回归 + 残差分析** | 本文件已做，标配 |
| **回归 + 岭/Lasso** | 共线、变量多 |
| **回归 + 随机森林** | 线性 vs 非线性的"模型对比"（下一份文件） |

### 三个常见扣分点

1. **只报 R²，不报调整 R² 和检验** → 显得不懂；
2. **系数符号和常识相反还不解释** → 一定是共线/遗漏变量，必须查；
3. **拿时序水平值回归就宣称因果** → 伪回归，评委一眼看穿。

### 第 5 步：共线性诊断（VIF）

| 变量 | VIF | 判断 |
|---|---|---|
| CPI | **13.913** | 严重（>10） |

**为什么会这样**：CPI 和 BTC 都是**单调上升的趋势变量**，两者互相能解释 95%；DXY 和 REAL 是经济学上的"孪生变量"。

**后果**：系数估计不稳（换一段样本，符号可能翻转），但对**预测值**影响不大。
**处理**：①删掉冗余变量；②岭回归；③对趋势变量取差分/对数收益率；④主成分回归。

> 这是本案例**故意保留**的真实毛病——宏观时序数据几乎必然共线。论文里把它写出来 + 给出处理方案，比假装 VIF=1 更得分。

| 线性（残差 vs 拟合相关） | −0.0000 | 无系统偏差 ✅ |

**结论**：三大假设基本满足，模型可用；DW 略大，若严格可改用 Newey-West 稳健标准误。

**情景**：CPI = 285、DXY = 98、实际利率 = 1.5%、BTC = 40000（大致对应"通胀继续、美元走强、加息"的组合）

| 点预测 | **1430.8 美元/盎司** |
| 95% 置信区间（均值的区间） | [1373.8, 1487.8] |
| 95% 预测区间（单次观测） | [1359.2, 1502.3] |

**必须分清这两个区间**（论文里写错会被扣分）：

- **置信区间**回答"如果这种宏观环境重复很多次，**平均**金价在哪"；
- **预测区间**回答"**下个月**的真实金价会在哪"，因为多了 ε 的随机性，所以更宽。

| 模型 | R² | 调整 R² | AIC | LOOCV-RMSE |

1. 从"仅 CPI"到"四变量"，调整 R² 从 0.28 跳到 0.92，**LOOCV-RMSE 从 65.5 降到 22.9**——多出来的变量带来的是真泛化收益，不是过拟合；
2. 岭回归的 R²（0.9287）只比 OLS 低 0.0005，但**系数更稳**——这就是共线时用正则化的理由；
3. 残差标准差 21.23 美元，相对金价 1530 约 **1.4%**，预测精度可以接受。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 解释"谁影响 y、影响多大" + 预测 y |
| 核心方法？ | 最小二乘：让残差平方和最小 |
| 最关键假设？ | 线性、同方差、无自相关、无共线、误差正态 |
| 必查什么？ | VIF（共线）、残差三检验、调整 R² |
| 最容易错？ | 拿原始系数比重要性（要标准化）、拿水平值做时序回归（伪回归） |
| 论文必写？ | 变量表 + 回归结果表 + 残差图 + 模型对比 |

## 自测三问

1. R² = 0.95 但 VIF 全是 20，这个模型能用吗？为什么？
2. 系数符号和经济学常识相反，最先怀疑什么？
3. n = 12、变量 5 个，能直接做多元回归吗？

<details>
<summary>参考答案</summary>

1. **预测勉强能用，解释不能用**。共线不破坏预测精度，但会让系数方差爆炸、符号不稳，此时 t 检验几乎全部失效。应删变量、用岭回归或做差分。
2. 先查**共线**（VIF）和**遗漏变量**，再看样本区间是否太短、异常值是否在撬动结果。符号翻转是共线的典型症状。
3. 不能。经验法则 n ≥ 10k，即至少 50 个样本；12 个样本配 5 个变量，R² 会虚高到接近 1，纯属过拟合。应减变量或改用岭回归/主成分。

</details>
