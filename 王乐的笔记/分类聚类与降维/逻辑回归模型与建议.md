# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：把"对数几率"写成特征的线性组合，从而**预测 0/1 事件发生的概率**，并把每个特征的影响写成**几率比 OR（odds ratio）**。

| 问题 | 回答 |
|---|---|
| 核心问题 | 给定特征，某件事**发生/不发生**的概率是多少；哪个特征影响最大 |
| 输入 | `n × k` 表格数据，**有标签**（标签是 0/1，或可整理成 0/1） |
| 输出 | 概率 `p ∈ (0,1)` + 系数 `β` + **OR** + p 值 + 置信区间 |
| 数据类型 | 表格型；也吃类别变量（做哑变量） |
| 方法类别 | 统计 → **广义线性模型（GLM）** → 二项分布 + logit 连接 |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **线性概率模型（LPM，直接对 0/1 跑 OLS）** | 逻辑回归的"退化版" | 只想快速看方向、不关心概率是否越界 |
| **随机森林 / GBDT 分类** | 非线性、更准、能自动抓交互 | 只要预测精度、不要系数解释 |
| **判别分析（LDA / QDA）** | 假设特征服从正态，用贝叶斯规则 | 特征近似正态、样本小、要降维 |
| **SVM** | 只给分类边界，不给概率 | 高维、小样本、只要分对 |
| **朴素贝叶斯** | 假设特征条件独立 | 文本分类、特征极多 |
| **Probit 回归** | 换成正态连接函数 | 结果与 logit 几乎一样，一般不必换 |

### 一句话选型

> **0/1 目标 + 要回答"哪个因素影响多大" → 逻辑回归；只要预测精度 → 随机森林/GBDT；要处理多分类 → 多项 logit / softmax。**

## 第二层：假设 —— 它成立的前提

**一句话**：它的假设比线性回归少一半，但每一条都更"硬"——违反了不是精度掉一点，而是**系数直接不可解释**。

| # | 假设 | 含义（大白话） | 违反了会怎样 |
|---|---|---|---|
| 1 | **线性于 logit** | 自变量每变 1 单位，**对数几率**变 β，而不是概率变 β | 关系是阈值型/U 形时，模型系统性偏差，AUC 明显掉 |
| 2 | **观测相互独立** | 每个样本互不影响 | 重复测量/时空数据要加随机效应，否则标准误偏小、p 值虚低 |
| 3 | **无完全分离** | 没有哪个变量能"完美"把 0 和 1 分开 | MLE 不收敛，系数趋于无穷，OR 变成天文数字 |
| 4 | **无严重共线** | 自变量之间别高度相关 | 系数方差膨胀、符号翻转，OR 不可信（但预测仍可能很准） |
| 5 | **样本量足够** | 经验法则 **EPV ≥ 10**（每个自变量至少 10 个"事件"） | 系数不稳定，p 值不可信，模型无法复现 |
| 6 | **无遗漏关键变量** | 影响 y 的变量都在模型里 | 遗漏变量会让 OR 混入混杂效应，甚至符号相反 |

### 它**不需要**的假设（相对线性回归的巨大简化）

- ❌ 不需要误差正态（y 是 0/1，本来就不可能正态）
- ❌ 不需要同方差（方差 = p(1−p)，天然随均值变）
- ❌ 不需要因变量连续
- ❌ 不需要自变量正态
- ✅ **但需要**：自变量与 logit(p) 的关系是线性的（这条比线性回归的"线性"更隐蔽，也更容易被忽略）

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **完全分离** | 某个变量一出现，y 就必为 1（或必为 0） | 系数不收敛，软件报错或给出巨大 OR |
| **强共线** | 系数方差被放大 `1/(1−R²)` 倍 | 单因素和多因素 OR 能差一倍以上（本案例 4.36 → 2.04） |
| **线性于 logit** | 真实关系是"超过阈值才风险陡增" | 模型抓不到拐点，只能给一条平滑曲线 |
| **OR ≠ RR** | 发生率不低（如 35%）时，OR 会明显高估"风险倍数" | 把 OR=2 读成"风险翻倍"是**错的** |
| **对离群点敏感** | MLE 会被极端样本拉偏 | 一个异常点就能改变 OR 的方向 |
| **不平衡数据** | 99:1 时全预测多数类，准确率仍 99% | 必须看 AUC/召回率，不能看准确率 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | 每个自变量 ≥ 10 个事件（EPV≥10）；本案例 295/10 = 29.5 ✅ |
| 缺失值 | sklearn / statsmodels **都不吃 NaN**，要先填补或删 |
| 类别变量 | 做哑变量，**k 个类别做 k−1 列**（否则"虚拟变量陷阱"导致完全共线） |
| 异常值 | 敏感，先看箱线图/3σ |
| 量纲 | 不影响预测，**但影响系数大小**；要比较强弱必须标准化 |
| 不平衡 | 先看发生率；<10% 要考虑加权、改阈值或换指标 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **把"概率"这个被限制在 (0,1) 的量，通过"对数几率"这把尺子拉开到整条实数轴，于是线性回归那套框架就能直接用了。**

### 关键公式（三个，够用）

```
① 对数几率（logit）：   logit(p) = ln( p / (1−p) ) = β₀ + β₁x₁ + … + βₖxₖ
② 反解回概率：          p = 1 / (1 + e^(−z))，  z = β₀ + Σβⱼxⱼ     ← 这就是 sigmoid
③ 几率比：              ORⱼ = e^(βⱼ)
```

三句话读懂：

- **β 加 1 单位 → 对数几率加 β → 几率乘 e^β**。所以 `OR = e^β` 才是能直接讲的东西。
- **OR = 1.05 不是"概率涨 5%"**，而是"几率变 1.05 倍"。
- 概率的变化量取决于起点：同样 β，在 p=0.1 和 p=0.9 附近，概率的绝对变化完全不同（sigmoid 两端平、中间陡）。

### 核心一步：极大似然（不是最小二乘）

逻辑回归的系数不是"让残差平方和最小"，而是**让"观测到这份数据"的概率最大**：

```
ℓ(β) = Σ [ yᵢ·ln pᵢ + (1−yᵢ)·ln(1−pᵢ) ]        ← 对数似然
```

- 这个函数是**凸的**，所以有唯一最优解，牛顿法/IRLS 几步就收敛。
- 它等价于最小化**交叉熵（log loss）**——这也是为什么评价分类模型用 LogLoss。

> **为什么不能对 0/1 直接跑 OLS**：OLS 的预测是 `Xβ`，值域是整个实数轴，必然出现 `p < 0` 或 `p > 1`（本案例 **14.2%** 的样本越界，最低 −0.456、最高 1.222）；而且 0/1 的误差方差是 `p(1−p)`，随均值变，违反同方差。所以 LPM 只能当"快速看方向"的基线。

### 机制拆解

| 机制 | 怎么做 | 作用 |
|---|---|---|
| **连接函数 logit** | 把 (−∞,+∞) 的线性预测压进 (0,1) | 概率有意义、永不越界 |
| **极大似然** | 最大化对数似然（等价最小化 log loss） | 0/1 数据的正确估计方式，且凸函数保证全局最优 |
| **对数几率线性** | `ln(p/(1−p)) = Xβ` | 系数可转 OR，直接回答"影响多大" |

### 关键超参数（sklearn 口径；statsmodels 口径没有超参）

| 超参数 | 控制什么 | 调大/调小的后果 | 常用范围 |
|---|---|---|---|
| `C` | **正则强度的倒数**（C 越小正则越强） | 小→系数被压向 0、更稳；大→贴近 MLE、易过拟合 | 0.01–100（对数网格） |
| `penalty` | 正则类型 | l2 稳、l1 可做变量筛选、elasticnet 两者兼有 | `l2` / `l1` / `elasticnet` |
| `solver` | 优化算法 | lbfgs 稳、liblinear 适合小样本、saga 支持 l1 | `lbfgs`（默认） |
| `class_weight` | 类别权重 | `balanced` 可缓解不平衡 | `None` / `balanced` |
| `max_iter` | 迭代上限 | 太小会"未收敛"警告 | 1000–5000 |

> **写论文时注意**：`C` 是"正则强度倒数"，跟教材里的"惩罚系数 λ"方向相反，别写反。

### 教材口径对照：线性回归 vs 逻辑回归

> 这张表是本文件最该记住的一页——**同一个回归框架，四处换了零件**。

| 环节 | 教材第 12 章（线性回归） | 逻辑回归 | 为什么必须换 |
|---|---|---|---|
| 估计方法 | 最小二乘（OLS） | **极大似然（MLE）** | 0/1 的方差随均值变，OLS 不再最优 |
| 拟合优度 | 判定系数 `R² = 1 − SSE/SST` | **伪 R²（McFadden）** | 0/1 无法做 SST=SSR+SSE 分解 |
| 整体检验 | F 检验 | **似然比检验 LLR**（`−2(ℓ₀−ℓ₁) ~ χ²`） | 比较嵌套模型的似然 |
| 单个系数检验 | t 检验 | **Wald z 检验**（`z = β/se`） | 大样本下 z ≈ t |
| 共线性诊断 | **条件数 κ**（§7，教材用 `√(λmax/λmin)`） | 条件数 **+ VIF** | 同思路，VIF 能定位到"哪个变量" |
| 变量筛选 | 偏 F 检验 + 逐步回归（§6，α进=0.05、α出=0.10） | 逐步 / **AIC** / LASSO | 准则不同，目的相同 |
| 数据预处理 | 中心化、无量纲化、标准化（§1.2） | 标准化后 **OR = 每 1 个标准差的效应** | 让不同量纲的 OR 可比 |

> **一句话**：教材教的是"怎么用最小二乘拟合一条线"，逻辑回归教的是"怎么把这条线弯成 S 形，还能保住可解释性"。骨架没变，零件全换了。

### 可解释性：★★★★☆（比随机森林强，比线性回归略弱）

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **系数 β / OR** | 这个特征每变 1 单位，几率变几倍 | ✅ 主结果，但必须配 95%CI |
| **标准化 β** | 哪个特征"相对更重要"（跨量纲可比） | ✅ 推荐同时报 |
| **Wald p 值** | 这个效应是不是碰巧 | ⚠️ 共线时会失真 |
| **OR 森林图** | 一眼看完所有效应 + 不确定性 | ✅ 论文里最好看 |
| **边际效应（AME）** | 概率平均变化多少（不是几率） | ✅ 想让评委"看懂概率"时用 |

## 第四层：操作 —— 怎么跑起来

**一句话**：逻辑回归的操作重点不是"调参"（它几乎没有超参），而是**把统计检验和模型对比做全**。

### 七步流程（速览）

```
① 数据准备     缺失填补、哑变量、划分训练/测试、EPV 自查
② 基线模型     线性概率模型（对 0/1 跑 OLS），拿到"没有逻辑回归时"的参照
③ 拟合          全变量逻辑回归（statsmodels 拿系数/OR/p，sklearn 拿预测）
④ 检验          LLR（整体）、Wald（单个）、伪 R²、VIF/条件数、HL（校准）
⑤ 变量筛选      逐步 / AIC / LASSO，三选一，别混用
⑥ 阈值           0.5 只是习惯；按代价选阈值，报混淆矩阵
⑦ 解释与对比     OR 森林图 + ROC + 校准曲线 + 四模型对比表
```

> **两个定位提醒**：
> 1. **第④步的"检验"不是一个动作**：LLR 管整体、Wald 管单个、HL 管概率是否可信——三者回答三个不同问题，缺一个都容易被评委追问。
> 2. **第⑥步的阈值不是"调参"**：它不改模型，只改"把概率翻译成 0/1 的规则"。论文里必须说清阈值怎么来的。

### 七步详解

> 每一步都给三样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**常见坑**。
> 照着走，一个下午能从原始表做到论文图表。

#### ① 数据准备：把原始表变成"能建模的表"

**做什么（按顺序）**：

1. **先看缺失**：算每列缺失率 `df.isnull().mean()`，按三档处理：① **>40%** 整列删掉（信息太少，填补等于编）；② **5%–40%** 填补——连续变量用**中位数**（比均值抗极端值，人口密度这类偏态变量尤其明显），类别变量把"缺失"单列一类、不要硬填众数；③ **<5%** 直接删行或中位数填，二选一并在论文里说明。
2. **转哑变量**：`pd.get_dummies(df, columns=['地区类型'], drop_first=True, dtype=int)`。
   `drop_first=True` 就是"k 类做 k−1 列"，否则各类别列相加恒等于 1，与截距完全共线（虚拟变量陷阱），逻辑回归直接不收敛。
3. **对齐列**：训练集和测试集必须**同一套列**。做法是记下 `train_cols = X_train.columns`，测试集 `reindex(columns=train_cols, fill_value=0)`。否则测试集少一个哑变量列，模型一预测就报错。
4. **分层划分**：`train_test_split(X, y, test_size=0.3, stratify=y, random_state=42)`。
   `stratify=y` 保证训练/测试的阳性率一致（本案例 0.351 / 0.353）；不写的话小样本时可能一边 40%、一边 25%，指标全乱。
5. **自查 EPV**：事件数 ÷ 入模变量数。小于 10 就该减变量或换模型，别硬上。

```python
from sklearn.model_selection import train_test_split

df['pm25'] = df['pm25'].fillna(df['pm25'].median())          # 连续：中位数
df = pd.get_dummies(df, columns=['region_type'], drop_first=True, dtype=int)

X, y = df[FEATURES], df['high_risk']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, stratify=y, random_state=42)
X_test = X_test.reindex(columns=X_train.columns, fill_value=0)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 阳性率 | `y.mean()`＝正例数 ÷ 总样本数 | 422 ÷ 1200 = **35.17%** |
| 各列缺失率 | `df[col].isnull().mean()` | 0%（构造数据无缺失） |
| EPV | 训练集事件数 ÷ 入模变量数 | 295 ÷ 10 = **29.5**（≥10，通过） |
| 训练/测试样本数 | `len(X_train)`、`len(X_test)` | **840 / 360** |
| 入模变量数 | `X_train.shape[1]`（哑变量展开后） | 10 |

**要画什么图**：这步不出正式图。可选：**缺失率条形图**（横轴列名、纵轴缺失率），放附录；正文用清洗对比表就够。

**论文呈现**：一张"清洗前后对比表"（样本量、缺失填补方法、最终变量数）+ 一句"EPV=29.5，满足 ≥10 的经验要求"。

**常见坑**：

- **先划分、再算填补用的中位数**。用全量数据算中位数再填，测试集信息就漏进了训练集。
- 哑变量在划分**前**做没问题，但列必须对齐；训练集没有的类别（测试集新出现）只能丢掉或归到"其他"。
- 标签是 0/1 时别做"标准化"，它没有意义。

#### ② 基线模型：先跑一个"最笨"的

**做什么（按顺序）**：

1. 对 0/1 直接跑 OLS：`LinearRegression().fit(X_train, y_train)`，输出 `predict()` 当作"概率"。
2. 统计**预测值越界**的样本数与比例——这是 LPM 最致命的证据，比任何文字都有说服力。
3. 算 Brier 与 AUC，作为后面逻辑回归的对照底数。

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import brier_score_loss, roc_auc_score

lpm = LinearRegression().fit(X_train, y_train)
p_lpm = lpm.predict(X_test)
out = ((p_lpm < 0) | (p_lpm > 1)).mean()                 # 越界比例
brier = brier_score_loss(y_test, np.clip(p_lpm, 0, 1))    # 必须先 clip，否则 sklearn 报错
auc = roc_auc_score(y_test, p_lpm)                        # AUC 只用排序，不用 clip
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 越界比例 | `((p<0) \| (p>1)).mean()` | 51 ÷ 360 = **14.2%**（范围 −0.456 ~ 1.222） |
| Brier | `mean((p − y)²)`，即"概率误差的平方平均" | 0.1489 |
| AUC | 随机取一正一负，正例得分更高的概率 | 0.8513 |

**要画什么图**：**预测概率直方图**——横轴 LPM 的预测概率、纵轴样本数，画 0 和 1 两条竖线，把越界部分涂成红色。这是"为什么必须换逻辑回归"最直观的一张证据图。

**论文呈现**：对比表第一行；正文一句"LPM 有 14.2% 的样本预测概率落在 [0,1] 之外"，直接点名它为什么不能当概率用。

**常见坑**：

- sklearn 1.9 的 `brier_score_loss` **不接受 >1 的概率**，会直接抛错，所以先 `np.clip`；但 AUC 不要 clip，clip 会改变排序的平局结构。
- 别用 R² 评价 0/1 模型——那是线性回归的指标，这里只看 Brier / AUC。

#### ③ 拟合：两个口径，各取所需

**做什么（按顺序）**：

1. `statsmodels` 拟合（拿统计量）：`sm.Logit(y, sm.add_constant(X)).fit(disp=0)`。
2. 取 `params`（β）、`bse`（标准误）、`tvalues`（z）、`pvalues`、`conf_int()`。
3. **OR = exp(β)**；OR 的 95%CI = `exp(conf_int())`。这一步是逻辑回归论文的核心表。
4. `sklearn` 再拟合一遍（拿概率、接交叉验证），两套结果应当很接近；差太多说明正则太强或没收敛。
5. 想横向比强弱，就**标准化后再拟合**：OR 变成"每增加 1 个标准差"的效应。

```python
import statsmodels.api as sm
import numpy as np

res = sm.Logit(y_train, sm.add_constant(X_train)).fit(disp=0)
or_tab = pd.DataFrame({
    'beta': res.params, 'se': res.bse, 'z': res.tvalues, 'p': res.pvalues,
    'OR': np.exp(res.params),
    'CI_low': np.exp(res.conf_int()[0]), 'CI_high': np.exp(res.conf_int()[1]),
}).round(3)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 系数 β | 极大似然解 | PM2.5：0.047 |
| OR | `exp(β)` | PM2.5：**1.048**（每涨 1 μg/m³，几率 ×1.048） |
| 95%CI | `exp(β ± 1.96·se)` | PM2.5：[1.028, 1.069] |
| 伪 R²（McFadden） | `1 − llf / llnull` | **0.3722** |
| LLR | `−2(llnull − llf)`，df = 变量数 | 405.29，p = 7.1e−81 |
| AIC / BIC | `−2llf + 2k` / `−2llf + k·ln n` | 705.66 / 757.72 |

> 这些量 statsmodels 都直接给：`res.prsquared`、`res.llr`、`res.llr_pvalue`、`res.aic`、`res.bic`，不用手算。

**要画什么图**：这步先不出终稿。可画一版**系数点图**（横轴 β、纵轴变量、带 95%CI）自查符号；正式的 OR 森林图放到第⑦步。

**论文呈现**：OR 表放正文（β、OR、95%CI、p 四列是底线）；伪 R² 一句话带过；AIC/BIC 放脚注或附录。

**常见坑**：

- **完全分离**：某个变量一出现 y 就必为 1，MLE 不收敛、OR 变成天文数字。处理：删该变量，或改用带 L2 的 `LogisticRegression(C=1.0)`。
- 统计口径（statsmodels）和预测口径（sklearn）系数不会完全相同——sklearn 默认带正则，论文主表用 statsmodels，别混着报。

#### ④ 检验：四个检验，四个问题

**做什么（按顺序）**：

1. **LLR**：看模型整体有没有用，`res.llr_pvalue`。
2. **Wald**：看每个系数显不显著，`res.pvalues`；同时看 OR 的 CI 是否跨 1。
3. **VIF**：每个自变量对其余变量回归，`VIF = 1/(1−R²)`；或算条件数 `κ = √(λmax/λmin)`。
4. **HL**：把预测概率按十分位分组，比较每组"观测事件数"与"期望事件数"。

```python
from sklearn.linear_model import LinearRegression

def vif_table(X):
    out = {}
    for c in X.columns:
        r2 = LinearRegression().fit(X.drop(columns=c), X[c]).score(X.drop(columns=c), X[c])
        out[c] = 1 / (1 - r2)
    return out

def hosmer_lemeshow(y, p, g=10):
    d = pd.DataFrame({'y': y, 'p': p})
    d['bin'] = pd.qcut(d.p.rank(method='first'), g, labels=False)
    chi2 = sum((grp.y.sum() - grp.p.sum())**2 / (grp.p.sum() * (1 - grp.p.sum()/len(grp)))
               for _, grp in d.groupby('bin'))
    return chi2, g - 2, 1 - chi2_dist.cdf(chi2, g - 2)
```

**要算的数据，怎么算**：

| 检验 | 统计量怎么来 | 通过标准 | 本案例 |
|---|---|---|---|
| LLR | `−2(llnull − llf)`，df = 变量数 | p < 0.05 | 405.29，p < 0.001 ✅ |
| Wald z | `z = β / se`，p 双侧正态 | p < 0.05 且 CI 不跨 1 | 7 个显著、3 个不显著 |
| VIF | `1/(1−R²ⱼ)` | <10（严格 <5） | 最大 **4.47** ✅ |
| 条件数 | `√(λmax/λmin)`，对相关矩阵 | <100 | **4.59** ✅ |
| HL | `Σ (O−E)² / [E(1−E/n)]`，df = g−2 | p > 0.05 | χ²=7.98，p=**0.436** ✅ |

**要画什么图**：**校准曲线**——横轴预测概率（十分位组均值）、纵轴实际发生率、加 45° 对角线，图注写 HL 的 χ² 与 p。VIF 可画横向条形图放附录。

**论文呈现**：一段"模型检验"，四个数各一句；VIF 表放附录，正文只写最大值。

**常见坑**：

- HL 的 p 值对分组数敏感（g=10 是惯例），换 g 结论可能翻转，论文里要写清 g。
- VIF 只对连续变量有意义；哑变量算 VIF 会天然偏高，别拿它下结论。
- 四个检验缺一个都会被追问，尤其是校准（HL），很多队伍直接不报。

#### ⑤ 变量筛选：三选一，别混用

**先搞清楚这一步在干什么**：

10 个变量全塞进模型，会有三个麻烦：① 不显著的变量每个都在"分走"自由度，EPV 掉下来，系数不稳；② 互相重复的变量（共线）让系数方差变大、符号乱跳；③ 论文里 10 行 OR 表，评委看不出重点。
变量筛选就是**在"解释力"和"简洁"之间做一次取舍**：删掉那些"删了也不怎么损失解释力"的变量。

**三种做法不是三个步骤，而是三把尺子**——量的是同一件事（这个变量该不该留），只是判据不同：

| 做法 | 判据（拿什么量） | 什么叫"该删" | 适合什么时候 |
|---|---|---|---|
| **p 值向后剔除** | 这个系数显不显著（Wald 检验） | p > 0.05 就删，重拟合后再判断 | 变量不多、论文要报 p 值 |
| **AIC 向后剔除** | 删它之后拟合变差多少 vs 少一个参数省下的惩罚 | 删了 AIC 变小就删 | 想同时兼顾拟合与复杂度 |
| **LASSO（L1）** | 惩罚项把系数压向 0 | 系数被压成 0 就淘汰 | 变量几十个、共线严重 |

> **一句话**：p 值问"它单独显著吗"，AIC 问"删了它整体划算吗"。
> 两者会打架——本案例 p 值踢了 3 个，AIC 反而**变差 1.65**：说明这 3 个变量单看都不显著，合起来仍有信息（人口密度、人均 GDP 与路网密度强相关，单独看时"功劳"被抢走了）。

**做什么（按顺序）**：

1. **向后剔除**（最贴近教材 §6 的偏 F 思路）：拟合全模型 → 找 p 最大的变量 → 若 p>0.05 剔除 → 重拟合 → 重复。
2. 或者按 **AIC** 选：同样逐次剔除，但比较的是 AIC 而不是 p 值。
3. 变量特别多时用 **LASSO**：`LogisticRegression(penalty='l1', solver='liblinear')`，看哪些系数被压成 0。

```python
keep = list(FEATURES)
while True:
    r = sm.Logit(y_train, sm.add_constant(X_train[keep])).fit(disp=0)
    ps = r.pvalues.drop('const')
    if ps.max() <= 0.05 or len(keep) <= 1:
        break
    keep.remove(ps.idxmax())      # 每次只踢一个，重拟合后再判断
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 剔除顺序 | 每轮被踢变量的 p 值 | 人口密度(0.358) → 纬度(0.082) → 人均 GDP(0.053) |
| 保留变量数 | `len(keep)` | 10 → **7** |
| AIC 对比 | 全模型 vs 精简模型 `res.aic` | 705.66 → **707.31**（反而 +1.65） |
| 精简模型伪 R² | `res.prsquared` | 0.3652 |

**要画什么图**：这步主要出表。若想图示，画**剔除路径图**（横轴剩余变量数、纵轴 AIC），一眼看出 AIC 在哪一步开始变差。

**论文呈现**：一张"全模型 / 精简模型"的 AIC + 伪 R² 对比表，说明选了哪个、为什么。

**常见坑**：

- **p 值和 AIC 打架时不能两头都占**。本案例 p 值踢了 3 个，AIC 反而变差，正确写法是"保留全模型并说明原因"，而不是假装没看见。
- 逐步筛选会让 p 值失真（多重比较），论文里别把筛选后的 p 当成严格的显著性检验。

#### ⑥ 阈值：0.5 是习惯，不是定理

**做什么（按顺序）**：

1. 用测试集概率画 ROC：`roc_curve(y_test, p)` 得到 `fpr, tpr, thr`。
2. 算 Youden 指数 `J = tpr − fpr`，取 `argmax` 对应的阈值。
3. 分别在 0.5 和最优阈值下算混淆矩阵四格，再算四个指标。
4. **阈值应该在验证集/训练集上定，测试集只报告一次**，否则等于拿测试集调参。

```python
from sklearn.metrics import roc_curve, confusion_matrix

fpr, tpr, thr = roc_curve(y_test, p_logit)
best_thr = thr[np.argmax(tpr - fpr)]          # Youden 点

def report(th):
    tn, fp, fn, tp = confusion_matrix(y_test, (p_logit >= th)).ravel()
    acc = (tp + tn) / (tp + tn + fp + fn)
    rec = tp / (tp + fn)
    pre = tp / (tp + fp)
    return dict(阈值=th, TP=tp, FP=fp, FN=fn, TN=tn, 准确率=acc, 召回=rec, 精确=pre, F1=2*pre*rec/(pre+rec))
```

**要算的数据，怎么算**：

| 数据 | 公式 | 0.5 阈值 | 0.327 阈值 |
|---|---|---|---|
| TP / FP / FN / TN | `confusion_matrix` 展开 | 82 / 33 / 45 / 200 | 104 / 59 / 23 / 174 |
| 准确率 | `(TP+TN) / N` | 0.7833 | 0.7722 |
| 召回率 | `TP / (TP+FN)` | 0.6457 | **0.8189** |
| 精确率 | `TP / (TP+FP)` | 0.7130 | 0.6380 |
| F1 | `2PR / (P+R)` | 0.6777 | **0.7172** |

**要画什么图**：**ROC 曲线**（标出 Youden 点与对应阈值）+ **混淆矩阵热图**（2×2，四格标 TP/FP/FN/TN 与数量）。这两张是阈值这步的交付物。

**论文呈现**：一张双阈值对比表；正文一句"漏判高风险区的代价更高，故取较低阈值"，把代价不对称讲出来。

**常见坑**：

- 只看准确率会漏掉"漏判"这个更贵的错误（本案例准确率还降了，但漏判少了一半）。
- 阈值不是模型的超参数，改阈值不改模型，别写成"调参得到 0.327"。

#### ⑦ 解释与对比：一张图讲完"谁重要、多重要、多确定"

**做什么（按顺序）**：

1. **标准化系数**：对自变量做 z-score 再拟合，得到"每 1 个标准差"的 β，按 |β| 排序——这才是能横向比的强弱。
2. **OR 森林图**：横轴 OR（对数刻度）、竖轴变量，点和 95%CI，p<0.05 加星号。
3. **ROC 叠图**：逻辑回归 / LPM / 单树 / 随机森林放同一张图。
4. **校准曲线**：按十分位画"预测均值 vs 实际发生率"，贴对角线才算概率可信。

```python
mu, sd = X_train.mean(), X_train.std(ddof=0)
res_z = sm.Logit(y_train, sm.add_constant((X_train - mu) / sd)).fit(disp=0)

order = np.exp(res_z.params[1:]).sort_values()
plt.errorbar(order.values, range(len(order)),
             xerr=[order.values - np.exp(res_z.conf_int()[0][1:]),
                   np.exp(res_z.conf_int()[1][1:]) - order.values],
             fmt='o'); plt.xscale('log'); plt.axvline(1, ls='--')
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 标准化 β | z-score 后拟合的系数，按绝对值排序 | PM2.5 **0.712** 排第一，OR=2.04 |
| 各模型 AUC | `roc_auc_score` | Logit 0.852 / RF 0.855 / 树 0.806 / LPM 0.851 |
| Brier | `mean((p−y)²)` | Logit 0.1467 / RF 0.1468 |
| 训练-测试差 | 训练 AUC − 测试 AUC | Logit **0.028** / RF 0.091 |

**要画什么图**：**OR 森林图**（对数横轴、OR=1 参考线、95%CI、显著性星号）+ **多模型 ROC 叠加**（4 条线 + AUC 图例）+ 校准曲线。三张一起，就是逻辑回归的"解释三件套"。

**论文呈现**：森林图与 ROC 并排；校准曲线放附录，正文一句"HL 检验 p=0.436，校准良好"。

**常见坑**：

- 森林图横轴一定要用**对数刻度**，否则 OR<1 的一侧会被压扁。
- 只报点估计不报 CI，等于把"不确定"藏起来；评委专看这个。
- 把训练集 AUC 当模型性能——本案例 RF 训练 0.946、测试 0.855，差的 0.09 才是重点。

## 第五层：评价 —— 怎么判断它好不好

**一句话**：判别力看 AUC，概率质量看 Brier 与校准，结论可信度看 OR 的置信区间——**三个层次，别混成一个"准确率"**。

| 维度 | 表现 |
|---|---|
| **概率指标（主）** | **Brier**、LogLoss、HL 校准 |
| **排序指标（辅）** | **AUC**、KS |
| **分类指标（看场景）** | 准确率、召回率、精确率、F1 |
| **基线** | 线性概率模型 / 均值模型（全预测多数类） |
| **对异常值** | 敏感（比线性回归更敏感） |
| **对噪声特征** | 不敏感（系数会趋近 0，但会吃掉自由度） |
| **小样本** | 不稳，EPV<10 时 OR 基本不可信 |
| **过拟合** | 中等风险：变量多时明显，靠正则/筛选控制 |
| **可解释性** | 强：OR + CI + p，能直接写进结论 |

### 三条容易被忽略的规律

> **① 排序能力和概率质量是两件事。**
> 本案例 LPM 的 AUC = 0.851，逻辑回归 0.852，几乎一样；但 LPM 有 14.2% 的样本概率越界。
> **AUC 只关心"谁排前面"，不关心"这个数是不是概率"。**

> **② 单因素 OR 会骗人。**
> PM2.5 的单因素 OR = 4.36，放进多因素模型后只剩 2.04——因为单因素模型里，它顺带替"工业占比、能耗强度"这些相关变量背了锅。
> **论文里报的必须是多因素 OR，单因素 OR 只能作辅助。**

> **③ 准确率会骗人。**
> 阈值 0.5 时准确率 0.783，阈值降到 0.327 后准确率**反而降到 0.772**，但漏判的高风险区从 45 个减到 23 个。
> **"准确率高"和"判得对且不漏"不是一回事。**

## 第六层：比赛 —— 怎么把它写进论文

**一句话**：评委要的不是"我用了逻辑回归"，而是"**系数能解释、对比有基线、局限写得诚实**"。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 实验成功/失败的二分类 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐⭐ 主战场 | 体育胜负、行为是否发生、用户是否流失 |
| D 运筹 | ⚠️ 偶尔 | 作为优化模型的前置"概率输入" |
| **E 环境** | ⭐ 常见 | 是否超标、是否高风险区（本案例） |
| **F 政策** | ⭐⭐ 常见 | 哪些地区/人群更可能参与、退出、违规 |

### 三个典型场景

1. **C 题·行为预测**：预测"这一分/这一场是否赢"，再用 OR 解释哪个因素最关键（和随机森林笔记里的网球案例是同一份问题的两种解法）。
2. **F 题·政策异质性**：哪些地区更可能"通过/退出/违规"，OR 直接回答"谁更敏感"，比聚类更容易写结论。
3. **E 题·风险分级**：判定"是否高风险区"，再用概率排序分配监管资源——**概率比 0/1 更有用**。

> 你库里的 O 奖笔记有现成用例：2020 C 题有队伍把"有用性投票率"当因变量做多元 Logistic 回归（C-2010638）；2025 F 题有队伍用多层无序多分类 logistic 建模"网络犯罪在何处成功/被阻/被起诉"（见《CEF80_创新点索引》）。这说明逻辑回归在美赛里**不是"基础模型"而是"结论模型"**——它负责给政策建议提供可解释的系数。

### 论文呈现顺序

```
1. 变量表 + 描述统计（含阳性率）
2. 模型对比表（LPM / Logit / 树 / RF）      ← 必须有
3. OR 表（β、OR、95%CI、p）                ← 逻辑回归的灵魂
4. 共线性与变量筛选（VIF/κ、单因素 vs 多因素）
5. ROC + 校准曲线
6. 阈值与混淆矩阵（说明为什么不用 0.5）
```

### 局限性写法（可直接改）

> "逻辑回归把对数几率写成特征的线性组合，系数可直接转成 OR，适合回答'哪个因素影响多大'；但它假设**关系线性于 logit**，无法自动捕捉阈值与交互，且强共线或完全分离时系数会不稳定。本文用 VIF 与条件数检验共线性（最大 VIF = 4.47、κ = 4.59，属轻度），用 Hosmer-Lemeshow 检验校准（χ² = 7.98，p = 0.436，通过），并报告 OR 的 95% 置信区间而非只看点估计。模型在测试集上 AUC = 0.852、Brier = 0.147，与随机森林（0.855 / 0.147）基本持平，但训练—测试 AUC 差距仅 0.028（随机森林 0.091）——说明这份数据的判别信息主要来自线性结构；若关系呈阈值型，应改用分箱或树模型。"

> 注意最后一句：**"判别信息主要来自线性结构"**——主动承认"复杂模型没赢"，比硬吹更得分。

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **Logit + 随机森林** | 线性 vs 非线性的标准对比（本案例两者持平，正好讲"可解释性溢价"） |
| **Logit + 分箱** | 把连续变量切段后再进模型，捕捉阈值效应 |
| **Logit + LASSO** | 变量多时自动筛选，还能防过拟合 |
| **Logit → 评分卡（WOE/IV）** | F 题政策评分：把 OR 变成"加分项/减分项" |
| **PCA + Logit** | 先降维再分类，治强共线（下一份 PCA 笔记会用同一份数据） |

### 三个常见扣分点

1. **只报准确率** → 阈值一换就变，不平衡时更骗人；至少报 AUC + 召回率。
2. **把 OR 说成"概率提高 x 倍"** → OR 是**几率比**；发生率 35% 时，OR=2 对应的概率增幅远小于 2 倍。正确写法："几率变为 2.04 倍，对应概率从 25% 升到 42%"。
3. **只放全模型、不报 CI、不查共线** → 评委一眼看出系数不稳；至少给 VIF 表和 95%CI。

### 第 1 步：划分与基线

**三条读表规则**（比数字本身更重要）：

1. **看 CI 不看星号**：`能耗强度` OR=4.825，但 CI 是 [1.402, 16.603]——跨度 12 倍，说明这个 OR 很不稳（因为它和 PM2.5、工业占比相关）。
2. **OR 的单位是"变量自己的单位"**：PM2.5 每涨 1 μg/m³，几率 ×1.048；能耗强度每涨 1 吨标煤/万元，几率 ×4.825。**不能直接比 4.825 > 1.048 就说能耗更重要**——量纲不同。

### 第 3 步：标准化系数（谁更重要）

| 绿化覆盖率 | −0.509 | 0.601 | 高 1 个 SD，几率降 40% |

| 人口密度 | 0.156 | 1.169 | p=0.358，不显著 |

### 第 4 步：共线性与变量筛选

**VIF**（>10 严重，>5 需警惕）：

```
路网密度     4.47     PM2.5 浓度   2.41
人均 GDP     3.56     绿化覆盖率   2.33
人口密度     3.33     能耗强度     2.21
年均风速     2.45     第二产业占比  2.13
                       环保支出占比  2.05
                       纬度        1.01
```

**条件数**（教材 §7 口径）：

```
κ = √(λmax/λmin) = 4.59  → 轻度复共线性
```

两种口径的分工：**VIF 告诉你"哪个变量被别的变量解释太多"，条件数告诉你"整体设计矩阵有多接近奇异"**。本案例都在安全区，但已经能看到后果——

**单因素 vs 多因素 OR**（共线性怎么"摊薄"系数）：

| 指标 | 单因素 OR | 多因素 OR | 倍数变化 |
|---|---|---|---|
| PM2.5 浓度 | 4.358 | 2.037 | **0.47** |
| 第二产业占比 | 2.721 | 1.491 | 0.55 |
| 能耗强度 | 2.625 | 1.423 | 0.54 |
| 年均风速 | 0.475 | 0.724 | 1.52 |
| 绿化覆盖率 | 0.465 | 0.601 | 1.29 |

> **PM2.5 的 OR 从 4.36 掉到 2.04，一半的效应被相关变量"分走"了。** 这不是 bug，是共线性的必然结果。

**向后剔除**（p > 0.05 逐个删）：

```
剔除顺序：人口密度(p=0.358) → 纬度(p=0.082) → 人均 GDP(p=0.053)
保留 7 个变量
全模型 AIC = 705.66 → 精简模型 AIC = 707.31（变化 +1.65）
```

> **两个准则打架了**：p 值说"这三个不显著"，AIC 说"删了反而更差"。结论是**保留全模型并说明**——因为被删的三个合起来仍提供信息。论文里必须交代一句，不能装作没看见。

### 第 5 步：阈值与混淆矩阵

**Youden 最优阈值 = 0.327**（不是 0.5）：

|---|---|---|---|---|---|---|
| 0.500（习惯） | **0.7833** | 0.6457 | 0.7130 | 0.6777 | 82/33/45/200 | **45** |
| 0.327（Youden） | 0.7722 | **0.8189** | 0.6380 | **0.7172** | 104/59/23/174 | **23** |

> **准确率降了，但漏判少了一半。** 监管场景里，"漏掉一个高风险区"的代价远大于"多查一个非高风险区"，所以应该用 0.327，而且要在论文里把**代价不对称**讲出来。

| 模型 | Brier↓ | LogLoss↓ | AUC↑ | 准确率↑ | 训练AUC | 训练-测试差 |
|---|---|---|---|---|---|---|

3. **LPM 的 AUC 几乎不输**（0.851 vs 0.852），但 Brier 更差（0.149 vs 0.147），且有 14.2% 概率越界——**排序能力不等于概率质量**。

## 三、结果解读（论文结论段可直接用）

- 控制其他因素后，**PM2.5 浓度是第一驱动**（标准化 OR = 2.04，p<0.001）；路网密度（1.78）、第二产业占比（1.49）、能耗强度（1.42）次之；
- **保护因素方向全部符合预期**：绿化覆盖率 OR = 0.60、环保支出占比 0.68、人均 GDP 0.67、年均风速 0.72，且均显著；
- **模型判别力 AUC = 0.852、Brier = 0.147**，与随机森林（0.855 / 0.147）基本持平，但逻辑回归的训练-测试差距只有 0.028，**更稳、更可解释**；
- **共线性造成系数摊薄**：PM2.5 的单因素 OR 为 4.36，多因素降到 2.04；因此本文只把多因素 OR 作为结论依据；
- 阈值从 0.5 降到 0.327 后，**漏判从 45 个减到 23 个**，代价是多查 26 个非高风险区——按监管成本核算，这个交换是划算的。

**给监管部门的建议**（E 题必写的一段）：

> 资源应优先投向 **PM2.5 浓度高、路网与工业密度大、且绿化与环保投入偏低** 的区县；在同等风险概率下，**提高环保支出占比与绿化覆盖率是最可控的两个抓手**（因为它们是"投入型"变量，不像 PM2.5 那样受气象影响）。按 0.327 的阈值排查，可把漏判控制在 23 个以内，年度核查工作量约增加 26 个区县。

Hosmer-Lemeshow 检验（statsmodels 没有现成的，自己写）：

```python
def hosmer_lemeshow(y_true, p, g=10):
    d = pd.DataFrame({'y': y_true, 'p': p})
    d['bin'] = pd.qcut(d.p.rank(method='first'), g, labels=False)
    chi2 = 0.0
    for _, grp in d.groupby('bin'):
        n_g, o_g = len(grp), grp.y.sum()
        e_g = grp.p.sum()
        chi2 += (o_g - e_g) ** 2 / (e_g * (1 - e_g / n_g))
    return chi2, g - 2, 1 - chi2_dist.cdf(chi2, g - 2)
```

### 三个环境坑（我踩过，写下来省你时间）

1. **sklearn 1.9 的 `brier_score_loss` 会直接报错**：线性概率模型的预测值超过 1 时，它抛
   `ValueError: y_prob contains values greater than 1`。必须先用 `np.clip(p, 0, 1)` 再算指标。
2. **`sm.Logit` 遇到完全分离会不收敛**：报 `Perfect separation or prediction` 或给出巨大 OR。处理办法：删掉那个变量，或改用 `sklearn.LogisticRegression(penalty='l2', C=1.0)`（正则化能把系数压住）。
3. **`pd.qcut` 分箱时若预测值重复太多会报 bins 不唯一**：本 demo 用 `rank(method='first')` 先打散，保证 10 组等量。评委不会问，但你自己跑的时候会遇到。

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 预测 0/1 事件概率 + 用 OR 解释每个因素的影响 |
| 核心思想？ | 把 logit(p) 写成线性组合，用极大似然估系数 |

| 最大硬伤？ | 抓不到阈值/交互；共线时 OR 不可信；OR≠RR |
| 关键超参？ | `C`（正则倒数）、`penalty`、`class_weight` |
| 论文必写？ | OR 表（带 CI）+ 模型对比表 + ROC + 校准 + 阈值说明 |

## 自测三问

1. 逻辑回归为什么用极大似然，而不是像线性回归那样用最小二乘？换成 OLS 会怎样？
2. PM2.5 的单因素 OR = 4.36，多因素 OR = 2.04，论文里该报哪个？为什么差这么多？
3. 评委问："你这模型准确率只有 77%，能用吗？"你怎么答？

<details>
<summary>参考答案</summary>

1. 因为 y 是 0/1，误差方差 `p(1−p)` 随均值变，违反同方差；而且 OLS 的预测值 `Xβ` 会跑出 [0,1]（本案例 14.2% 越界）。极大似然直接对"观测到这份 0/1 数据的概率"求最大，得到的估计一致、有效，而且对数似然是凸函数，有唯一最优解。

2. 报**多因素 OR**。单因素模型里没有控制其他变量，PM2.5 顺带代表了"工业占比、能耗强度"这些与它高度相关的因素，所以 OR 被放大；多因素模型把它们的效应拆开后，PM2.5 只剩 2.04。差一倍不是数据错误，是共线性的正常表现——所以论文必须报 VIF 并说明。

3. "准确率 77% 是在阈值 0.5 下的数字，而 0.5 只是习惯。本模型 AUC = 0.852，说明排序能力良好；如果把阈值调到 0.327（Youden 点），召回率从 0.65 提到 0.82，漏判从 45 个降到 23 个，代价是多查 26 个区县。对监管场景来说，漏判的代价更高，所以这个交换是划算的。"——**用代价说话，不要用准确率辩解**。

</details>
