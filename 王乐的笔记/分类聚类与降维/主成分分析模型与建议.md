# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：把很多个**互相相关**的指标，换成少数几个**互不相关**的新指标（主成分），并且尽量少丢信息。

| 问题 | 回答 |
|---|---|
| 核心问题 | 指标太多且互相重叠，能不能压成几个"说得清"的维度？能不能据此算一个综合指数 |
| 输入 | `n × p` 数值矩阵，**没有标签**（也不需要） |
| 输出 | 主成分得分（新坐标）+ 载荷矩阵 + 解释率 + 综合指数 |
| 数据类型 | 连续数值型；类别变量不适用 |
| 方法类别 | 无监督 → **线性降维**（正交变换） |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **因子分析（FA）** | 假设"有潜在构念"，能旋转出更好解释的因子 | 想找"潜在维度"、要旋转（方差最大化） |
| **LDA 线性判别** | **有监督**降维，找"最能分开类别"的方向 | 有标签、目标是分类 |
| **稀疏 PCA** | 载荷稀疏，变量可筛选 | 变量极多、想要"哪几个变量组成的" |
| **t-SNE / UMAP** | 非线性，保局部结构 | 只为可视化、不要求可解释 |
| **直接加权（熵权/等权）** | 人为定权 | 指标少、权重有业务依据 |
| **主成分回归（PCR）** | PCA + 回归 | 共线严重时替代 OLS |

### 一句话选型

> **指标多 + 强相关 + 要降维/赋权 → PCA；要找"潜在构念" → 因子分析；有标签、要分类 → LDA；只为画图 → t-SNE。**

## 第二层：假设 —— 它成立的前提

**一句话**：PCA 的假设少，但有一条很隐蔽——**它默认"方差大 = 信息多"**，而这条在噪声面前经常不成立。

| # | 假设 | 含义（大白话） | 违反了会怎样 |
|---|---|---|---|
| 1 | **线性** | 主成分是原始变量的线性组合 | 非线性流形（如"环形"）会被压坏 |
| 2 | **方差 = 信息** | 方差越大的方向越重要 | 一个高方差的噪声变量会独占第一主成分（本案例的纬度就是） |
| 3 | **指标之间要有相关性** | 没相关性就没有"重叠信息"可压 | 各指标近似独立时，PCA 等于没做（每个主成分≈一个原变量） |
| 4 | **连续数值 + 近似线性关系** | 相关系数要有意义 | 类别变量、强非线性关系（如 U 形）会低估真实关联 |
| 5 | **样本量足够** | 经验：n ≥ 5p，或 n ≥ 100 | 相关矩阵不稳，主成分方向乱跳 |
| 6 | **量纲统一（标准化）** | 否则方差被单位绑架 | 第一主成分变成"数值最大的那个变量" |

### 它**不需要**的假设

- ❌ 不需要正态分布
- ❌ 不需要样本独立（但时序数据要小心）
- ❌ 不需要标签
- ❌ 不需要主成分有物理意义（但**论文里必须给它起名字**）

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **只能线性** | 主成分是线性组合 | 非线性结构压不出来 |
| **方差 ≠ 重要性** | 噪声也可能方差大 | 本案例 PC4 就是纯噪声（纬度）独占 10% |
| **主成分难命名** | 它是构造出来的，不是原始指标 | 常见"PC3 说不清是什么"，只能说"综合因素" |
| **载荷符号任意** | 特征向量乘 −1 仍是解 | 不同软件/版本符号可能相反，必须自己定符号 |
| **降维有信息损失** | 丢掉的是"方差小"的方向 | 而"方差小"的方向有时恰恰能区分目标 |
| **对异常值敏感** | 方差被极端值放大 | 一个离群点能改变第一主成分方向 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | ≥ 5 倍变量数；本案例 1200 / 10 = 120，很充裕 |
| 缺失值 | 要先填补（PCA 不吃 NaN） |
| 变量类型 | 连续数值；类别变量先做哑变量（但哑变量的方差含义不同，慎用） |
| 异常值 | 先检查，否则方差被污染 |
| 量纲 | **必须标准化**（用相关矩阵等价于标准化） |
| 相关性 | 先看相关矩阵/KMO；全都接近 0 就别做了 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **换一套坐标轴：让数据在新轴上的方差最大，且新轴两两垂直。方差最大的那根轴就是第一主成分，第二根在与它垂直的方向里方差最大，依此类推。**

### 关键公式

```
① 标准化：      z_ij = (x_ij − x̄_j) / s_j
② 相关矩阵：    R = (1/n) ZᵀZ            （标准化后，协方差矩阵 = 相关矩阵）
③ 特征分解：    R w_k = λ_k w_k           λ1 ≥ λ2 ≥ … ≥ λp
④ 解释率：      λ_k / Σλ
⑤ 载荷：        l_jk = w_jk · √λ_k        （第 j 个变量在第 k 个主成分上的载荷）
⑥ 得分：        F_k = Z · w_k             （每个样本在新坐标上的位置）
```

三句话读懂：

- **特征值 λ 就是这个主成分"能解释多少方差"**；λ 的总和 = 变量个数 p（标准化后每个变量方差为 1）。
- **载荷 l 是"变量与主成分的相关系数"**，绝对值越大，说明这个变量对这个主成分贡献越大——命名就靠它。
- **得分 F 是新的坐标**，可以拿去做回归、聚类、排序。

### 核心一步：相关矩阵的特征分解

这一步等价于对标准化数据做 **SVD**，也等价于"找让投影方差最大的方向"。三种说法是一回事：

| 说法 | 数学形式 | 直觉 |
|---|---|---|
| 最大化投影方差 | `max Var(Zw), s.t. ‖w‖=1` | 让点在新轴上摊得最开 |
| 特征分解 | `Rw = λw` | 相关矩阵的特征向量就是方向 |
| 奇异值分解 | `Z = UΣVᵀ`，`w = V` 的列 | 数值上最稳的算法（sklearn 默认） |

> **为什么方差大 = 信息多？** 因为如果所有样本在某方向上几乎一样（方差≈0），那个方向就区分不了任何对象。但反过来不成立：**方差大也可能是噪声大**。这是 PCA 最需要警惕的地方。

### 机制拆解

| 机制 | 怎么做 | 作用 |
|---|---|---|
| **标准化** | 减均值、除标准差 | 让每个变量"话语权"相同，否则量纲决定结果 |
| **特征分解** | 对相关矩阵求特征值/特征向量 | 得到一组正交的新轴 |
| **按 λ 排序** | λ 从大到小 | 前面的主成分信息多，后面的接近噪声 |
| **载荷** | 特征向量 × √λ | 把"方向"翻译成"变量贡献"，用于命名 |
| **得分** | 原始（标准化）数据投影到新轴 | 得到可继续建模的新变量 |

### 关键超参数

| 超参数 | 控制什么 | 调大/调小的后果 | 常用范围 |
|---|---|---|---|
| `n_components` | 保留几个主成分 | 小→压缩狠、信息丢；大→没起到降维作用 | 按累计 85% 或 Kaiser |
| `whiten` | 是否把各主成分方差归一 | 开了之后各成分等权，适合后续用距离的模型 | 一般 `False` |
| `svd_solver` | 数值算法 | `full` 精确、`randomized` 快（大样本） | 默认 `auto` |

> PCA 几乎没有"要调"的超参数——真正要决策的只有**保留几个**，而这靠准则 + 业务判断，不靠网格搜索。

### 教材口径对照

| 环节 | 教材第 26 章 §3–§4 | 本文 | 说明 |
|---|---|---|---|
| 出发点 | 指标间相关性强 → 信息重叠 | 同 | 教材案例里 10 个高教指标相关性强 |
| 计算路径 | 相关系数矩阵 → 特征根/特征向量 | 同 | 本文用 `np.corrcoef` + 特征分解复算，与 sklearn 一致 |
| 保留几个 | 看**累计贡献率** | 同，但加了 Kaiser 准则 | 教材案例**前两个已 90.79%，却取到前四个（98.22%）** |
| 综合评价 | 主成分得分加权求和 | 同 | 教材用贡献率做权 |
| 本文补充 | — | KMO/Bartlett、载荷与共同度、降维后建模的代价 | 教材没展开这三块 |

> **教材那个细节值得记住**：前两个主成分已经解释 90.79%，教材却取到四个（98.22%）才做综合评价。
> 这说明**"累计 85%"从来不是硬门槛**——保留几个，取决于你拿它干什么。本文取 4 个（83.2%）也是同样的道理。

### 可解释性：★★☆☆☆

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **载荷矩阵** | 这个主成分由哪些变量构成 | ✅ 命名依据，必须给 |
| **共同度 h²** | 某个变量被保留的成分解释了多少 | ✅ 判断"这个变量有没有被丢掉" |
| **碎石图** | 前几个成分是"真信号"、后面是"碎石" | ✅ 论文标配 |
| **双标图** | 样本与变量在同一张图上 | ⚠️ 二维投影会骗人，要标解释率 |
| **贡献率** | 这个成分占多少信息 | ⚠️ 只说明"方差占比"，不说明"重要性" |

## 第四层：操作 —— 怎么跑起来

**一句话**：PCA 的操作重点不是"算"，而是**证明这组数据适合做（KMO）、证明保留几个合理（准则+业务）、证明降维没白降（对下游任务的影响）**。

### 七步流程（速览）

```
① 标准化            减均值除标准差（不做这步，第一主成分就是方差最大的变量）
② 适用性检验        相关矩阵、KMO、Bartlett
③ 特征分解          特征值、解释率、累计解释率、碎石图
④ 选主成分          Kaiser（λ>1）/ 累计 85% / 碎石拐点，三者常打架
⑤ 载荷 + 共同度     给主成分命名，检查有没有变量被丢掉
⑥ 得分 + 综合指数    加权方式要说明（等权？贡献率？只取第一个？）
⑦ 验证与代价        与目标变量的关系、降维后建模效果对比
```

### 七步详解

> 每一步都给三样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**常见坑**。
> PCA 最容易错的地方不在公式，而在两个细节：**sklearn 的 PCA 只中心化、不标准化**；以及**载荷不是回归系数**。

#### ① 标准化：不标准化 = 没做 PCA

**做什么（按顺序）**：

1. 算各变量方差，确认量纲差异有多大（本案例人口密度方差是 PM2.5 的约 600 倍）。
2. **自己先做 Z-score**，再送进 PCA。这一点必须记住：`sklearn.decomposition.PCA` 默认只做**中心化**（减均值），**不会**除以标准差。
3. 检查异常值：PCA 追方差，一个离群点能把第一主成分的方向拽偏。

```python
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

Z = StandardScaler().fit_transform(df[FEATURES])   # 必须自己标准化
pca = PCA().fit(Z)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 各变量方差 | `X[col].var()` | PM2.5 227；人口密度约 14.2 万 |
| 标准化后方差 | 全部为 1 | 1.0000 |
| 相关系数矩阵 | `np.corrcoef(Z.T)` | 10×10，最强的一对是绿化率—风速 0.740 |

**要画什么图**：不出正式图。可选**方差对比条形图**（对数纵轴），说明量纲差多少倍、为什么必须标准化。

**论文呈现**：方法节一句话"10 个指标经 Z-score 标准化后做 PCA"+ 一张方差对比表（证明为什么必须标准化）。

**常见坑**：

- **直接用 `PCA()` 处理原始数据**：等于对协方差矩阵做分解，第一主成分几乎就是方差最大的那个变量。
- 标准化必须在**训练集**上 `fit`，测试集用同一个 `scaler.transform`，否则泄漏。

#### ② 适用性检验：这组数据配不配做

**做什么（按顺序）**：

1. 算相关矩阵，看有多少对 |r|>0.5——没有相关性就没有"重叠信息"可压。
2. 算 **KMO**：比较"简单相关"与"偏相关"的平方和，衡量能不能用少数因子概括。
3. 做 **Bartlett 球形检验**：原假设是"相关矩阵为单位阵"，要拒绝它（p<0.05）才能做。

```python
import numpy as np
from scipy.stats import chi2

R = np.corrcoef(Z.T)
inv = np.linalg.inv(R)
D = np.diag(1 / np.sqrt(np.diag(inv)))
P = -D @ inv @ D                      # 偏相关矩阵
np.fill_diagonal(P, 0); R0 = R.copy(); np.fill_diagonal(R0, 0)
kmo = (R0**2).sum() / ((R0**2).sum() + (P**2).sum())

n, p = Z.shape
chi2_val = -(n - 1 - (2*p + 5)/6) * np.log(np.linalg.det(R))
p_bartlett = 1 - chi2.cdf(chi2_val, p*(p-1)//2)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 | 判读 |
|---|---|---|---|
| KMO | `ΣΣr² / (ΣΣr² + ΣΣq²)`，q 为偏相关 | **0.768** | >0.8 良好、0.7–0.8 中等、<0.5 不适合 |
| Bartlett χ² | `−(n−1−(2p+5)/6)·ln|R|`，df=p(p−1)/2 | 6453.98，df=45 | p<0.05 才做 |
| Bartlett p | 卡方右尾概率 | **<0.001** | 拒绝"单位阵" ✅ |
| 最强相关对 | `R` 的上三角最大值 | 绿化率—风速 0.740 | 说明确有重叠信息 |

**要画什么图**：**相关矩阵热力图**（10×10，红蓝发散色），图注写 KMO 与 Bartlett 结果；放附录即可。

**论文呈现**：一段"适用性检验"，KMO 与 Bartlett 各一句；KMO 只是"中等"就如实写，别吹成"非常适合"。

**常见坑**：

- KMO<0.5 还硬做，等于强行造维度。
- 相关矩阵接近奇异（有完全共线的变量）时 `det(R)≈0`，`ln` 直接报错或给 −inf，先删冗余变量。

#### ③ 特征分解：看每个成分值多少

**做什么（按顺序）**：

1. 对相关矩阵做特征分解（等价于对标准化数据做 SVD）。
2. 特征值按从大到小排序，算解释率与累计解释率。
3. 画碎石图（特征值对序号），标出 Kaiser 线（λ=1）。

```python
eigval, eigvec = np.linalg.eigh(R)      # eigh 返回升序，要反转
order = eigval.argsort()[::-1]
eigval, eigvec = eigval[order], eigvec[:, order]

ratio = eigval / eigval.sum()           # 总和 = 变量个数 p
cum = np.cumsum(ratio)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 特征值 λ | 相关矩阵的特征根，`Σλ = p` | 3.246 / 2.571 / 1.517 / 0.998 … |
| 解释率 | `λ_k / Σλ` | 32.4% / 25.7% / 15.2% / 10.0% |
| 累计解释率 | `cumsum(解释率)` | 32.4% / 58.1% / 73.3% / **83.2%** |

**要画什么图**：**碎石图**（特征值柱 + Kaiser 线 λ=1）+ **累计解释率折线**（标 85% 线）。两张并排，是"保留几个"的依据。

**论文呈现**：一张"主成分 / 特征值 / 贡献率 / 累计贡献率"表（教材案例就是这张表）+ 碎石图。

**常见坑**：

- `np.linalg.eigh` 返回的是**升序**，忘记反转会把"最后一个主成分"当成第一个。
- 特征向量乘 −1 仍是合法解，符号要在后面统一定（见第⑤步）。

#### ④ 选主成分：准则经常打架

**做什么（按顺序）**：

1. **Kaiser 准则**：保留 λ>1 的（标准化后每个变量贡献 1 个单位的方差）。
2. **累计 85%**：保留到累计解释率 ≥85%。
3. **碎石拐点**：看曲线从陡变缓的位置。
4. 三个结果不一致时，结合"能不能命名"来定，并在论文里写清理由。

```python
kaiser = int((eigval > 1).sum())
pct85 = int(np.searchsorted(cum, 0.85)) + 1
print(kaiser, pct85, cum[3])      # 3, 5, 0.832
```

**要算的数据，怎么算**：

| 准则 | 怎么算 | 本案例的结果 |
|---|---|---|
| Kaiser | `(λ > 1).sum()` | **3 个**，累计 73.3% |
| 累计 85% | `searchsorted(cum, 0.85)+1` | **5 个**，累计 87.1% |
| 最终选择 | 折中 + 可解释性 | **4 个**，累计 83.2% |

**要画什么图**：与第③步共用碎石图 / 累计图，只需在图上**加一条竖虚线标出最终选的个数**；不用另画一张。

**论文呈现**：一句话交代"Kaiser 给 3 个、85% 给 5 个，本文取 4 个，理由是……"。

**常见坑**：

- 为了凑 85% 硬加一个没法命名的成分，反而降低可解释性。
- 教材案例前两个已 90.79%，却取到四个（98.22%）——**85% 不是硬门槛**，取决于你拿它干什么。

#### ⑤ 载荷 + 共同度 + 命名

**做什么（按顺序）**：

1. 算载荷：`载荷 = 特征向量 × √特征值`。注意**不是** `components_` 本身。
2. **统一定符号**：让每个主成分里绝对值最大的那个载荷为正，否则不同版本符号相反，图会"看着不对"。
3. 按 |载荷|≥0.45 挑出每个主成分的主要变量，给它起名字。
4. 算共同度 `h² = Σ载荷²`，检查有没有变量被整体丢掉（h²<0.5 要说明）。

```python
load = pca.components_.T * np.sqrt(pca.explained_variance_)
for j in range(load.shape[1]):
    if load[np.argmax(np.abs(load[:, j])), j] < 0:
        load[:, j] *= -1                       # 统一符号
communality = (load ** 2).sum(axis=1)          # 共同度
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 载荷 | `w_jk · √λ_k` | PM2.5 在 PC1 上 +0.849 |
| 共同度 h² | `Σ_k 载荷²` | 平均 **83.3%**；最低 PM2.5 也有 0.736 |
| 命名依据 | \|载荷\|≥0.45 的变量 | PC1：PM2.5/路网/能耗/二产 正、环保支出 负 →「污染压力」 |

**要画什么图**：**载荷热力图**（行=变量、列=主成分、颜色=载荷）+ **双标图**（样本散点 + 指标箭头）。前者说明"成分由什么构成"，后者说明"样本落在哪"。

**论文呈现**：载荷热力图（变量×主成分）+ 一段命名说明；共同度低的变量在局限性里提一句。

**常见坑**：

- **把载荷当回归系数**：载荷是"变量与主成分的相关系数"，不能说"主成分每增 1 单位，PM2.5 涨 0.85"。
- 不统一符号，不同机器画出来的载荷图一正一负，队友会以为跑错了。

#### ⑥ 得分 + 综合指数

**做什么（按顺序）**：

1. 算得分：`F = Z @ w`（sklearn 里就是 `pca.transform(Z)`）。
2. 若要合成指数，**先想清楚权重怎么来**：等权、按贡献率加权、还是只取 PC1。
3. 把指数 min-max 到 0–100，方便解读与排名。
4. 列出指数最高/最低的各 5 个样本，检查是否符合常识。

```python
F = pca.transform(Z)
w = pca.explained_variance_ratio_ / pca.explained_variance_ratio_.sum()
idx_pc1 = F[:, 0]                        # 只取 PC1
idx_all = F @ w                          # 按贡献率加权
idx_pc1 = 100 * (idx_pc1 - idx_pc1.min()) / (idx_pc1.max() - idx_pc1.min())
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 权重（贡献率归一化） | `λ_k / Σ_{k≤4} λ` | 0.390 / 0.309 / 0.182 / 0.120 |
| 综合指数 | `Σ w_k · F_k`，再 min-max 到 0–100 | 范围 0–100 |
| 两种指数相关性 | `corr(idx_pc1, idx_all)` | r = **0.784**（像，但用途不同） |
| 判别力对比 | 单变量 AUC | PC1 **0.833** vs 加权 **0.661** |

**要画什么图**：**指数分布直方图**，或**排名前 20 的条形图**；若同时做了两种指数（只取 PC1 / 加权），画散点对比并标相关系数。

**论文呈现**：指数表 + 一句"权重如何确定"；如果只想要"污染压力"，就明说只用 PC1。

**常见坑**：

- 把所有主成分都加权进去当"综合指数"——本案例 AUC 从 0.833 掉到 0.661，因为加进去的是"信息量"不是"区分度"。
- 指数不做归一化，量纲看不懂（主成分得分是 z 分数级的数）。

#### ⑦ 验证与代价

**做什么（按顺序）**：

1. 看指数与目标变量的关系：分四组看标签率、算单变量 AUC。
2. **降维前后各跑一次下游模型**（本案例是逻辑回归），比 AUC 与 Brier。
3. PCA 必须**只在训练集上 fit**，再 `transform` 测试集，否则泄漏。
4. 结论写成"有损/无损 + 为什么"，不要只说"效果良好"。

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

Xtr, Xte, ytr, yte = train_test_split(Z, y, test_size=0.3, random_state=42, stratify=y)
pca_tr = PCA(n_components=4, random_state=42).fit(Xtr)     # 只在训练集 fit
lr_pc = LogisticRegression(max_iter=2000).fit(pca_tr.transform(Xtr), ytr)
p_pc = lr_pc.predict_proba(pca_tr.transform(Xte))[:, 1]
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 分组标签率 | 按 PC1 指数四等分，各组 `y.mean()` | 7.0% → 19.7% → 38.7% → **75.3%** |
| 单变量 AUC | `roc_auc_score(y, idx_pc1)` | **0.833** |
| 降维前后 AUC | 两次 `roc_auc_score` | 0.852 → **0.854**（+0.002） |
| 降维前后 Brier | 两次 `brier_score_loss` | 0.1465 → 0.1458 |

**要画什么图**：**分组标签率柱状图**（按指数四等分）+ **降维前后对比条形图**（AUC、Brier 各一组）。这是结论图，放正文。

**论文呈现**：一张"原始 p 指标 vs 前 k 个主成分"的对比表；正文给"有损/无损"的结论。

**常见坑**：

- PCA 在全量数据上 fit 再切分，测试集信息已经进了主成分方向，评估虚高。
- AUC 没掉就说"降维无损"——本案例是数据冗余给的运气，换个数据集可能掉 0.05。
- 只看 AUC 不看 Brier，概率质量的变化会被漏掉。

| 处理 | 要不要做 | 说明 |

| 异常值处理 | ✅ 必须 | 方差被极端值放大 |

## 第五层：评价 —— 怎么判断它好不好

**一句话**：解释率只说明"保住了多少方差"，不说明"保住了多少有用信息"——**要看下游任务**。

| 维度 | 表现 |
|---|---|
| **主指标** | 累计解释率、KMO、共同度 |
| **可解释性** | 载荷是否清晰、能否命名 |
| **对异常值** | 敏感（方差被放大） |
| **对量纲** | 极敏感（必须标准化） |
| **小样本** | 不稳，n < 5p 时主成分方向会跳 |
| **过拟合** | 无监督没有过拟合，但"保留太多"等于没降维 |
| **外推** | 新样本按同一组载荷投影，超出训练范围不可靠 |
| **副作用** | 降维后变量失去物理含义，回归系数无法解释 |

### 三条容易被忽略的规律

> **① 方差大 ≠ 有用。**
> 本案例 PC4 的载荷几乎是"纬度"一个变量（+0.995），解释了 10.0% 的方差——但纬度是故意放的**无关变量**。
> 一个噪声变量，只要方差够大、且与其他变量不相关，就能独占一个主成分。

> **② 把主成分加权成"综合指数"，可能越加越差。**
> 只用 PC1 做判别：AUC = 0.833；把 PC1–PC4 按贡献率加权：AUC **掉到 0.661**。
> 因为加权的是"信息量"，而判别要的是"区分度"。

> **③ 降维未必有损，但也别指望总是无损。**
> 本案例 4 个主成分做逻辑回归 AUC = 0.854，原始 10 指标 0.852——几乎无损，因为指标间确实存在大量冗余（PC1+PC2 已占 58.1%）。
> 但这是"数据本身冗余"给的运气；**如果目标恰好由方差很小的方向决定，PCA 会把它扔掉**。

## 第六层：比赛 —— 怎么把它写进论文

**一句话**：PCA 在论文里通常不是主角，而是**"让主模型跑得动"的那一步**——写清楚"为什么降、降了几个、损失多少"就够了。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 多参数系统的降维/降噪 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐ 常见 | 指标多的预测题、先降维再建模 |
| D 运筹 | ⚠️ 偶尔 | 多目标评价的指标压缩 |
| **E 环境** | ⭐⭐ 主战场 | 指标一大堆（气象/地理/排放），天然适合 PCA |
| **F 政策** | ⭐⭐ 常见 | 合成"发展指数/脆弱性指数"，或给多指标客观赋权 |

### 三个典型场景

1. **E 题·指标太多**：十几二十个环境指标，先 PCA 压到 3–4 维，再聚类或回归。
2. **F 题·合成指数**：把"教育/收入/健康"多指标压成"人类发展指数"式的单一分数。
3. **PCA + TOPSIS 赋权**：用主成分贡献率当权重，替代主观打分（O 奖常见组合）。

> 你库里的 O 奖笔记有现成用法：2023 E 网球动量题用 **PCA + TOPSIS** 处理 5 维 18 指标（前 6 个主成分累计 86.65%）；气候难民题用 PCA 合成"文化损失风险指数"；奥运奖牌题用 PCA 合成"历史实力"一维指标。**共同点：PCA 都不是结论，而是给结论提供输入。**

### 论文呈现顺序

```
1. 变量表 + 标准化说明                    ← 先说量纲
2. 适用性检验（KMO + Bartlett）           ← 很多队漏，写了加分
3. 碎石图 + 累计解释率                    ← 证明保留几个有依据
4. 载荷矩阵（热力图）+ 命名               ← 核心，说明"这几个维度是什么"
5. 主成分得分/综合指数（权重怎么来）
6. 降维前后效果对比                       ← 证明"没白降"
```

### 局限性写法（可直接改）

> "主成分分析将 10 个指标压缩为 4 个互不相关的主成分，累计解释 83.2% 的方差；KMO = 0.768、Bartlett 检验 p<0.001，满足分析前提。前两个主成分分别刻画'污染压力'（32.4%）与'发达—宜居'水平（25.7%），可解释性较好；但第 4 主成分的载荷几乎全部集中在'纬度'（+0.995），说明**未加筛选的无关变量会单独占据一个主成分**——这提示我们应在上游先做变量筛选。另需说明，主成分是原始指标的线性组合，其得分不具备原始单位，本文仅将其用于分组与排序，未对主成分系数作因果解读。"

> 最后一句很重要：**不要对主成分做因果解释**，这是最常见的越界。

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **PCA + TOPSIS / 熵权** | 客观赋权，替代主观打分（E/F 题最常用） |
| **PCA + 聚类** | 先降维再分型，或降维后画 2 维散点（本案例画图就是） |
| **PCA + 回归（PCR）** | 共线严重时替代 OLS，但系数不可解释 |
| **PCA + 逻辑回归** | 先降维再分类（本案例验证：AUC 几乎无损） |
| **因子分析** | 想要"可旋转、可解释"的潜在维度时替换 |

### 三个常见扣分点

1. **不标准化** → 第一主成分就是"数值最大的变量"，等于没做降维。
2. **不报 KMO/Bartlett** → 评委无法判断这组数据是否适合 PCA；KMO 0.5 还硬做，结论不可信。
3. **硬给主成分起名** → 载荷混在一起还非要叫"综合发展水平"，不如老实说"第 3 主成分不易解释，仅用于降维"。

## 二、完整建模流程（7 步）

### 第 1 步：标准化

```
PM2.5：均值 46.20，标准差 15.06（方差 227）
人口密度：均值 549，标准差 377（方差 14 万）
```

> 方差相差约 600 倍。不标准化，第一主成分会被人口密度垄断。

### 第 2 步：适用性检验

```
KMO = 0.768（>0.9 极好，0.8 良好，0.7 中等，0.6 勉强，<0.5 不适合）
Bartlett 球形检验：χ² = 6453.98，df = 45，p = 0.000e+00
```

**判读**：KMO 0.768 属"中等"，Bartlett 显著（相关矩阵明显不是单位阵）。**能做，但不算强**——这也预示了后面"降维收益有限"。

### 第 3 步：特征分解

| 主成分 | 特征值 | 解释率 | 累计解释率 | λ>1？ |
|---|---|---|---|---|
| PC1 | 3.246 | 32.4% | 32.4% | ✅ |
| PC2 | 2.571 | 25.7% | 58.1% | ✅ |
| PC3 | 1.517 | 15.2% | 73.3% | ✅ |
| PC4 | **0.998** | 10.0% | 83.2% | ❌（**差 0.002**） |
| PC5 | 0.387 | 3.9% | 87.1% | ❌ |
| PC6–PC10 | 0.351→0.162 | 各 1.6–3.5% | 90.6%→100% | ❌ |

> **PC4 的特征值 0.998 是个漂亮的巧合**：正好卡在 Kaiser 线上。它让"两个准则打架"这件事变得非常直观。

![碎石图（左）与累计解释率（右）](fig_pca_scree.png)

> 左图：第 4 根柱子正好压在 Kaiser 线上；右图：累计到 4 个是 83.2%，要过 85% 得取 5 个。

### 第 4 步：选几个主成分

```
Kaiser 准则（特征值 > 1）：3 个，累计 73.3%
累计 85% 准则：5 个，累计 87.1%
→ 两个准则差了 2 个，本文取中间的 4 个（累计 83.2%）
```

**取 4 个的理由（要写进论文）**：

- 取 3 个（Kaiser）只到 73.3%，丢掉的信息偏多；
- 取 5 个（85%）要牺牲可解释性，第 5 个主成分很难命名；
- 4 个的代价是差 2 个百分点，收益是前三个都能命名、第四个也有明确含义（见下）。

> 对比教材案例：**前两个已解释 90.79%，教材仍取到四个（98.22%）才做综合评价**。可见"85%"只是惯例，不是门槛。

|---|---|---|---|---|---|
| PM2.5 | **+0.849** | −0.12 | −0.02 | +0.01 | 0.736 |
| 二产占比 | **+0.679** | −0.17 | **+0.537** | −0.00 | 0.779 |

**命名**：

| 主成分 | 载荷特征 | 命名 | 一句话解释 |
|---|---|---|---|
| PC1（32.4%） | PM2.5、路网、能耗、二产 全为正；环保支出、绿化为负 | **污染压力** | 排放越重、治理越弱，得分越高 |
| PC2（25.7%） | 人均 GDP、风速、绿化、人口、环保支出 全为正 | **发达—宜居高** | 大城市 + 好环境 + 高治理 |
| PC3（15.2%） | 二产、能耗、绿化、风速 为正；人口密度 为负 | **工业—自然 vs 集聚** | 混合维度，**勉强可解释** |
| PC4（10.0%） | 几乎只有纬度 +0.995 | **（不命名）** | 它就是那个无关变量 |

**前 4 个主成分平均解释每个指标 83.3% 的方差**；共同度最低的 PM2.5 也有 0.736——没有变量被完全丢掉。

> 教训：**先筛变量，再做 PCA**，否则噪声也会被算进"信息量"。

### 第 6 步：得分与综合指数（两种做法）

|---|---|---|

### 第 7 步：验证与代价

**（1）指数与标签的关系**

```
PC1 指数 vs 高风险标签：Spearman ρ = 0.550（p = 6.85e-96）
按 PC1 指数分四组：高风险率 7.0% → 19.7% → 38.7% → 75.3%
单变量判别力：只用 PC1 指数 AUC = 0.833
用加权综合指数（做法 B）AUC = 0.661
```

**（2）降维的代价（同一训练/测试集，各跑一个逻辑回归）**

| 输入 | AUC | Brier |
|---|---|---|
| 原始 10 指标 | 0.852 | 0.1465 |
| 前 4 个主成分 | **0.854** | **0.1458** |

**结论**：本例降维**几乎无损、甚至略好**（+0.002）——因为 10 个指标里有大量冗余（PC1+PC2 已占 58.1%）。

> 但这不能推广：PCA 保留的是"方差大"的方向，若目标恰好由方差小的方向决定，就会把有用信息扔掉。
> 所以**必须做这一步验证**，不能假设"降维总是安全的"。

## 三、结果解读（论文结论段可直接用）

- 10 个指标可压缩为 4 个主成分，累计解释 **83.2%** 的方差；KMO = 0.768、Bartlett p<0.001，满足分析前提；
- **PC1（32.4%）刻画"污染压力"**（PM2.5、路网、能耗、二产为正，环保支出为负），**PC2（25.7%）刻画"发达—宜居"水平**；这两维已能支撑区域画像；
- **PC4（10.0%）的载荷几乎全在纬度（+0.995）**，说明未筛选的无关变量会独占主成分，**上游应先做变量筛选**；
- 只用 PC1 指数排序，与"高风险"的 AUC 达 **0.833**，四分组风险率从 7.0% 升到 75.3%，可用于快速筛查；
- 但把四个主成分加权成"综合指数"后，AUC 反而降到 **0.661**——**"信息量"与"区分度"不是一回事**；
- 降维后建模 AUC 0.854（原始 0.852），本例几乎无损，原因是指标间冗余度高。

**给决策者的建议**（E 题必写的一段）：

> 日常筛查不必用 10 个指标：**只用"污染压力"这一个主成分**（PM2.5、路网密度、能耗强度、二产占比为正，环保支出为负）即可解释大部分风险差异，且它比"综合指数"更贴合监管目标。若要给区县画像，再补上第二维"发达—宜居"，把区县分成"高压力高宜居""高压力低宜居"等类型分别施策。**数据治理层面**，建议在上游剔除与目标无关的指标（如纯粹的地理坐标），否则它们会虚增"信息量"、稀释真正的信号。

## 四、完整 Python 代码

见同目录 `pca_demo.py`（约 330 行，八步）。核心六行：

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X = StandardScaler().fit_transform(df[FEATURES])       # 必须先标准化
pca = PCA(n_components=4).fit(X)
ratio = pca.explained_variance_ratio_                  # 每个主成分解释率
load = pca.components_.T * np.sqrt(pca.explained_variance_)   # 载荷（不是 components_ 本身）
F = pca.transform(X)                                   # 得分
```

符号约定（不同软件/版本可能整体反号，必须自己定）：

```python
for j in range(n_pc):
    if load[np.argmax(np.abs(load[:, j])), j] < 0:
        load[:, j] *= -1        # 让每个主成分里绝对值最大的载荷为正
```

### 三个环境坑

1. **`components_` 的符号是任意的**：特征向量乘 −1 仍是解，不同版本/不同 `svd_solver` 可能给出相反符号，导致载荷图"看着不对"。**必须自己定符号约定**，并在图注里说明。
2. **PCA 只能在训练集上 `fit`**：如果在全量数据上拟合再切分，测试集信息已经泄漏进主成分方向，评估会虚高。本 demo 里 `pca_tr` 只在 `Xtr` 上拟合。
3. **载荷 ≠ `components_`**：`components_` 是单位特征向量，载荷要乘 `sqrt(explained_variance_)`。两者差别在"量级"，直接拿 `components_` 当载荷画图，会让所有主成分看起来一样重要。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 把多个相关指标压成少数几个不相关的主成分 |
| 核心思想？ | 换坐标轴：让投影方差最大、新轴两两垂直 |
| 要什么假设？ | 线性、方差=信息、指标间有相关性、必须标准化 |
| 最大硬伤？ | 方差大≠有用；主成分难命名；线性；符号任意 |
| 关键超参？ | 只有 `n_components`（Kaiser / 累计 85% / 业务判断） |
| 论文必写？ | KMO+Bartlett + 碎石图 + 载荷/命名 + 降维前后对比 |

## 自测三问

1. 为什么 PCA 之前必须标准化？不标准化会怎样？
2. 你的 PC4 载荷几乎只有"纬度"一个变量（+0.995），解释率还有 10%，要不要保留？
3. 论文里写"第一主成分每增加 1 个单位，PM2.5 上升 0.85 个单位"——这句话错在哪？

<details>
<summary>参考答案</summary>

1. PCA 找的是方差最大的方向，而方差和量纲绑死。本案例人口密度方差约是 PM2.5 的 600 倍，不标准化时第一主成分几乎就是人口密度，其余 9 个指标等于没参与。标准化（Z-score）后各变量方差都为 1，"话语权"才平等。

2. **不要保留，或者先剔除纬度再做 PCA。** 纬度是我们故意放的无关变量，它与其他 9 个指标几乎不相关，因此自己占了一个主成分——这 10% 的解释率是"噪声的信息量"，不是"有用的信息"。正确做法分两步：① 上游先做变量筛选（业务上无关的变量直接剔除）；② 如果已经做了 PCA，就在论文里把它当作"未筛选变量的代价"如实说明，不要把它命名为"地理维度"。

3. 错在**把载荷当回归系数**。载荷是"变量与主成分的相关系数"，不是"主成分变化 1 单位，原始变量变化多少"。正确表述是"第一主成分与 PM2.5 高度正相关（载荷 0.849），与环保支出负相关（−0.644），故可解释为'污染压力'"；而"主成分得分增加 1 单位对应 PM2.5 上升多少"这个说法本身没有意义——**主成分没有原始单位**。

</details>

## 与其他模型的衔接

| 下一步 | 说明 |
|---|---|
| 逻辑回归 | 先降维再分类（本案例 AUC 0.852 → 0.854，几乎无损） |
