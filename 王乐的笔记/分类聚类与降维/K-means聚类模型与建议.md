# 第一部分 · 理论（六层）

## 第一层：定位 —— 它解决什么问题

**一句话**：**不看标签**，只按"谁和谁像"把样本分成 K 组，让**组内尽量紧凑、组间尽量分开**。

| 问题 | 回答 |
|---|---|
| 核心问题 | 手上这批对象，能不能自然分成几"型"？每一型长什么样 |
| 输入 | `n × p` 数值矩阵，**没有标签** |
| 输出 | 每个样本的簇号 + 每个簇的中心（可反解回原量纲）+ 各簇画像 |
| 数据类型 | 表格型；类别变量要用 K-modes 或先编码 |
| 方法类别 | 无监督学习 → **划分聚类**（partitional clustering） |

### 同类竞品

| 竞品 | 关系 | 什么时候换 |
|---|---|---|
| **系统聚类 / 层次聚类（Ward 法）** | 教材 §1 的主角，给一张树状图 | 不知道分几类、要"从粗到细看一遍"、样本量不大（<1000） |
| **DBSCAN** | 基于密度，不需要预设 K | 有噪声、簇形状不规则、簇大小差很多 |
| **高斯混合（GMM）** | 软划分，给"属于每类的概率" | 需要概率归属、簇是椭球 |
| **K-medoids（PAM）** | 用真实样本点当中心 | 有离群点、距离不是欧氏 |
| **谱聚类** | 图划分 | 簇非凸、样本几千以内 |
| **K-prototypes** | 混合数值+类别 | 类别变量多，不想 one-hot |

### 一句话选型

> **要"分几型" + 样本量大 + 簇大致是球状 → K-means；不知道几类、要树状图 → 层次聚类；有噪声或非球形 → DBSCAN / GMM。**

---

## 第二层：假设 —— 它成立的前提

**一句话**：它的假设比逻辑回归更"隐"，违反时不会报错，只会**给你一堆看起来很整齐、其实没意义的簇**。

| # | 假设 | 含义（大白话） | 违反了会怎样 |
|---|---|---|---|
| 1 | **簇是凸的、球状的、大小相近** | 用欧氏距离 + 最小化平方误差，隐含"每簇是个球" | 长条形/环形/密度差异大的簇会被切错（DBSCAN 的主场） |
| 2 | **每个样本只属于一个簇** | 硬划分，没有"60% 属于 A" | 真实归属模糊时，边界样本被强行塞进某簇 |
| 3 | **距离有意义** | 欧氏距离要能反映"像不像" | 量纲不统一时，数值大的变量直接统治结果（**最常见、最致命**） |
| 4 | **K 事先给定** | 算法不会自己决定分几类 | K 猜错，整套结论都跟着错 |
| 5 | **对初值敏感** | 目标函数非凸，只能保证局部最优 | 换种子结果就变（要靠 `n_init` 多次重启压住） |
| 6 | **对异常值敏感** | 中心是"均值"，会被极端点拉走 | 一个离群点能把整个簇的中心拽偏 |

### 它**不需要**的假设

- ❌ 不需要标签（这是它相对分类模型的全部价值）
- ❌ 不需要正态分布
- ❌ 不需要自变量独立（但强相关会让距离被重复计算）
- ❌ 不需要线性关系

### 它**特有的**软肋

| 软肋 | 说明 | 后果 |
|---|---|---|
| **K 得自己定** | 没有"正确答案"，所有指标都只是参考 | 写论文时最容易被问"凭什么是 4 类" |
| **只能凸簇** | 平方误差本质是"到中心的距离" | 环形、"月牙形"数据必然错（见图对比） |
| **对量纲极敏感** | 未标准化时，方差大的变量独占距离 | 不标准化等于只用一个变量聚类 |
| **结果不稳定** | 局部最优 + 初值随机 | 不报稳定性检验，结论不可复现 |
| **不能给概率** | 只说"属于第 3 簇"，不说"多大把握" | 边界样本的处理无法解释 |
| **簇号无意义** | 簇 0/1/2/3 的编号是随机的 | 直接写"第 1 类"会误导读者 |

### 数据条件

| 项 | 要求 |
|---|---|
| 样本量 | 至少几百；太小则每簇只有几个点，中心不可信 |
| 缺失值 | sklearn 不吃 NaN，要先填补（或用 K-means 的变体） |
| 类别变量 | 先 one-hot（会造虚假距离）或改用 K-modes |
| 异常值 | **必须处理**，均值和平方距离都会被拉偏 |
| 量纲 | **必须标准化**（本案例不标准化时，第一主成分几乎就是人口密度） |
| 相关性 | 强相关变量等于给同一维度加权两次，可先 PCA 降维 |

## 第三层：原理 —— 它为什么 work

### 一句话核心思想

> **先随便放 K 个中心，然后"把每个点分给最近的中心 → 把中心挪到组内均值"，反复两遍，直到不再动。**

### 关键公式

```
目标函数（SSE / 惯性）：
    J = Σ(k=1..K) Σ(x ∈ C_k) || x − μ_k ||²

两步交替（Lloyd 算法）：
    ① 分配：C_k = { x : ||x − μ_k|| ≤ ||x − μ_j||, ∀j }      ← 固定中心，分点
    ② 更新：μ_k = mean(C_k)                                  ← 固定分组，挪中心
```

两个性质决定了它的一切行为：

- **每一步都不会让 J 变大**（分配只会选更近的；均值是平方误差的最优解），所以算法**一定收敛**。
- 但 J 是**非凸**的，不同的起点会落到不同的局部最优——所以**必须多次重启**（`n_init`）并固定种子。

### 核心一步：分配与更新的交替

这一步是 K-means 的全部。理解它，就能理解为什么"必须标准化"（距离被量纲绑架）、为什么"只能凸簇"（到中心的距离天然是球形）、为什么"对初值敏感"（局部最优）。

> 面试/答辩常问："K-means 一定会收敛吗？" —— 会，因为它等价于**坐标下降**：固定中心优化分组是凸的，固定分组优化中心也是凸的，每步目标不增且有下界，必然收敛到驻点。但收敛到的是**局部**最优。

### 机制拆解

| 机制 | 怎么做 | 作用 |
|---|---|---|
| **平方误差目标** | 最小化每点到中心的距离平方和 | 让簇"紧凑"，代价是只认球形 |
| **交替优化** | 分配 → 更新 → 再分配 | 每步都降 J，保证收敛 |
| **k-means++ 初始化** | 第一个中心随机，后续按"离已选中心越远越可能被选" | 大幅减少陷入坏局部最优 |
| **多次重启（n_init）** | 跑 10 次取 SSE 最小 | 把"运气"压到最低 |

### 关键超参数

| 超参数 | 控制什么 | 调大/调小的后果 | 常用范围 |
|---|---|---|---|
| `n_clusters`（K） | 分几类 | 太小→簇内混杂；太大→簇无意义 | 2–10（业务决定） |
| `init` | 初始中心 | `k-means++` 明显优于 `random` | `k-means++` |
| `n_init` | 重启次数 | 越大越稳、越慢 | **10–20**（sklearn 1.4+ 默认 `'auto'` 只跑 1 次，**务必显式设**） |
| `max_iter` | 单次迭代上限 | 太小会"未收敛" | 300（默认够） |
| `tol` | 收敛阈值 | 越大越早停 | 1e-4 |

### 教材口径对照：系统聚类 vs K-means

> 教材 §1 讲的是层次聚类，但"相似性度量"这一节对 K-means 完全适用。

| 环节 | 教材第 26 章 §1（系统聚类） | K-means | 差别在哪 |
|---|---|---|---|
| 相似性度量 | Minkowski / 绝对值 / **欧氏** / 马氏距离 | 默认欧氏 | 同一套距离，K-means 一般只用欧氏 |
| 聚类方式 | 自底向上合并，给**聚类图（谱系图）** | 先定 K，迭代划分 | 前者看全过程，后者只给一个结果 |
| 类间距离 | 最短距离、最长距离、重心法、**Ward 离差平方和** | 不涉及（直接优化 SSE） | Ward 法与 K-means 目标最接近 |
| 选几类 | 看聚类图在哪一层切 | 看肘部图 / 轮廓系数 | **都要人工判断，都没有"正确答案"** |
| 计算量 | O(n²)~O(n³)，n 大就跑不动 | 近似 O(n·K·p·迭代) | 上千样本以上，K-means 才实用 |
| 标准化 | 需要（马氏距离可免） | **必须** | 同 |

> **一句话**：教材教你"怎么定义像不像、怎么画树"，K-means 教你"怎么在上万样本上快速切一刀"。**距离的定义没变，切法变了。**

### 可解释性：★★☆☆☆

| 工具 | 回答什么问题 | 可信度 |
|---|---|---|
| **簇中心** | 每一型的"典型画像" | ✅ 主结果，但要反解回原量纲 |
| **簇画像表** | 各簇在每个指标上的均值 | ✅ 论文必备，是"命名"的依据 |
| **轮廓系数** | 这个点跟本簇有多贴、跟邻簇有多远 | ⚠️ 只能比较同一批数据的不同 K |
| **降维散点图** | 分得开不开（肉眼） | ⚠️ 2 维投影会骗人，必须说明解释率 |

## 第四层：操作 —— 怎么跑起来

**一句话**：K-means 的操作重点不是"调参"，而是**证明"这个 K 不是拍的"、"这个结果不是碰巧的"**。

### 七步流程（速览）

```
① 数据准备     缺失处理、异常值、标准化（不做这步等于白跑）
② 选 K         SSE 肘部 + 轮廓系数 + CH + DBI，四个一起看
③ 聚类         k-means++、n_init=10~20、固定 random_state
④ 稳定性检验    换 20 个种子重跑，算 ARI
⑤ 簇画像与命名  反解回原量纲，给每一型起名字
⑥ 外部验证      有标签就对照（ARI、各簇标签率）；没标签就做业务解释
⑦ 可视化 + 结论  PCA 降到 2 维画散点 + 各簇关键指标柱状图
```

### 七步详解

> 每一步都给三样东西：**怎么做**（分动作 + 可抄的代码）、**要算的数据怎么算**（公式 + 本案例的值）、**常见坑**。
> K-means 的难点不在代码（三行），而在"标准化、选 K、证明结果稳"这三件事上。

#### ① 标准化：不做等于用方差最大的变量聚类

**做什么（按顺序）**：

1. **先看量纲差异**：算各变量的方差，差两个数量级以上就必须标准化。本案例人口密度方差约 14 万，PM2.5 只有 227，差 600 倍。
2. **剔除与业务无关的变量**：比如纬度、编号、行政区代码。它们会污染距离（本案例的纬度就是故意放的"陷阱"）。
3. **标准化**：`StandardScaler().fit_transform(X)`，每个变量变成均值 0、标准差 1。
4. **处理异常值**：先看箱线图或 3σ，极端值会把簇中心整体拉偏。

```python
from sklearn.preprocessing import StandardScaler

X_raw = df[FEATURES]
print(X_raw.var().sort_values(ascending=False).head())   # 先看方差，确认必须标准化

X = StandardScaler().fit_transform(X_raw)
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| 各变量方差 | `X[col].var()` | PM2.5 227；人口密度约 14.2 万（差 626 倍） |
| 标准化后均值/标准差 | 应恒为 0 和 1 | 0.0000 / 1.0000 |
| 异常值个数 | 3σ 或 IQR=1.5 倍法则 | 用于决定是否剔除 |

**要画什么图**：不出正式图。可选**标准化前后箱线图**（或方差对比条形图），用来说明"为什么必须标准化"。

**论文呈现**：一句话"已对 10 个指标做 Z-score 标准化"+ 张表写清"哪个变量剔了、为什么"。

**常见坑**：

- **不标准化就跑 K-means**，聚出来的是"人口多/少"，其余 9 个指标等于没参与；论文里一眼能看出来（各簇只在最大量纲变量上分开）。
- 变量筛选要在标准化**之前**想清楚：先剔无关变量，再标准化，别反过来。

#### ② 选 K：四个指标一起看

**做什么（按顺序）**：

1. 让 K 从 2 跑到 8，每个 K 都重新 `fit`。
2. 每个 K 记录四个数：SSE（`inertia_`）、轮廓系数、CH、DBI。
3. 同时算"最小簇占比"，防止出现只有 3 个点的小簇。
4. 画两张图：肘部图（SSE 对 K）、轮廓/CH 对 K。

```python
from sklearn.cluster import KMeans
from sklearn.metrics import (silhouette_score, calinski_harabasz_score,
                             davies_bouldin_score)

rows = []
for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    rows.append([k, km.inertia_, silhouette_score(X, km.labels_),
                 calinski_harabasz_score(X, km.labels_),
                 davies_bouldin_score(X, km.labels_),
                 min(np.bincount(km.labels_)) / len(X)])
```

**要算的数据，怎么算**：

| 指标 | 公式 | 方向 | 本案例（K=2 / K=4） |
|---|---|---|---|
| SSE（惯性） | `Σ_k Σ_{x∈C_k} ‖x − μ_k‖²` | 越小越好，找拐点 | 9475.9 / 7417.6 |
| 轮廓系数 | 单点 `s=(b−a)/max(a,b)`，a=到本簇平均距离，b=到最近他簇平均距离；整体取均值 | 越大越好，>0.5 才有结构 | **0.185** / 0.141 |
| CH 指数 | `[SSB/(k−1)] / [SSW/(n−k)]` | 越大越好 | 319.1 / 246.3 |
| DBI | `(1/k)Σ max_j (S_i+S_j)/d(c_i,c_j)` | 越小越好 | 1.863 / 1.782 |
| 最小簇占比 | `min(bincount) / n` | 别低于 5% | 47.9% / 23.4% |

**要画什么图**：**肘部图**（SSE vs K，标出拐点）+ **轮廓系数 / CH 双轴图**（标出最终选的 K）。这两张就是"K 不是拍出来的"的全部证据。

**论文呈现**：一张 K 扫描表 + 一张双面板图；正文用 2–3 句说明为什么取这个 K。

**常见坑**：

- 轮廓系数是 O(n²)，上万样本会很慢，可以先抽样（`sample_size=5000`）。
- CH 和 DBI **只能在同一批数据的不同 K 之间比**，跨数据集比毫无意义。
- 四个指标常常不一致（本案例都指向 K=2，但 0.185 本身已经是"弱结构"）。

#### ③ 聚类：把随机性压住

**做什么（按顺序）**：

1. 用 `k-means++` 初始化，`n_init` 显式设 10 次（sklearn 1.4 之后默认 `'auto'` 只跑 1 次）。
2. 训练集固定 `random_state=42`，保证任何人跑出来一样。
3. 取 `labels_`（簇号）和 `cluster_centers_`（中心）。
4. **中心要反标准化**才可读：`scaler.inverse_transform(km.cluster_centers_)`。

```python
km = KMeans(n_clusters=4, init='k-means++', n_init=10,
            max_iter=300, random_state=42).fit(X)
labels = km.labels_
centers_raw = scaler.inverse_transform(km.cluster_centers_)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 最终 SSE | `km.inertia_` | 7417.6 |
| 最终轮廓/CH/DBI | 同第②步，用最终 `labels_` | 0.141 / 246.3 / 1.782 |
| 各簇样本数 | `np.bincount(labels)` 或 `value_counts()` | 292 / 326 / 301 / 281 |
| 簇中心（原量纲） | `inverse_transform(cluster_centers_)` | 见第⑤步画像表 |

**要画什么图**：先出草图——**PCA 二维散点 + 簇中心**（正式版在第⑦步重画）；可再加一张各簇样本数条形图，检查有没有过小的簇。

**论文呈现**：结论表里给"K / 样本数 / 轮廓系数"三列，并写清 `n_init` 与随机种子。

**常见坑**：

- **`n_init` 不写**，不同机器结果会不一样，答辩现场复现不出来。
- `cluster_centers_` 是 z 分数，直接写进论文没人看得懂。
- 簇号（0/1/2/3）是随机分配的，同一份数据跑两次可能对调，写论文前要按业务重排（比如按 PM2.5 均值升序编号）。

#### ④ 稳定性：换个种子会不会变

**做什么（按顺序）**：

1. 用 20 个不同的 `random_state` 重跑，得到 20 组标签。
2. 每组都跟基准结果算 **ARI**（调整兰德指数）。
3. 看 ARI 的均值与最小值；更严格的做法是对数据做 bootstrap 重采样再聚类。

```python
from sklearn.metrics import adjusted_rand_score

aris = [adjusted_rand_score(labels,
        KMeans(n_clusters=4, n_init=10, random_state=s).fit(X).labels_)
        for s in range(20)]
print(f'ARI 均值 {np.mean(aris):.4f}，最小 {np.min(aris):.4f}')
```

**要算的数据，怎么算**：

| 数据 | 公式 | 本案例的值 |
|---|---|---|
| ARI | 基于列联表：`(RI − E[RI]) / (max RI − E[RI])`，取值约 [−0.5, 1] | 均值 **0.9592**，最小 0.8321 |
| 判读 | >0.8 稳；0.5–0.8 尚可；<0.5 别写进论文 | 通过 ✅ |

**要画什么图**：**20 次 ARI 的点图或箱线图**（横轴种子序号、纵轴 ARI、画 0.8 参考线）。不画也能用一句话交代，但画了更稳。

**论文呈现**：一句话"20 次重跑的 ARI 均值 0.96（最小 0.83），分法稳定"。

**常见坑**：

- ARI 只在**同一个 K** 的不同运行之间比；拿 K=2 和 K=4 的结果算 ARI 没有意义。
- 稳定性差说明数据本身没有簇结构，不是你代码写错了——这时候该在论文里承认。

#### ⑤ 簇画像与命名：把簇号翻译成人话

**做什么（按顺序）**：

1. 按簇求每个指标的**原始量纲均值**（不是 z 分数）。
2. 算每个指标"偏离总体几个标准差"，找出每个簇最突出的 2–3 个指标。
3. 用这几个指标给簇命名，命名必须能在表里被检验。
4. 统计每簇样本数，以及每簇的标签率（若手上有标签）。

```python
d = df.copy()
d['cluster'] = labels
profile = d.groupby('cluster')[FEATURES].mean().round(2)
profile['样本数'] = d['cluster'].value_counts().sort_index()

overall_std = d[FEATURES].std()
z_dev = (profile[FEATURES] - d[FEATURES].mean()) / overall_std   # 偏离几个 SD
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 簇×指标均值 | `groupby('cluster').mean()` | 见下表 |
| 各簇样本数 | `value_counts()` | 292 / 326 / 301 / 281 |
| 各簇标签率 | `groupby('cluster')['y'].mean()` | 8.2% / 13.5% / 56.8% / 65.1% |
| 偏离度 | `(簇均值 − 总体均值) / 总体标准差` | 用来挑"命名依据" |

本案例的四型：

| 指标 | 簇 0 | 簇 1 | 簇 2 | 簇 3 |
|---|---|---|---|---|
| PM2.5 | 38.5 | 34.7 | **52.5** | **60.9** |
| 二产占比 | 34.0 | 29.1 | **45.3** | **45.6** |
| 能耗强度 | 0.52 | 0.42 | **0.72** | **0.73** |
| 路网密度 | 4.57 | 2.33 | 3.90 | **6.90** |
| 人口密度 | 664 | 310 | 333 | **936** |
| 绿化率 | **44.1** | 35.7 | 33.1 | 36.2 |
| 环保支出 | **2.93** | 2.60 | 1.77 | 1.91 |

**要画什么图**：**簇画像热力图**（行=簇、列=指标、颜色=偏离总体的标准差），比 7 列表格直观得多，命名依据一眼可见。

**论文呈现**：簇画像表是核心；命名要写成"绿色集约型/工业依赖型"这种可检验的标签，不要写"第一类/第二类"。

**常见坑**：

- 直接用 z 分数均值做表，读者看不懂；必须反解回原量纲。
- 命名只看一个指标容易被质疑（比如只看 PM2.5 就说是"污染型"），至少给 2–3 个依据。

#### ⑥ 外部验证：聚类不是分类

**做什么（按顺序）**：

1. 如果手上有标签（本案例有 `high_risk`），算聚类与标签的 ARI。
2. 统计每个簇的标签率，看有没有梯度。
3. 可选：卡方检验，看"簇"与"标签"是否相关。
4. **标签绝对不能参与聚类**，只能事后对照。

```python
from sklearn.metrics import adjusted_rand_score
from scipy.stats import chi2_contingency

ari = adjusted_rand_score(df['high_risk'], labels)
ct = pd.crosstab(labels, df['high_risk'])
chi2, p, dof, _ = chi2_contingency(ct)
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| ARI | 同第④步公式，输入换成"簇号 vs 标签" | **0.123**（几乎无关） |
| 各簇标签率 | `groupby('cluster')['high_risk'].mean()` | 8.2% → 65.1% |
| 卡方 p | `chi2_contingency` | p<0.001（显著相关） |

**要画什么图**：**各簇高风险率柱状图**，加一条全样本均值的虚线。这张图回答"分型到底有没有用"，比散点更有说服力。

**论文呈现**：一张"各簇高风险率"柱状图；正文点明"聚类给型、不负责给是不是"。

**常见坑**：

- ARI 低就慌：ARI 衡量的是"两种分组是否一致"，不是"聚类好坏"。本案例 ARI 0.12 但风险率梯度明显，说明它按另一个维度分了组。
- 把标签喂进聚类（半监督）再声称"无监督发现"，属于方法造假。

#### ⑦ 可视化：2 维投影 + 关键指标

**做什么（按顺序）**：

1. 用 PCA 把 p 维降到 2 维（**只为画图**，聚类本身用全部维度）。
2. 散点按簇着色，簇中心用大标记（也要降到 2 维）。
3. 配一张柱状图：各簇的关键指标或标签率——这张图往往比散点更有说服力。
4. 图注必须写"PCA 二维投影，解释率 xx%"。

```python
from sklearn.decomposition import PCA

pca2 = PCA(n_components=2, random_state=42).fit(X)
X2 = pca2.transform(X)
centers2 = pca2.transform(km.cluster_centers_)
print(pca2.explained_variance_ratio_.sum())    # 必须写进图注
```

**要算的数据，怎么算**：

| 数据 | 怎么算 | 本案例的值 |
|---|---|---|
| 二维解释率 | `explained_variance_ratio_.sum()` | 32.4% + 25.7% = **58.1%** |
| 簇中心二维坐标 | `pca2.transform(centers)` | 用于画 X 标记 |
| 各簇风险率 | 同第⑥步 | 8.2% / 13.5% / 56.8% / 65.1% |

**要画什么图**：**PCA 二维散点**（按簇着色 + 中心用 X 标出）+ **各簇关键指标柱状图**，左右并排；图注必须写前两个主成分的解释率。

**论文呈现**：散点图 + 柱状图并排；图注写清投影方式与解释率。

**常见坑**：

- 只画 2 维散点就下结论"四类分得很开"——58.1% 的解释率意味着还有 42% 的信息没画出来，散点上重叠很正常。
- 图注不写解释率，评委会以为你在用 2 维聚类。

## 第五层：评价 —— 怎么判断它好不好

**一句话**：轮廓系数告诉你"分得紧不紧"，簇画像告诉你"分得有没有用"——**两者都过，才算成**。

| 维度 | 表现 |
|---|---|
| **主指标** | 轮廓系数、CH、DBI |
| **稳定性** | 多种子 ARI |
| **基线** | 不分（K=1）或按单变量分箱 |
| **对异常值** | 敏感（比层次聚类更敏感） |
| **对量纲** | **极敏感**（不标准化 = 白跑） |
| **小样本** | 不稳，每簇少于 20 个点就别下结论 |
| **过拟合** | 无监督没有"过拟合"概念，但有"K 太大"的等价问题 |
| **外推** | 不能用：新样本只能"分给最近的中心"，超出训练范围不可靠 |

### 三条容易被忽略的规律

> **① 轮廓系数最高的 K，往往不是能用的 K。**
> 本案例 K=2 的轮廓系数 0.185 最高，但只有"高/低"两半，没法写政策建议；取 K=4（0.141）才有四型。
> **指标用来排除坏答案，不用来拍板。**

> **② 聚类和标签可以几乎无关，但业务上仍然有区分度。**
> 本案例聚类与 `high_risk` 的 **ARI 只有 0.123**（几乎无关），但四簇的高风险率是 **8.2% / 13.5% / 56.8% / 65.1%**。
> **ARI 低不代表聚类没用，只代表"它按另一个维度分组"。**

> **③ 数据里可能根本没有簇。**
> 轮廓系数最高只有 0.185，说明这 1200 个区县在 10 维空间里是**连续分布**，没有天然团块。
> 此时聚类的价值不是"发现自然类别"，而是"**人为切档**"——论文里必须这么说，不能写成"数据自然分为四类"。

## 第六层：比赛 —— 怎么把它写进论文

**一句话**：评委看的不是"你用了 K-means"，而是"**你凭什么分 K 类、这 K 类站不站得住**"。

### 对应题型

| 题型 | 匹配度 | 说明 |
|---|---|---|
| A 连续/物理 | ⚠️ 偶尔 | 参数分区、状态划分 |
| B 离散/物理 | ⚠️ 偶尔 | 同上 |
| **C 数据科学** | ⭐ 常见 | 给样本分档、找"典型样本" |
| D 运筹 | ⚠️ 偶尔 | 先分型再分配资源 |
| **E 环境** | ⭐⭐ 主战场 | 区域分级、污染类型分区（本案例） |
| **F 政策** | ⭐ 常见 | 人群/地区分型，差异化施策 |

### 三个典型场景

1. **E 题·区域分级**：把几百个地区按污染/风险指标分成 4–5 档，**用聚类中心代表每一档**（O 奖常见套路）。
2. **F 题·人群分型**：按行为/态度把受访者分成几类，再对每类给不同政策建议。
3. **先分型、再分层建模**：先聚类，再在每一型里单独做回归/逻辑回归，避免"一个系数套所有样本"。

> 你库里的 O 奖笔记有现成用例：2314817 用 K-means 给 284 个地区定四级风险阈值；2314354 用**聚类中心**代表四类地区（"聚类中心 = 数据代表"这句话直接可抄）。

### 论文呈现顺序

```
1. 变量表 + 标准化说明                    ← 先说清洗
2. K 扫描表（SSE / 轮廓 / CH / DBI）      ← 证明 K 不是拍的
3. 稳定性检验（多种子 ARI）               ← 加分项，很多队不写
4. 簇画像表（簇 × 指标均值 + 样本数）      ← 核心
5. 二维散点图 + 各簇关键指标柱状图
6. 命名与施策建议（每型一条）
```

### 局限性写法（可直接改）

> "K-means 以欧氏距离与平方误差为目标，隐含'簇为球状、大小相近'的假设；本文数据的轮廓系数最高仅 0.185，说明样本在指标空间中更接近连续分布而非天然分簇，因此本文的聚类结果应理解为**人为分档**，而非客观存在的类别。为降低随机初值的影响，采用 k-means++ 初始化并重复 10 次取最优，另以 20 个不同随机种子重跑，调整兰德指数（ARI）均值 0.96，分法稳定。需要指出，聚类结果与'高风险'标签的 ARI 仅 0.123，说明'类型'与'是否高风险'是两个维度；本文因此把聚类用于**差异化施策**，而非风险判定。"

> 关键在"**人为分档**"这四个字——主动承认，比硬说"数据自然分为四类"安全得多。

### 替代 / 组合

| 组合 | 用途 |
|---|---|
| **K-means + 熵权/TOPSIS** | 先综合评价打分，再对分数聚类分档（E 题标配） |
| **K-means + 回归/逻辑回归** | 先分型，再在每型内建模（分层建模） |
| **PCA + K-means** | 变量多、共线严重时先降维再聚类（本案例画图就是这么做的） |
| **K-means + 判别分析** | 用聚类结果当"伪标签"，再训一个分类器给新样本定性 |
| **系统聚类（Ward）** | 样本 <1000 且想展示树状图时替换 |

### 三个常见扣分点

1. **不标准化** → 聚出来的其实是"数值最大的那个变量"，评委一问就露馅。
2. **不报选 K 的依据** → 直接写"分为 4 类"，没有任何指标或论证，必被追问。
3. **说"聚类证明数据有 4 类"** → 轮廓系数 0.14 还说"自然分为四类"，属于过度解读；正确说法是"按业务需要切为四档，并验证其稳定性"。

# 第二部分 · 案例（E 题风格：1200 个区县的"污染类型"分型）

## 二、完整建模流程（7 步）

### 第 1 步：标准化

```
原始：PM2.5 均值 46.20，标准差 15.06，范围 [12.0, 91.9]
标准化后：均值 0.0000，标准差 1.0000
```

> 为什么必须做：人口密度的方差约是 PM2.5 的 600 倍。不标准化，欧氏距离几乎只由人口密度决定。

### 第 2 步：选 K

K 从 2 试到 8：

| K | SSE | 轮廓系数↑ | CH↑ | DBI↓ | 最小簇占比 |
|---|---|---|---|---|---|
| 2 | 9475.9 | **0.185** | **319.1** | 1.863 | 47.9% |
| 3 | 8145.0 | 0.164 | 283.3 | 1.712 | 30.7% |
| **4** | **7417.6** | 0.141 | 246.3 | 1.782 | 23.4% |
| 5 | 6923.4 | 0.138 | 219.1 | 1.716 | 16.0% |
| 6 | 6483.2 | 0.138 | 203.2 | 1.644 | 12.1% |
| 7 | 6174.7 | 0.134 | 187.6 | 1.658 | 11.1% |
| 8 | 5926.3 | 0.129 | 174.5 | 1.675 | 10.2% |

**读表**：

- SSE 从 K=2 到 K=3 降了 1331，K=3 到 4 降 727，之后越来越平——**肘部不明显**，这本身就是"弱结构"的信号。
- 轮廓系数单调下降，K=2 最高但只有 0.185（<0.5，属于"弱结构"）。
- CH 与 DBI 同样指向 K=2。

![选 K 的两张诊断图：肘部法（左）、轮廓系数与 CH（右）](fig_kmeans_k.png)

> 左图看"肘部"（并不明显），右图看轮廓系数与 CH（都在 K=2 最高）。两张图其实在说同一件事：**这份数据的结构很弱**。

### 第 3 步：定 K=4 —— 一次真实的取舍

```
轮廓系数在 K=2 最高（0.185），K=4 只有 0.141。
但 0.185 本身就已经是"弱结构"——数据里并没有天然分明的团块。
硬按指标取 K=2，只会得到"高/低"两半，没法支撑政策建议；
取 K=4 的代价是轮廓系数再降一点，换来的是四类可以分别命名、分别施策。
```

> **这一段应该原样搬进论文的"模型选择"节**：它同时交代了指标结果、偏离指标的理由、以及代价。评委最认这种写法。

### 第 4 步：聚类 + 稳定性

```
K=4：SSE=7417.6，轮廓=0.141，CH=246.3，DBI=1.782
20 次不同种子：ARI 均值 0.9592，最小 0.8321，最大 1.0000
```

ARI 0.96 说明"换种子基本还是同一套分法"——这条比轮廓系数更能让评委放心。

## 三、结果解读（论文结论段可直接用）

- 用 K-means 把 1200 个区县分为四型：**绿色集约型（292 个）、低排欠发达型（326 个）、工业依赖型（301 个）、高密度复合型（281 个）**；
- 轮廓系数最高仅 0.185，说明样本在指标空间接近连续分布，**分型应理解为人为分档**；但 20 次重跑的 ARI 均值 0.96，分法稳定；
- 四型的高风险率呈明显梯度（**8.2% → 13.5% → 56.8% → 65.1%**），说明分型对风险有区分力；
- 聚类与高风险标签的 ARI 仅 0.123，**"型"与"是不是高风险"是两个维度**——不能互相替代。

**给决策者的建议**（E 题必写的一段）：

> 施策应按型而不是按排名：**工业依赖型**（二产 45%、能耗 0.72、环保支出仅 1.77%）应优先抓产业结构与能耗强度，这是"源头治理"；**高密度复合型**（人口 936、路网 6.9）应主攻交通源与用地布局，靠末端治理收效有限；**绿色集约型**已是标杆，可作为其他区的对照样本；**低排欠发达型**当前风险低，但环保支出与绿化都偏弱，应防止"承接产业转移"后跃迁为工业依赖型——这是最该提前布防的一类。

## 四、完整 Python 代码

见同目录 `kmeans_demo.py`（约 280 行，八步）。核心五行：

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

X = StandardScaler().fit_transform(df[FEATURES])          # 必须先标准化
km = KMeans(n_clusters=4, init='k-means++', n_init=10, random_state=42).fit(X)
labels = km.labels_                                        # 簇号（无意义，需重排）
centers_raw = scaler.inverse_transform(km.cluster_centers_)  # 反解回原量纲才可读
```

稳定性检验（这一步最容易被漏）：

```python
from sklearn.metrics import adjusted_rand_score
aris = [adjusted_rand_score(labels,
        KMeans(n_clusters=4, n_init=10, random_state=s).fit(X).labels_)
        for s in range(20)]
print(np.mean(aris), np.min(aris))     # >0.8 才算稳
```

### 三个环境坑

1. **sklearn 1.4+ 的 `n_init` 默认是 `'auto'`**：用 k-means++ 时只跑 1 次（旧版默认 10 次），结果会明显更依赖初值。**必须显式写 `n_init=10`**。
2. **`km.cluster_centers_` 在标准化空间里**，数值是 z 分数，直接写进论文没人看得懂。要用 `scaler.inverse_transform()` 反解回原量纲。
3. **`labels_` 的簇号是随机分配的**：同一份数据跑两次，"簇 0"可能对应不同的型。写论文前要按业务逻辑重排（例如按 PM2.5 均值从低到高编号）。

# 第三部分 · 速记与自测

## 一页速记

| 问题 | 答案 |
|---|---|
| 它做什么？ | 无标签，按"像不像"把样本分成 K 组 |
| 核心思想？ | 分配 → 更新中心 → 反复，最小化簇内平方误差 |
| 要什么假设？ | 球形簇、距离有意义（要标准化）、K 已知、每个点只属一类 |
| 最大硬伤？ | K 得猜；只能凸簇；对量纲和异常值敏感；结果只是局部最优 |
| 关键超参？ | `n_clusters`、`n_init`、`init='k-means++'` |
| 论文必写？ | 选 K 的依据 + 稳定性 ARI + 簇画像表 + 二维散点图 |

## 自测三问

1. 为什么 K-means 必须标准化？不标准化会发生什么？能不能用一句话说清。
2. 轮廓系数在 K=2 时最高（0.185），你取 K=4，评委问"为什么不听指标的"，怎么答？
3. 聚类结果是四类，但和"高风险"标签的 ARI 只有 0.12，是不是说明聚类失败了？

<details>
<summary>参考答案</summary>

1. 因为 K-means 用欧氏距离，距离是**各变量差的平方和**——方差大的变量天然占主导。本案例人口密度方差约是 PM2.5 的 600 倍，不标准化时距离几乎只由人口密度决定，聚出来的"类型"就是"人口多/少"，其余 9 个指标等于没用。一句话：**不标准化 = 用方差最大的那个变量聚类。**

2. "0.185 本身已经是弱结构（<0.2 基本没结构），指标在这里只能排除坏答案，不能拍板。取 K=2 只能得到'高/低'两半，无法支撑差异化施策；取 K=4 的代价是轮廓系数降 0.044，收益是四型可分别命名（绿色集约/低排欠发达/工业依赖/高密度复合），且 20 次重跑的 ARI 达 0.96，分法稳定。**指标服从于任务**，这是聚类与监督学习的最大不同。"

3. 不是。ARI 衡量的是"两种分组是否一致"，不是"聚类好坏"。聚类按 10 个指标的整体相似性分组，标签只按"是否高风险"二分，两者本就是不同维度。但四簇的高风险率从 8.2% 到 65.1% 有明显梯度，说明**分型对风险有区分力**——正确的用法是"按型施策"，而不是"用型代替风险判定"。

</details>
