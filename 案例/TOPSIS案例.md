## 一、和熵值法的关系

| 步骤 | 谁负责 | 说明 |
|---|---|---|
| 定权重 | 熵值法 | 算出每个指标的权重 w |
| 排序 | TOPSIS | 用这组权重，按「离理想解远近」排序 |

两个合起来就是最经典的 **「熵权-TOPSIS」组合**。所以本案例**数据沿用熵值法的 5 城市 4 指标，权重直接用熵值法第 5 步的结果**。

### 原始数据（输入，同熵值法）

| 城市 | 人均GDP(万元) ↑ | 空气优良率(%) ↑ | PM2.5(μg/m³) ↓ | 森林覆盖率(%) ↑ |
|---|---|---|---|---|
| A | 12.5 | 78 | 45 | 18 |
| B | 8.6 | 65 | 62 | 25 |
| C | 15.2 | 82 | 38 | 30 |
| D | 6.8 | 71 | 58 | 42 |
| E | 10.4 | 75 | 50 | 22 |

---

## 二、权重来源（重要，务必看懂）

```
w = [0.2473, 0.1998, 0.2575, 0.2954]
      ↑人均GDP  ↑优良率  ↑PM2.5  ↑森林覆盖
```

这组权重**不是拍脑袋来的**，是「熵值法案例」最后三步的结果：

| 步骤 | 公式 | 人均GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|---|
| 熵值法·第 3 步 | 信息熵 e | 0.7792 | 0.8217 | 0.7701 | 0.7363 |
| 熵值法·第 4 步 | 差异系数 `d = 1 − e` | 0.2208 | 0.1783 | 0.2299 | 0.2637 |
| 熵值法·第 5 步 | 权重 `w = d / Σd`（Σd = 0.8927） | **0.2473** | **0.1998** | **0.2575** | **0.2954** |

> ⚠️ 如果换一批数据，这组权重必须**重新用熵值法算一遍**，不能照抄——熵权法的权重跟着数据走，数据变了差异程度就变，权重也变。

---

## 三、关键区别（最容易踩坑）

| | 熵值法 | TOPSIS |
|---|---|---|
| 标准化方法 | **min-max**（压到 0~1） | **平方和归一化**（除以列模长） |
| 为什么 | 后面要算「比重/概率」，要求非负 | 后面要算「欧氏距离」，要把各指标放到同一尺度 |

所以 TOPSIS 第 2 步**不是** min-max，是平方和归一化。

---

## 四、完整计算流程（7 步）

### 第 1 步：正向化（把所有指标变成「越大越好」）

TOPSIS 四种指标类型公式：

- **极大型**（越大越好）：`x' = x`（不变）
- **极小型**（越小越好）：`x' = max − x`（翻过来）
- **中间型**（越接近某值越好）：`x' = 1 − |x − x_best| / max|x − x_best|`
- **区间型**（落在区间内最好）：略（本例用不到）

本例：人均GDP、优良率、森林覆盖是极大型 → 不变；**PM2.5 是极小型 → 用 `max − x` 翻转**（max = 62）。

**代入示例**（城市 A 的 PM2.5）：`62 − 45 = 17`

**正向化后**

| 城市 | 人均GDP | 优良率 | PM2.5(翻转后) | 森林覆盖 |
|---|---|---|---|---|
| A | 12.5 | 78 | 17 | 18 |
| B | 8.6 | 65 | 0 | 25 |
| C | 15.2 | 82 | 24 | 30 |
| D | 6.8 | 71 | 4 | 42 |
| E | 10.4 | 75 | 12 | 22 |

---

### 第 2 步：平方和归一化

```
z_ij = x'_ij / sqrt( Σ x'_ij² )      （分母 = 这一列每个数平方后加总、再开根号）
```

先算每列的分母（列模长）：

| 指标 | 人均GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|
| Σx'² | 615.65 | 27699 | 1025 | 4097 |
| sqrt(Σx'²) | 24.8123 | 166.4302 | 32.0156 | 64.0078 |

**代入示例**（城市 A 的人均GDP）：`12.5 / 24.8123 = 0.5038`

**归一化矩阵 z**

| 城市 | 人均GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|
| A | 0.5038 | 0.4687 | 0.5310 | 0.2812 |
| B | 0.3466 | 0.3906 | 0.0000 | 0.3906 |
| C | 0.6126 | 0.4927 | 0.7496 | 0.4687 |
| D | 0.2741 | 0.4266 | 0.1249 | 0.6562 |
| E | 0.4191 | 0.4506 | 0.3748 | 0.3437 |

---

### 第 3 步：加权（乘上权重）

```
v_ij = z_ij × w_j
```

**加权矩阵 v**

| 城市 | 人均GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|
| A | 0.1246 | 0.0936 | 0.1367 | 0.0831 |
| B | 0.0857 | 0.0780 | 0.0000 | 0.1154 |
| C | 0.1515 | 0.0984 | 0.1930 | 0.1385 |
| D | 0.0678 | 0.0852 | 0.0322 | 0.1938 |
| E | 0.1037 | 0.0900 | 0.0965 | 0.1015 |

---

### 第 4 步：找理想解 Z+ 和负理想解 Z-

```
Z+_j = 第 j 列的最大值      （想象中最完美的城市）
Z-_j = 第 j 列的最小值      （想象中最差的城市）
```

| | 人均GDP | 优良率 | PM2.5 | 森林覆盖 |
|---|---|---|---|---|
| 理想解 Z+ | 0.1515 | 0.0984 | 0.1930 | 0.1938 |
| 负理想解 Z- | 0.0678 | 0.0780 | 0.0000 | 0.0831 |

---

### 第 5 步：算欧氏距离

```
D+_i = sqrt( Σ_j (v_ij − Z+_j)² )     （离理想解有多远）
D-_i = sqrt( Σ_j (v_ij − Z-_j)² )     （离负理想解有多远）
```

**代入示例**（城市 A）：

```
D+ = sqrt((0.1246−0.1515)² + (0.0936−0.0984)² + (0.1367−0.1930)² + (0.0831−0.1938)²) = 0.1272
D- = sqrt((0.1246−0.0678)² + (0.0936−0.0780)² + (0.1367−0)²       + (0.0831−0.0831)²) = 0.1489
```

**距离表**

| 城市 | D+（离理想） | D-（离最差） |
|---|---|---|
| A | 0.1272 | 0.1489 |
| B | 0.2195 | 0.0370 |
| C | 0.0554 | 0.2185 |
| D | 0.1818 | 0.1156 |
| E | 0.1421 | 0.1053 |

---

### 第 6 步：算贴近度 C

```
C_i = D-_i / (D+_i + D-_i)       （C 越大 = 越接近理想解 = 越好，范围 0~1）
```

**代入示例**（城市 A）：`C = 0.1489 / (0.1272 + 0.1489) = 0.5392`

| 城市 | 贴近度 C |
|---|---|
| A | 0.5392 |
| B | 0.1441 |
| C | 0.7978 |
| D | 0.3886 |
| E | 0.4256 |

---

### 第 7 步：排序

| 排名 | 城市 | C |
|---|---|---|
| 1 | C | 0.7978 |
| 2 | A | 0.5392 |
| 3 | E | 0.4256 |
| 4 | D | 0.3886 |
| 5 | B | 0.1441 |

**结论**：城市 C 可持续发展水平最高，B 最低。

---

## 五、重点：为什么 D 和 E 的排名和熵值法不同？

| 方法 | 排名 |
|---|---|
| 熵值法（简单加权） | C > A > **D** > **E** > B |
| TOPSIS | C > A > **E** > **D** > B |

D 和 E 互换了。原因：

- **城市 D**：森林覆盖率最高（0.1938，全场第一），但人均GDP 最低、PM2.5 很差——典型「严重偏科」。
- **城市 E**：每个指标都居中，没有短板——「均衡型」。

TOPSIS 用「到理想解的**直线距离**」衡量，会**惩罚偏科**：D 虽然一项很强，但另外几项离理想解太远，总距离反而大。所以 E 排到了 D 前面。

> 这正是 TOPSIS 和「简单加权求和（SAW）」的核心差别。写论文时这个对比可以直接作为「方法对比/交叉验证」的素材。

## 六、完整 Python 代码（每步带注释）

```python
# -*- coding: utf-8 -*-
"""
TOPSIS 完整实例 —— 城市可持续发展评价（承接熵值法）
====================================================
数据：沿用熵值法的 5 城市 × 4 指标
权重：来自【熵值法案例】第 5 步的结果 w = [0.2473, 0.1998, 0.2575, 0.2954]

每一步公式：
  ① 正向化       极大型不变；极小型 x' = max - x
  ② 平方和归一化 z_ij = x'_ij / sqrt( Σ x'_ij² )
  ③ 加权         v_ij = z_ij × w_j
  ④ 理想解/负理想解  Z+ = 每列最大，Z- = 每列最小
  ⑤ 欧氏距离     D+ = sqrt(Σ(v-Z+)²)，D- = sqrt(Σ(v-Z-)²)
  ⑥ 贴近度       C = D- / (D+ + D-)
  ⑦ 排序         C 从大到小

运行： python topsis_demo.py
中文乱码： python -X utf8 topsis_demo.py
"""

import math   # math.sqrt 求平方根


# ================= 第 0 步：准备数据 =================
cities = ['A', 'B', 'C', 'D', 'E']

# 每一行 = 一个城市；4 个数依次是 人均GDP、优良率、PM2.5、森林覆盖率
X = [
    [12.5, 78, 45, 18],   # 城市 A
    [8.6,  65, 62, 25],   # 城市 B
    [15.2, 82, 38, 30],   # 城市 C
    [6.8,  71, 58, 42],   # 城市 D
    [10.4, 75, 50, 22],   # 城市 E
]

# 每个指标的类型：'max'=极大型(越大越好)  'min'=极小型(越小越好)
kind = ['max', 'max', 'min', 'max']     # PM2.5 是极小型

# 权重：来自【熵值法案例】第 5 步的结果（w = d/Σd，差异系数归一化）
# 对应指标顺序：人均GDP、优良率、PM2.5、森林覆盖
# 注意：换数据要重新用熵值法算权重，不能照抄
w = [0.2473, 0.1998, 0.2575, 0.2954]

n = len(X)        # 城市个数 = 5
m = len(X[0])     # 指标个数 = 4
col_names = ['人均GDP', '优良率', 'PM2.5', '森林覆盖']


# 打印表格的小工具
def 打印矩阵(标题, 行名, 列名, 矩阵, 保留=4):
    print("\n" + 标题)
    print("        " + "  ".join(f"{c:>10}" for c in 列名))
    for i, name in enumerate(行名):
        row = "  ".join(f"{矩阵[i][j]:>{10}.{保留}f}" for j in range(len(列名)))
        print(f"  {name:>4}  {row}")


# ================= 第 1 步：正向化 =================
# 极大型：不变；极小型：x' = max - x（用本列最大值减去原值，翻过来）
X_pos = [row[:] for row in X]     # 先复制一份原始数据

for j in range(m):                # 遍历每个指标
    if kind[j] == 'min':          # 只有极小型才需要翻转
        col_max = max(X[i][j] for i in range(n))   # 这一列的最大值
        for i in range(n):
            X_pos[i][j] = col_max - X[i][j]        # max - x

打印矩阵("第 1 步：正向化后（全部变成越大越好）", cities, col_names, X_pos)


# ================= 第 2 步：平方和归一化 =================
# z_ij = x'_ij / sqrt( Σ x'_ij² )
# 分母 = 这一列每个数先平方、再加总、最后开根号
col_norm = [0.0] * m
for j in range(m):
    sumsq = sum(X_pos[i][j] ** 2 for i in range(n))   # 这一列的平方和
    col_norm[j] = math.sqrt(sumsq)                     # 开根号
print("\n每列的 sqrt(Σx²)（归一化分母）：", [round(v, 4) for v in col_norm])

z = [[0.0] * m for _ in range(n)]
for j in range(m):
    for i in range(n):
        z[i][j] = X_pos[i][j] / col_norm[j]

打印矩阵("第 2 步：平方和归一化后的 z", cities, col_names, z)


# ================= 第 3 步：加权 =================
# v_ij = z_ij × w_j
v = [[z[i][j] * w[j] for j in range(m)] for i in range(n)]
打印矩阵("第 3 步：加权后的 v（z × 权重）", cities, col_names, v)


# ================= 第 4 步：理想解 / 负理想解 =================
# Z+ = 每列最大值，Z- = 每列最小值
Z_plus  = [max(v[i][j] for i in range(n)) for j in range(m)]
Z_minus = [min(v[i][j] for i in range(n)) for j in range(m)]
print("\n第 4 步：理想解 Z+（每列最大）：", [round(x, 4) for x in Z_plus])
print("        负理想解 Z-（每列最小）：", [round(x, 4) for x in Z_minus])


# ================= 第 5 步：欧氏距离 =================
# D+ = sqrt(Σ(v - Z+)²)，D- = sqrt(Σ(v - Z-)²)
D_plus  = [0.0] * n
D_minus = [0.0] * n
for i in range(n):
    s_plus  = sum((v[i][j] - Z_plus[j])  ** 2 for j in range(m))
    s_minus = sum((v[i][j] - Z_minus[j]) ** 2 for j in range(m))
    D_plus[i]  = math.sqrt(s_plus)
    D_minus[i] = math.sqrt(s_minus)

print("\n第 5 步：欧氏距离")
for i in range(n):
    print(f"  城市 {cities[i]}  D+ = {D_plus[i]:.4f}   D- = {D_minus[i]:.4f}")


# ================= 第 6 步：贴近度 C =================
# C = D- / (D+ + D-)，越接近 1 越好
C = [D_minus[i] / (D_plus[i] + D_minus[i]) for i in range(n)]
print("\n第 6 步：贴近度 C")
for i in range(n):
    print(f"  城市 {cities[i]}  C = {C[i]:.4f}")


# ================= 第 7 步：排序 =================
rank = sorted(range(n), key=lambda i: C[i], reverse=True)   # 按 C 从大到小
print("\n第 7 步：最终排名")
for 名次, i in enumerate(rank, start=1):
    print(f"  第 {名次} 名：城市 {cities[i]}  C = {C[i]:.4f}")

print("\n结论：城市 C 可持续发展水平最高，B 最低。")
```
